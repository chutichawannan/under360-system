# 📬 Under360 — บุรุษไปรษณีย์ (Postman)

> **หลักการ (นัทออกแบบ 1 ส.ค. 2026 · B+C hybrid):** ทุกห้องเปิด terminal ค้างไว้ (attended) · บุรุษไปรษณีย์ 1 ตัวไล่ดูบอร์ดทุก 1 ชม. → **ปลุกเฉพาะห้องที่มีจดหมายจริง** → ห้องนั้นค่อยโหลดสมองตอบ · ห้องไม่มีจดหมาย = ไม่ตื่น = ไม่เผา token
> ⚠️ **ต้องรันในโหมด attended (terminal เปิดค้าง)** — `send_message` ปลุกห้องอื่นไม่ได้ในโหมด headless/scheduled-task · วิธีรัน: `/loop 1h /under360-postman`

## รอบการทำงาน (1 cycle)
**1. หาแผนที่ ห้อง→session ที่รันอยู่** — `mcp__ccd_session_mgmt__list_sessions` → เอาเฉพาะ `isRunning:true` → map ชื่อ→room (เอา session ที่ `lastActivityAt` ใหม่สุดถ้าชื่อซ้ำ):
`13/07/03 U-track`→u · `02/02.1 M-track`→m · `05 LINE OA`/`06 FB Ads`→eath · `08 F-track`→f · `11 P-Track`/`Migrate`→migrate · `12 …นิว`→niw · `10 …เตียง`→tiang · `04 A-track`/`09 Widget`→a · `R&D 01`→rnd01 · `ห้องพลอย`→ploy

**2. อ่านบอร์ด หาจดหมายค้าง** — `GET session_messages?order=created_at.desc&limit=40` (creds ใน CLAUDE.md) → group ตาม room → **ห้องมีจดหมายค้าง เมื่อ:** ข้อความล่าสุดของห้องนั้น **ไม่ใช่**จาก session ห้องนั้นเอง (เป็นของนัท หรือห้องอื่นโพสต์เข้ามา) และ created_at อยู่ใน ~70 นาทีล่าสุด (กันปลุกซ้ำของเก่า)

**3. ปลุกเฉพาะห้องที่ (มีจดหมายค้าง ∧ มี session รันอยู่)** — `mcp__ccd_session_mgmt__send_message(sessionId, "📬 มีข้อความใหม่ในห้อง {room} ที่ command center — อ่าน session_messages room={room} แล้วตอบกลับลงบอร์ด")`
- ห้องมีจดหมายแต่ไม่มี session เปิด → **ข้าม** (session-start จะเก็บให้ตอนห้องนั้นเปิดเอง)
- **ห้ามปลุก `cc`** (นั่นคือหน้าจอนัท/hub) · ห้ามปลุกห้องเดิมซ้ำในรอบเดียว

**4. สรุป 1 บรรทัด** — ปลุกห้องไหนไปบ้าง / ห้องไหนมีจดหมายแต่ปิดอยู่ → ถ้ารันเป็น `/loop` จะวนรอบใหม่ใน 1 ชม.

## กติกา
- บุรุษไปรษณีย์ **แค่ปลุก** ไม่ตอบแทนห้อง (ห้องตอบเอง — ดู inbox protocol ใน `under360-session-start` ข้อ 4)
- ปรับความถี่ได้ที่ `/loop` (เริ่ม 1 ชม. · ถี่กว่านี้เปลืองเร็ว · ดูตารางต้นทุนที่นัทเคาะ)
- เรื่องที่ต้องนัทตัดสิน = ห้องยกให้นัท ไม่ตอบกันเอง (เคารพ [[cc-no-auto-coordinate]] — บุรุษไปรษณีย์ = กลไกที่นัท sanction ให้ · ต่างจากการ ping มั่วเอง)

## ⚠️ เทสก่อนใช้จริง (ตอนนัทออนไลน์)
1. นัทเปิด terminal ทุกห้องค้าง + 1 หน้ารัน `/loop 1h /under360-postman`
2. นัท (หรือ CC) โพสต์จดหมายเทส 1 ใบเข้า room ใดห้องหนึ่ง
3. ดูว่าบุรุษไปรษณีย์ปลุกถูกห้อง → ห้องนั้นตื่นมาอ่าน+ตอบลงบอร์ด → จูนความถี่/ข้อความ ping
