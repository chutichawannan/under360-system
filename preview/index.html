🧪 ของรอนัทเทส

หน้านี้รวมของที่ยังไม่ขึ้นใช้จริง — เปิดจากมือถือได้เลย ไม่ต้องหาลิงก์เอง
ของในหน้านี้เป็น สำเนาแยก — กดเล่นได้เต็มที่ ไม่กระทบหน้าที่แอดมิน/ครัวใช้จริง
ถูกใจแล้วบอก “merge เลย” · ไม่ถูกใจบอก “ทิ้ง” ได้ทันที

🎫 กระเป๋าคูปอง — ม็อกอัพ (ยังไม่ใช่ของจริง)

ไม่ต่อฐานข้อมูล กดเล่นได้ทุกปุ่ม ไม่มีอะไรถูกบันทึก · ดูให้จบทั้ง 4 ฉาก
เปิดม็อกอัพคูปอง
  • ① เห็นคูปอง — แถบเหลืองบนสุดของหน้าเมนู "มีคูปองให้เก็บ 4 ใบ"
  • ② กระเป๋า — 3 แท็บ: ใช้ได้ / ยังไม่เก็บ / ใช้แล้ว · กดปุ่ม "＋ เก็บคูปอง" ดูได้
  • ③ ตอนจ่ายเงิน — เลือกคูปองแล้วยอดเปลี่ยนสด · ใบที่ใช้ไม่ได้จะจางพร้อมบอกเหตุผล (ลองใบ NEW200 ที่ยอดไม่ถึง)
  • ④ เก็บจากบรอดแคสต์ — กดปุ่มในแชท LINE แล้วเข้ากระเป๋าเลย ไม่ต้องพิมพ์โค้ด
  • ท้ายหน้ามี 3 คำถามที่ต้องนัทเคาะ ก่อนผมลงมือทำของจริง

🔍 หน้าครัว — ช่องค้นหาในแท็บ “รายสินค้า”

สำเนาหน้าครัว — ข้อมูลจริง · ค้นหาเป็นการอ่านอย่างเดียว แต่ปุ่มอื่นในหน้ายังกดโดนของจริงได้ ระวัง
เปิดหน้าครัว (ตัวอย่าง)
  • วิธีดู: แท็บ 📋 รายสินค้า → มีช่องค้นหาอยู่บนสุด → พิมพ์ BJ1
  • ค้นได้ทั้ง รหัส (BJ1) · ชื่อเมนู (บ๊ะจ่าง) · ชื่อเล่น (S1 / D4)
  • ถ้าวันที่ดูอยู่ไม่มีใครสั่งเมนูนั้น จะไม่ขึ้นแค่ว่า “ไม่เจอ” แต่บอกว่า เมนูมีในระบบ แต่วันนี้ไม่มีออเดอร์ พร้อมยอดคงเหลือ
  • ช่วยดูให้หน่อย: พิมพ์แล้วคีย์บอร์ดเด้งปิดไหม · ลบข้อความแล้วรายการกลับมาครบไหม

📱 หน้าครัว — แก้ให้ใช้บน iPhone ได้ (N-62)

สำเนาหน้าครัว — ข้อมูลจริง ปุ่มกดสถานะใช้งานได้จริง ระวังกดโดน
เปิดหน้าครัว (ตัวอย่าง)
  • ชื่อเมนูแตกทีละตัวอักษร — ต้นเหตุคือ “โหมดแท็บเล็ต” ติดค้างบนจอมือถือ (วัดจริง: ช่องชื่อเมนูเหลือกว้าง 0px สูง 475px) → ตอนนี้จอแคบกว่า 700px จะไม่ใส่โหมดแท็บเล็ต (ค่ายังจำไว้ เปิดบนแท็บเล็ตจริงยังใหญ่เหมือนเดิม)
  • ปุ่มล้น 3 แถว — หัว + แถบกรองเคยกินที่ 344px จาก 812px (42% ของจอ) → เปลี่ยนเป็นแถวเดียว ปัดนิ้วซ้าย-ขวา ปุ่มยังอยู่ครบทุกตัว
  • ตารางรายสินค้าบีบคอลัมน์ตัวเลข คืนความกว้างให้ชื่อเมนู
  • แถมแก้บั๊กที่เจอระหว่างทาง: โน้ตลูกค้า (ตัวแดง) ไม่เคยโชว์เลยทั้งหน้า และ แถบ ❄️ ของแช่ตู้ไม่มีสีพื้น — ทั้งคู่เกิดจากคอมเมนต์ใน CSS กินโค้ดไป โดยไม่มีอะไรฟ้อง
  • ช่วยดูให้หน่อย: ชื่อเมนูอ่านออกเป็นคำไหม · ปัดปุ่มบนหัวแล้วครบไหม · เห็นออเดอร์ได้เลยโดยไม่ต้องเลื่อนผ่านปุ่มไหม

🥗 ลูกค้ากรอกเองว่า “แพ้อะไร / ไม่ทานอะไร”

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้ · เทสจากมือถือได้เลย
เปิดหน้าลูกค้า (ตัวอย่าง)
  • วิธีดู: กดการ์ด Meal Plan → เลือกแบบ + ชุด → ใส่ตะกร้า → ในหน้าตะกร้าจะมีกล่องสีแดง “⚠️ แพ้อาหารอะไรไหม”
  • ช่อง แพ้ (แดง เด่น) แยกจากช่อง ไม่ทาน/ไม่ชอบ (ธรรมดา) — คนละความรุนแรง
  • พิมพ์เป็นข้อความอิสระได้เลย ไม่มีตัวเลือกตายตัว · ไม่บังคับกรอก
  • กรอกแล้วเด้งบันทึกทันที · เปิดใหม่ครั้งหน้าค่าเดิมขึ้นให้แก้ ไม่ต้องกรอกซ้ำ
  • หน้ายืนยันออเดอร์จะทวนของแพ้ให้เห็นอีกรอบก่อนกดส่ง
  • แอดมินเห็น/แก้ได้ที่ OH → ลูกค้า → 🥗 ข้อจำกัดอาหาร (ที่เดียวกัน)
  • โชว์เฉพาะตอนตะกร้ามี Meal Plan — สั่งข้าวกล่องปกติไม่ต้องเจอคำถามนี้

🛑 เซ็ต/คอร์ส เช็คสต็อกแล้ว

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้ · ด่วน: กระทบลูกค้าจริงแล้ว 12 ส.ค. 4 ใบ
เปิดหน้าลูกค้า (ตัวอย่าง)
  • ปัญหาเดิม: เซ็ต/คอร์สไม่เคยเช็คสต็อกเลยสักบรรทัด — เมนูเหลือ 1 ลูกค้าใส่ในเซ็ตได้ 5 ระบบไม่ค้าน
  • เมนูที่ หมดแล้ว จะเทาและกดไม่ได้ (ไม่ซ่อน — ลูกค้าจะได้รู้ว่ามีเมนูนี้ แค่วันนี้หมด)
  • เมนูเหลือ ≤5 กล่อง บอกจำนวนไว้เลย · ปุ่ม + ดับเองเมื่อเลือกครบตามของที่มีจริง
  • นับรวมทั้ง ของในตะกร้า และ ของที่กำลังเลือกค้างในเซ็ต — กดทีละชิ้นจนเกินไม่ได้
  • มีด่านสุดท้ายก่อนเข้าตะกร้าอีกชั้น เผื่อสต็อกเปลี่ยนระหว่างที่ลูกค้าเลือกอยู่
  • วิธีเทส: กดการ์ดเซ็ต (เช่น Diet Set A) → เลือกเมนู → ลองกดตัวที่ขึ้น “หมดแล้ววันนี้”

🏷️ ระบบเซล (ลดราคา) + บ่อเซล

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้
เปิดหน้าลูกค้า (ตัวอย่าง)
  • เมนูที่อยู่ใน “บ่อเซล” จะขึ้นป้าย -N% + ราคาเดิมขีดทับ + ราคาใหม่
  • ราคาในตะกร้า/ยอดรวม = ราคาที่ลดแล้ว
  • ตั้งบ่อเซลที่ หน้า DB → แท็บ 🏷️ บ่อเซล (สร้างบ่อ · ตั้ง % · โยนเมนูลงบ่อ)
  • เอาเมนูออกจากบ่อ = กลับราคาเดิมทันที ไม่ต้อง deploy
  • แพค Clearance -30% (เลือกอย่างน้อย 5 อย่าง) สร้างไว้แล้วแต่ ยังปิดอยู่ — ลูกค้ายังไม่เห็น

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้ · ของจริงยังไม่เปลี่ยน

  • สิ่งที่อยากให้ช่วยดูที่สุด คือ HP/LC ต้องเหมือนเดิมทุกอย่าง — ราคา 4,190 / 3,190 / 15,900 / 12,000 · วันส่ง จ/พ/ศ · ตัดยอด 8:30

  • 🔌 สวิตช์ปิดอยู่ที่ DB ไม่ใช่ในโค้ด — ถ้าไม่เอาแล้ว ปิด 2 แถวใน mp_offer_sets ตัวเลือก Hyrox หายทันที ไม่ต้องแก้โค้ด ไม่ต้อง deploy
  • ⚠️ ยังไม่ได้กดสั่งจริงจนสุดสาย (ครัว / แพลนเมนู / แมส) — จะเทสให้ครบหลังนัทเคาะหน้าตาก่อน

💳 ชำระเงิน — รวมเป็นปลายทางเดียว

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้
เปิดหน้าลูกค้า (ตัวอย่าง)
  • เดิม: บังคับเลือกก่อนว่า QR หรือโอนเงิน ทั้งที่เงินเข้าบัญชีเดียวกันทั้งคู่
  • 🔴 ที่แย่กว่า: ช่องแนบสลิปอยู่ในกล่อง "โอนเงิน" เท่านั้น → ลูกค้าที่เลือก QR 94 ใบใน ส.ค. ไม่มีที่แนบสลิปเลย
  • ตอนนี้: เห็น QR + เลขบัญชี + ช่องแนบสลิป รวดเดียว ไม่ต้องเลือกอะไรก่อน
  • วิธีเทส: ใส่ของลงตะกร้า → ไปหน้าตะกร้า → เลื่อนดูหัวข้อ "ชำระเงิน"

📌 เซ็ตที่ล็อกวันส่งตายตัว + เก็บสถิติหน้าสั่ง

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้
เปิดหน้าลูกค้า (ตัวอย่าง)
  • ปัญหาเดิม: แอดมินตั้ง "วันส่งตายตัว" ของเซ็ตได้ตั้งแต่ 8 ส.ค. แต่ฝั่งลูกค้าไม่เคยอ่านค่านี้เลย → ตั้งไว้แล้วลูกค้ายังเลือกวันไหนก็ได้
  • ตอนนี้: ตะกร้ามีเซ็ตที่ล็อกวัน → โชว์วันเดียว เลือกวันอื่นไม่ได้
  • ถ้าวันที่ล็อกไว้ผ่านไปแล้ว → ขึ้น "เซ็ตนี้ปิดรับแล้ว" และสั่งไม่ได้
  • มีด่านกันซ้ำตอนกดยืนยันอีกชั้น (กันค่าที่ค้างจากก่อนใส่เซ็ต)
  • + เก็บสถิติหน้าสั่ง: รู้ว่าลูกค้าไปตกหล่นตรงไหน (เมนู → ตะกร้า → ยืนยัน → สำเร็จ) · ไม่เก็บชื่อ เบอร์ ที่อยู่ หรือ LINE ID

🏷️ ป้ายสัปดาห์ในหน้าเลือกเมนูของเซ็ต/คอร์ส

หน้าลูกค้า — สำเนาเทส กดสั่งจริงไม่ได้ · สีป้ายในหน้าเมนูหลักขึ้นใช้จริงไปแล้ว ตัวที่รอเทสคือหน้าเลือกเมนูในเซ็ต
เปิดหน้าลูกค้า (ตัวอย่าง)
  • ปัญหาเดิม: ตอนนี้ขายของ 2 รอบพร้อมกันจริง (10-16 ส.ค. 13 เมนู · 17-23 ส.ค. 13 เมนู) แต่ป้ายเป็นสีเหลืองเหมือนกันทั้งคู่ — นัทเห็นเองแล้วสั่งแก้
  • ตอนนี้ 3 สี: 🔵 สัปดาห์หน้า 17-23 Aug (ฟ้า) · ⭐ เมนูพิเศษ 10-16 Aug (เหลือง) · ⬜ เมนูพิเศษ 3-9 Aug (เทา)
  • คำในป้ายรอบหน้าเปลี่ยนเป็น “สัปดาห์หน้า” ไม่ใช่ “เมนูพิเศษ” — อ่านออกโดยไม่ต้องดูสี
  • ของใหม่ที่รอเทสตรงนี้: หน้าเลือกเมนูในเซ็ต/คอร์ส เดิมไม่มีป้ายสัปดาห์เลย และไม่เรียงรอบ → ตอนนี้ติดป้ายเหมือนหน้าเมนูหลัก + เรียง รอบนี้ → รอบหน้า → รอบก่อน → เมนูประจำ
  • วิธีเทส: กดการ์ดเซ็ต (เช่น Diet Set A) → ดูรายชื่อเมนู ควรเห็นป้ายสีใต้ชื่อเมนู และของรอบนี้ลอยขึ้นบนสุด
  • พอถึงวันจันทร์ป้ายเลื่อนสถานะเอง ไม่ต้องมีใครไปไล่แก้
