# แท็กสัปดาห์เมนูพิเศษ — ดึงจากชีทของนัทโดยตรง

> **นัทสั่งเอง 7 ส.ค. 2569:** *"ต่อไปนี้ยึดจากชีทนี้เป็นหลักเพราะฉันทำเอง ดูไล่จากสัปดาห์ล่าสุดก่อนเป็นหลัก แล้วค่อยๆ ย้อนขึ้น"*

## 🎓 บทเรียน — ห้ามเดาสัปดาห์จากยอดขาย
รอบแรกผมอนุมานสัปดาห์จาก "เมนูนี้เริ่มขายสัปดาห์ไหน" → **ผิด**
ของค้างขายยาวข้ามหลายสัปดาห์ พอเจอยอดเก่าก็ลากย้อนไปไกลเกินจริง
(`D105` กลายเป็น "4-10 May" ทั้งที่เป็นของ **27 ก.ค.–2 ส.ค.** — นัทจับได้เอง)
→ **ตารางหมุนเมนูเป็นสิ่งที่เจ้าของกำหนด ยอดขายบอกไม่ได้ ต้องอ่านจากชีทเท่านั้น**

```bash

node scripts/menu/tag_weeks_from_sheet.cjs <โฟลเดอร์เดียวกัน>       # → เขียน kitchen_data.menu_special_weeks
```

## กติกา
- เอาเฉพาะแถวที่มีเลขช่อง **S1–S8 / D1–D5** (แถวไม่มีเลข = เมนูสำรอง ยังไม่ยืนยันว่านับด้วยไหม)
- เมนูโผล่หลายสัปดาห์ → **ยึดสัปดาห์ล่าสุด**
- `ALIAS` ในสคริปต์ = ชีทเรียกจานเดียวกันคนละรหัสกับ DB (ตอนนี้มี `D200 → A18`)
- แท็กเก็บใน `kitchen_data` คีย์ `menu_special_weeks` = `{"S103":"2026-08-03"}` (วันจันทร์ต้นสัปดาห์)
