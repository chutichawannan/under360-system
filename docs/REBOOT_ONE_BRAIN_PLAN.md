# 🔁 รื้อวิธีทำงาน — "สมองเดียว สองเครื่อง" (นัทเริ่ม 25 ก.ย. 2569)

> **สถานะ: นัทเคาะทิศทางแล้ว · รายละเอียดข้อที่ติดป้าย 🟡 = เลขาเสนอ ยังไม่เคยคุยกัน**
> ทำทีละห้อง เริ่มจากห้องเลขา · ห้องไหนย้ายแล้วให้ติ๊กในตารางท้ายไฟล์

---

## 1. ทำไมต้องรื้อ (คำนัท สรุปจากที่เล่า 25 ก.ย.)

- สร้าง session เยอะ · แต่ละห้องรับสารไม่ตรงกัน · ไม่มีตัวกลาง · คุยกันเองเยอะ · ทำงานซ้อนกัน → **คนที่ overload กลายเป็นนัทเอง**
- อยากได้ full automation เลยเปิด **Claude pc** (คอมออฟฟิศ) 24 ชม. แต่หลายครั้งไม่สำเร็จ · การ setup และแก้ระบบทำให้ท้อ
- ทำงานจาก **Nut pc** (ห้องนอน) ก็ยังต้อง Chrome Remote Desktop ลงไปคุม Claude pc ตลอด · ไฟล์ที่ Claude ส่งมาไม่ค่อยขึ้นฝั่งรีโมท · บางเรื่องต้องวิ่งไปเปิดคอม
- **เป้า: ทำงานแล้วไม่มี friction = นัทไม่หมดไฟ**

## 2. ทิศทางที่นัทเคาะ

1. **ลดการรีโมท · ทำงานผ่าน Claude Code ตรงให้มากขึ้น**
2. **MacBook เครื่องใหม่ = โต๊ะทำงานหลักของนัท** · ลง Claude Code บน Mac
3. **Claude pc กับ Mac ใช้ git ตัวเดียวกัน** + กติกาเดียวกัน → ทำงานเหมือนสมองเดียว
4. **ยุบหลาย session ให้เหลือน้อยที่สุด** เพื่อลด friction · ทำทีละห้อง เริ่มจากห้องเลขา
5. ช่วงนี้ **ลดงานใหม่ลง** มาจัดการเรื่องนี้ให้เรียบร้อยก่อน

## 3. ช่องโหว่ที่ต้องปิดก่อน ไม่งั้น "สมองเดียว" ไม่เกิดจริง

🔴 **ความจำของ Claude ไม่ได้อยู่ใน git** — อยู่ที่ `~/.claude/projects/<พาธโปรเจค>/memory/` บนเครื่องใครเครื่องมัน
→ เปิด Claude Code บน Mac = **ความจำว่างเปล่า** (พาธโปรเจคบน Mac คนละชื่อ) · 123 ไฟล์ของห้องเลขาไม่ตามไปด้วย
→ ของอื่นที่ติดเครื่องแบบเดียวกัน: skill ส่วนตัวใน `~/.claude/skills/` (grill-me · poller · pollerall · skip-turn · tested-source) · กฎส่วนตัว `~/.claude/CLAUDE.md` · โต๊ะเลขา `~/.claude/SECRETARY.md` · `~/.claude/PORTFOLIO.md` · `nut_personal_profile.md`
→ scheduled tasks ก็ติดเครื่อง (ตั้งบน Claude pc = รันบน Claude pc เท่านั้น)

## 4. ข้อเสนอของเลขา 🟡 (ยังไม่เคยคุยกัน — รอนัทเคาะทีละข้อ)

**ก. แบ่งบทบาทเครื่องให้ชัด**
- **Mac = โต๊ะ** · นัทคุยงาน สั่งงาน เปิดหน้าเว็บ ล็อกอินที่ต้องล็อกอิน (Claude in Chrome บน Mac ได้เลย ไม่ต้องรีโมท)
- **Claude pc = เซิร์ฟเวอร์** · รันเฉพาะงานอัตโนมัติ (กะปัน · ตัวเฝ้า · งานตามเวลา) · **ไม่ใช่ที่คุยงาน** · ถ้าไม่ต้องแก้ ไม่ต้องรีโมทเข้าไปเลย

**ข. ย้าย "สมอง" เข้าที่ที่ทั้งสองเครื่องเห็น**
- ความจำเรื่องงาน + skill ส่วนกลาง → **เข้า repo** (เช่น `.claude/memory/` หรือรวบเป็นกฎเข้า `CLAUDE.md` ของโปรเจค) · เครื่องไหนเปิดก็อ่านชุดเดียวกัน
- ⛔ เรื่องส่วนตัว/ครอบครัว/การเงิน **ห้ามเข้า repo นี้** (ขึ้น GitHub) → ทางเลือก: repo ส่วนตัวแยกอีกอัน (private) หรือเก็บไว้เครื่องเดียว

**ค. กติกาสองเครื่องห้ามชนกัน**
- เริ่มงาน = `git pull` ก่อนทุกครั้ง · จบงาน = commit + push ทันที ไม่ค้างไว้ในเครื่อง
- งานโค้ดทำใน worktree/branch แยกเสมอ (กติกาเดิมยังใช้)
- **ห้ามสองเครื่องแก้ไฟล์เดียวกันพร้อมกัน** — ถ้าเครื่องไหนกำลังทำ ให้จองใน `work_claims` แบบที่มีอยู่แล้ว

**ง. ยุบห้อง**
- เหลือ **ห้องหลักห้องเดียวที่นัทคุย** (บน Mac) · ห้องอื่นกลายเป็น "งานเฉพาะกิจ" เปิด-ทำ-ปิด ไม่ค้างถาวร
- ห้องที่ต้องค้างถาวรจริงมีแค่ตัวที่รอฟังคนนอก เช่น **กะปัน/การุน** (รอไลน์) → อยู่บน Claude pc
- ห้องห้ามคุยกันเอง (กฎ 22 ก.ย. ยังใช้) · ห้องหลักคือตัวกลางคนเดียว

**จ. ลำดับย้าย (ทีละห้อง)**
1. ห้องเลขา → เขียนใบส่งต่อ (ทำแล้ว `docs/HANDOFF_SECRETARY_20260925.md`) → ย้ายความจำเข้า repo → เปิดบน Mac → ทดสอบว่าจำได้จริง
2. ห้องอื่นทีละห้อง: เขียนใบส่งต่อ → รวมเข้าห้องหลัก หรือปิด
3. ย้าย scheduled tasks ที่จำเป็นไปรันบน Claude pc ที่เดียว · ที่ไม่จำเป็นปิดทิ้ง
