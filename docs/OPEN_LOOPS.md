กำแพงห้ามปนตะกร้าถูกลบแล้ว (`e62f08c`) แต่ตะกร้าที่ปนของพรีออเดอร์ **วันส่งยังถูกดันไปวันช้าสุดทั้งใบ** — ถูกสำหรับครัว แต่ลูกค้าที่อยากได้ของปกติพรุ่งนี้อาจไม่คาดคิด · มีป้ายบอก 2 จุด **ยังไม่รู้ว่าลูกค้าจริงอ่านทัน** · 2 ทางที่นัทเคาะได้: (ก) ปล่อยแบบนี้ (ข) แยกกล่อง "ส่งได้เลย / ส่งวันที่ X" ในตะกร้า

### ⚠️ ข้อจำกัดของห้องนี้ที่นัทควรรู้ (ย้ายมาทั้งดุ้น ห้ามหล่น)
1. **U เทสสั่งออเดอร์จริงไม่ได้** — กลัวขยะไปโผล่หน้าครัวแล้วครัวทำอาหารทิ้ง (เคยเกิดจริง 11 ใบ) → ดักการเขียนแล้วเทสแทน = พิสูจน์ได้ ~80% **ที่เหลือตกเป็นภาระนัท**
2. **Vercel ปิด Preview Deployment อยู่** → กฎ "ทำ branch แล้วส่งลิงก์ให้นัทเทส" ทำตามไม่ได้จริง
