# 🧵 เรื่องที่ยังไม่จบ (Open Loops)

> **นัทออกแบบเอง 11 ส.ค. 2026** — เกิดจากปัญหาจริง: นัทอ่านที่ Claude พิมพ์ นึกเรื่องใหม่ได้ เลยเปลี่ยนเรื่อง
> แล้ว**ทั้งเรื่องเดิมและเรื่องที่เพิ่งนึกได้ หายไปทั้งคู่**
>
> **ไฟล์นี้คือที่เดียวที่ "เรื่องค้าง" อยู่รอดข้าม session** — ในหัว Claude ไม่รอด (context เต็ม/ปิดห้อง = หาย)
>
> **กติกา:** ทุกครั้งที่นัทพูดว่า *skip turn / ข้าม / เดี๋ยวกลับมา* → **เขียนลงที่นี่ก่อนทำเรื่องใหม่**
> ทุกครั้งที่ Claude ถามแล้วนัทไม่ได้ตอบ → **เขียนลงที่นี่ด้วย** (ไม่ใช่ถามซ้ำจนน่ารำคาญ)
> ปิดเรื่องแล้ว → ย้ายลงท้ายไฟล์ในหมวด "ปิดแล้ว" พร้อมวันที่ **ห้ามลบทิ้ง** (จะได้รู้ว่าเคยเคาะว่าอะไร)
