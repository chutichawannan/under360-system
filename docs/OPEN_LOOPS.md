3. **ชีทมีลแพลนของพลอย = จุดเดียวที่พังได้ทั้งก้อน** — 1,767 แถว 10 เดือน ไม่เคยเข้าระบบ · ระบบเรามีแค่ 100 แถว เริ่ม 5 ส.ค. → **จะ import ไหม (~ครึ่งวัน)**

5. **ระบบล็อกหลังบ้าน** — `app.360foodbox.com` + 3 ชั้น (เปิด / PIN ทีม / Gmail ส่วนตัว) · **ตอนนี้หน้าครัว-แอดมินไม่มีล็อกอะไรเลย** · เสนอทำ P2 (PIN) ก่อน
6. **`1A` ตั้งสต็อกค้างไว้ที่ 5** (ของจริง ∞) — เหลือจากการเทส รอนัทบอกให้คืน
