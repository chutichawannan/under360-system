## 1️⃣ ทำไมถึงทำ

**นัทนึกขึ้นได้เอง 20 ส.ค.** ระหว่างสั่งให้ทำปฏิทินเทศกาล:
> *"ช่วงนี้ใกล้สารทจีน **ก็ต้องเตรียมเมนูสารทจีน และฉันก็ไม่รู้ว่ามันเป็นวันไหนด้วย**"*

**= ไม่มีใครวางแผนไว้ล่วงหน้าเลย** เพิ่งนึกได้ตอนเหลือ **6 วัน**
→ กลายเป็นจุดกำเนิดของ [`docs/EVENT_CALENDAR.md`](../EVENT_CALENDAR.md) (ปฏิทินเทศกาลทั้งปี) ไปในตัว

## 2️⃣ ตัดสินใจอะไรบ้าง — **ส่วนที่มีค่าที่สุดของใบนี้**

### 🔑 ① เหลือ 6 วัน → **"เกาะรอบที่มีอยู่" แทนสร้างรอบใหม่** ← นัทคิดเอง
PM บอกว่า *"เมนูใหม่ไม่ทัน"* เกือบจะข้ามทั้งเทศกาล
**นัทแก้ให้:** ไม่ต้องสร้างรอบใหม่ — **เปลี่ยนธีมของรอบ S1-S8 ที่จะทำอยู่แล้ว**

```
ต้นทุนเพิ่ม     0
งานครัวเพิ่ม    0
สิ่งที่เปลี่ยน   แค่ "เลือกเมนูไหนลงช่อง S1-S8"
```
→ **กลายเป็นกฎถาวรของร้าน** อยู่ใน `EVENT_CALENDAR.md` แล้ว:
*เหลือ >4 สัปดาห์ = ทำใหม่ได้ · 1-4 สัปดาห์ = เกาะรอบ · <1 สัปดาห์ = คอนเทนต์อย่างเดียว*

### 🔑 ② **ห้ามมีเมนูคิดใหม่แม้แต่ตัวเดียว**
ทั้ง 8 ตัว = เมนูที่ **เคยทำ เคยขายจริง มียอดใน DB มีรูปครบ 100%**
→ ครัวไม่ต้องลองสูตร · ไม่ต้องถ่ายรูปใหม่ · **ความเสี่ยงเกือบเป็นศูนย์**

### 🔑 ③ **ไม่ใส่โค้ดส่วนลด — ใช้ "เส้นตาย" แทน**
ตัดสินจากผลจริงรอบก่อน ไม่ใช่ความรู้สึก:
- `BDAY08` = **0 ใบ** · `COMEBACK` = **0 ใบ**
- พิสูจน์แล้วว่า **ขั้นต่ำไม่ใช่ตัวขวาง** (79% ของบิลกลุ่มนั้นเคยถึงขั้นต่ำอยู่แล้ว)
- → **ส่วนลดไม่ได้สร้างความอยาก มันแค่ลดราคาให้คนที่ตั้งใจซื้ออยู่แล้ว**
- **สารทจีนมีเส้นตายจริงในตัวเอง (27 ส.ค.)** = แรงผลักที่แรงกว่าส่วนลด **และไม่กินกำไร**

### 🔑 ④ ยิงบรอดแคสต์ **กลุ่ม ~10,000 คนที่ยัง active** ไม่ยิงเต็มฐาน 23,372
**ไม่ใช่เลือกเอง — โควตาบังคับ:** ส่งฟรีเดือนนั้นใช้ไป ~21,228 จาก 35,000 → **เหลือ ~13,772 ยิงเต็มฐานไม่พอ**
*(ตัวเลขเพดานจาก API 135,000 ไม่ตรงกับคอนโซล 35,000 — **ส่วนเกินน่าจะมีค่าใช้จ่าย ยังยืนยันไม่ได้** → เลี่ยงไว้ก่อน)*

### 🔑 ⑤ ตัดของที่เสี่ยงออกเอง
**`BJ4` บ๊ะจ่างไส้จักรพรรดิ (เป๋าฮื้อ/กังป๋วย ฿169)** — ของต้องสั่งพิเศษ เหลือ 6 วัน **ไม่แนะนำ → ตัด**

### 🎨 ⑥ โทน — **ให้เกียรติ ห้ามมุกผี**
เป็นเรื่องไหว้บรรพบุรุษ · ห้ามทำเป็นเทศกาลสนุก · ห้ามเคลม "ดีที่สุด"
**มุมขายที่มีของจริงรองรับ:** >90% ของเมนูโซเดียมต่ำกว่าที่ขายทั่วไป · คุมน้ำมัน ≤5 ก./กล่อง
**ของไหว้ตามธรรมเนียมมัน/ทอด/เค็ม → ไหว้เสร็จต้องกินกันทั้งบ้านอีกหลายวัน** ← ช่องที่คู่แข่งสายคลีนยังไม่มีใครเล่น

## 7️⃣ ปีหน้าทำอะไรต่าง — **สารทจีน 2027**

1. **เริ่มก่อน 4 สัปดาห์** → ทำเมนูใหม่ได้ ไม่ต้องเกาะรอบ *(ปฏิทินจะเตือนเองแล้ว)*
2. **ตัดของเสริมออก หรือมัดเป็นเซ็ต** — ขายเดี่ยวคู่กันแล้ว **ไม่มีใครหยิบ**
3. **ทำ "ชุดโต๊ะไหว้" ขายเป็นชุดเดียว** — D1-D5 วางเรียงกันคือโต๊ะไหว้ครบชุดอยู่แล้ว **แต่เราขายแยกกัน** → ตะกร้าน่าจะโตกว่านี้อีก
4. **เก็บสูตร 8 ตัวนี้ก่อนถึงเทศกาล** → ฟ้าคำนวณวัตถุดิบให้ได้ ไม่ต้องเดา
5. **เช็คโควตา LINE ตั้งแต่ต้นเดือน**
6. **บอก buyer พร้อมกับบอกครัว** ไม่ใช่ทีหลัง
7. **ถ้าอยากได้ลูกค้าใหม่ ต้องมีตัวอื่นช่วย** — เทศกาลอย่างเดียวทำได้แค่ขยายตะกร้าคนเดิม
