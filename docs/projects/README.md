## ✍️ ใบรายงานต้องมีอะไร — **โครงเดียวกันทุกใบ**

เพื่อให้ **เทียบข้ามปี/ข้ามแคมเปญได้** ห้ามใครเปลี่ยนหัวข้อเอง

```
1. ทำไมถึงทำ           ← ที่มา ใครเสนอ ตัดสินใจบนอะไร
2. ตัดสินใจอะไรบ้าง     ← ทางที่เลือก + ทางที่ไม่เลือก และเหตุผล  ← สำคัญที่สุด
3. ทำอะไรจริง          ← เมนู · ราคา · ภาพ · ข้อความ · ช่วงเวลา
4. ผลลัพธ์             ← ตัวเลขจาก DB จริง เทียบกับช่วงก่อนหน้า
5. อะไรเวิร์ค          ← พร้อมหลักฐาน
6. อะไรไม่เวิร์ค        ← ห้ามข้าม ห้ามแต่งให้ดูดี
7. ปีหน้าทำอะไรต่าง    ← ของที่มีค่าที่สุดในใบนี้
8. ของแนบ             ← ไฟล์ · ภาพ · ลิงก์ · ใครถืออยู่
```

## 🔴 กฎ 4 ข้อ
1. **ตัวเลขต้องมาจาก DB จริง** ระบุ query/ช่วงวันที่ให้ตรวจซ้ำได้ · **ห้ามใช้ตัวเลขที่ Hato รายงาน** (เว่อร์เกินจริง — ดู `CLAUDE.md`)
2. **"กระบวนการคิด" สำคัญกว่า "ผลลัพธ์"** — ผลลัพธ์บอกว่าเกิดอะไร กระบวนการคิดบอกว่า **ปีหน้าควรทำยังไง**
3. **อะไรไม่เวิร์คต้องเขียน** — ใบที่มีแต่เรื่องดี = ใบที่ใช้ไม่ได้
4. **เขียนตอนจบทันที ห้ามรอ** — รอ 2 สัปดาห์แล้วจะจำไม่ได้ว่าตอนนั้นคิดอะไร
