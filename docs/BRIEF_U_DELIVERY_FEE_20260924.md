## กติกาใหม่ที่นัทเคาะ

| เงื่อนไขตะกร้า | ค่าส่ง |
|---|---|
| ของแยก (ไม่ใช่เซ็ต) รวม **≥ ฿500** | **ฟรี** |
| ของแยก รวม **< ฿500** | คิดตามระยะจริง (เรทเดิม) |
| **เซ็ตทดลอง / เซ็ตเริ่มต้น** | **฿30 เหมาจ่าย** |
| เซ็ตใหญ่ที่ติ๊ก `free_shipping` · Meal Plan ทุกแพ็ค | ฟรี (เหมือนเดิม) |

**ข้อยกเว้นที่นัทระบุเอง**
1. ลูกค้าที่มีโค้ด/คูปอง **FREESHIP** หรือสิทธิ์ส่งฟรี → **ฟรี** (โค้ดชนะกติกา ฿30)
2. ถ้าค่าส่งตามระยะจริง **ถูกกว่า ฿30** → **คิดตามจริง** (฿30 คือเพดานของเซ็ตเริ่มต้น ไม่ใช่ราคาตายตัว)
3. "เพื่อนนัท" → ฟรีเหมือนเดิม

## จุดที่ต้องแก้ในโค้ด (`liff_customer.html`)
1. `cartFreeShipping()` (~บรรทัด 4877-4883) — ตอนนี้คืน true ถ้ามี Meal Plan หรือแพคที่ติ๊ก `free_shipping`
   → เพิ่มชั้น: ของแยกรวม ≥฿500 = ฟรี
2. เพิ่มแนวคิด **"ค่าส่งเหมาของเซ็ต"** — เสนอเก็บเป็นคอลัมน์ใหม่ `packages.flat_shipping_fee` (int, null = ใช้กติกาปกติ)
   → ตั้ง 30 ให้เซ็ตทดลอง/เริ่มต้น · ค่าส่งสุดท้าย = `Math.min(flat_shipping_fee, calcDeliveryFee(km))`
3. หน้า DB (`main_database_v2.html` แท็บแพคเกจ) — เพิ่มช่องกรอกค่าส่งเหมาต่อแพคเกจ
4. ข้อความหน้า checkout: ถ้าเป็นเซ็ตเหมา ให้ขึ้นว่า **"ค่าส่ง ฿30"** ไม่ใช่ "ส่งฟรี"

## SQL ที่ต้องรัน
```sql
ALTER TABLE packages ADD COLUMN IF NOT EXISTS flat_shipping_fee INT;
```
