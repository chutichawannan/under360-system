# 🔢 เทียบเมนู Hyrox กับแคตตาล็อก LC/HP — หาที่ต้องเติมเลขใหม่

> **โจทย์นัท (7 ส.ค.):** Hyrox จะรวมเข้าระบบ MP{เลข} ทุกรายการ · เอาเลขมากางเทียบ → อันไหนซ้ำ (ใช้เลขเดิม) · อันไหนใหม่ (เติมเลขใหม่)
> **แหล่ง:** แคตตาล็อก LC01–83 (ชีท Meal Plan tab) · Hyrox 25 เมนู (ชีท Hyrox tab col 9–33)
> ⚠️ **จับคู่จาก "ชื่อเมนู" เท่านั้น** (ยังไม่เทียบสูตรจริง) — กลุ่ม 🟡 คล้าย ต้องให้ครัว/นัทดูสูตรจริงก่อนเคาะ

## 📊 สรุปเลขที่ต้องเติม

- 🟢 **ใช้เลขเดิม 2** (แซลมอนเพสโต้=20 · กุ้งพริกขี้หนู=64)
- 🔴 **เติมเลขใหม่แน่ๆ 13** → ถ้าต่อจาก 83 = **MP84–96**
- 🟡 **รอนัทเคาะ 10** → ถ้าเคาะว่า "ใหม่หมด" = อีก 10 เลข (MP97–106) · ถ้า "ใช้เลขเดิม+ปีกย่อย" (เช่น 39a/48b) = ไม่กินเลขใหม่

**ปมที่ต้องตัดสิน:** กลุ่ม 🟡 = "เมนูเดียวกันเปลี่ยนซอส" นับเป็นเมนูใหม่ หรือเป็นเวอร์ชันของเลขเดิม? → กระทบว่าจะมีเลขทั้งหมดกี่ตัว (95 หรือ 106) · แนะนำ: ถ้าซอส/โปรตีนต่างจนลูกค้ามองเป็นคนละเมนู = เลขใหม่ · ถ้าแค่สลับเครื่องเคียง = เลขเดิม
