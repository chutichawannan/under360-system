# 📚 คลังประวัติแอด Under360 (Ads History Library)

> **นัทสั่งเอง 27 ส.ค. 2026:** *"ทุกชุดแอดที่ยิงไป ทำ history library ไว้ด้วยนะ เราจะได้มาดูงานวิเคราะห์ย้อนหลังกันได้"*

## ทำไมต้องมี
รอบ ก.ค. 2026 เผา ฿1,047 แล้ว **ไม่เหลือบันทึกว่าใช้รูปไหน ข้อความอะไร ยิงกลุ่มไหน** → วิเคราะห์ย้อนหลังไม่ได้เลย ได้แต่ความรู้สึก
คลังนี้แก้เรื่องนั้น — **ทุกแคมเปญที่ยิงจริงต้องมี 1 ไฟล์ที่นี่ ไม่มีข้อยกเว้น**

## กติกา
| | |
|---|---|
| **ชื่อไฟล์** | `YYYY-MM-DD_ชื่อแคมเปญ.md` (เช่น `2026-08-27_fb-pack-aug.md`) |
| **สร้างเมื่อไหร่** | ตอน**กด Publish** ไม่ใช่ตอนคิดแผน (แผนที่ไม่ได้ยิง = ไม่ต้องมีไฟล์) |
| **อัปเดตเมื่อไหร่** | ทุกครั้งที่ตัวเฝ้าแอดเจอของใหม่ + **ตอนปิดแคมเปญต้องสรุปผลปิดท้ายเสมอ** |
| **ห้ามลบ** | แคมเปญที่แป้กมีค่าเท่ากับแคมเปญที่สำเร็จ — **ของที่ไม่เวิร์คคือข้อมูลว่าอย่าทำซ้ำ** |
| **รูปที่ใช้จริง** | ก๊อปไฟล์ `.png` มาไว้ในโฟลเดอร์นี้ด้วย (ไฟล์ใน `.scratch/` หายได้) |

## สิ่งที่ทุกไฟล์ต้องมี (ห้ามขาด)
1. **ตั้งค่าที่ใช้จริง** — เป้าหมาย · กลุ่มเป้าหมาย · งบ/วัน · วันเริ่ม-จบ · ตำแหน่งโฆษณา
2. **ครีเอทีฟ** — ชื่อไฟล์รูป + ข้อความเต็ม (primary text / headline / CTA)
3. **ลิงก์ปลายทาง + ป้าย UTM เต็ม** ← ตัวนี้คือกุญแจเชื่อมกับยอดขายจริงใน `orders.source_campaign`
4. **โค้ดส่วนลดที่ผูก** + เงื่อนไข
5. **ตัวเลขรายวัน** — เงินที่ใช้ · คลิก · ต้นทุน/คลิก · ออเดอร์ · ยอดขาย
6. **สรุปตอนปิด** — คุ้มไหม · **ได้เรียนรู้อะไร** · รอบหน้าทำอะไรต่าง

## วิธีดูย้อนหลังว่าแคมเปญไหนทำเงินจริง
```
orders?select=order_number,total,source_campaign&source_campaign=like.fb/paid*
```
ค่า `source_campaign` ในใบสั่งซื้อ = ป้าย UTM ในไฟล์นี้ → **จับคู่กันได้ตรงๆ เป็นบาท**
