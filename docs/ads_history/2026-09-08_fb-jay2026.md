## 🧱 ด่านที่ต้องผ่านกว่าจะสร้างได้ (8 ก.ย. ใช้เวลาทั้งเช้า — จดไว้กันเสียเวลาซ้ำ)
1. **System User ไม่มีสิทธิ์ "จัดการแคมเปญ"** บนบัญชีโฆษณา → เปิดที่ การตั้งค่าธุรกิจ → ผู้ใช้ระบบ → จัดการ
2. **System User ไม่มีสิทธิ์บนเพจ** → การตั้งค่าธุรกิจ → เพจ → กำหนดผู้คน → เปิด "โฆษณา"
3. 🔑 **"Provide a verified advertiser"** — สร้างชุดโฆษณาใหม่ไม่ได้เลยทั้งบัญชี เพราะยังไม่ยืนยันธุรกิจ
   **ทางอ้อมที่ใช้ได้จริง: ก๊อปชุดที่ Meta อนุมัติแล้ว (`/copies`) แล้วดัดแปลง** — ชุดเก่าพก "ใบอนุญาต" ติดมาด้วย
   ⚠️ ข้อจำกัดของวิธีนี้: objective ต้องตรงกับต้นแบบ · แก้ `start_time` และ **เหตุการณ์คอนเวอร์ชั่นไม่ได้** (นับว่าเริ่มไปแล้ว)
4. **แอปอยู่โหมดพัฒนา** → เติม URL นโยบายความเป็นส่วนตัว แล้วกดเผยแพร่ที่ `developers.facebook.com/apps/<id>/go_live/`
5. **นโยบายไม่เลือกปฏิบัติ** ต้องให้แอดมินธุรกิจกดยอมรับ — **URL ที่ถูกคือของธุรกิจ** `business.facebook.com/certification/nondiscrimination/?business_id=…`
   (`facebook.com/certification/nondiscrimination` ตัวธรรมดา = ของบัญชีส่วนตัว **ปุ่มจะเทากดไม่ได้** เสียเวลาตรงนี้ไปหลายรอบ)
6. **`standard_enhancements` เลิกใช้แล้ว** → ต้องปิด Advantage+ **ทีละฟีเจอร์** (`image_touchups`, `text_optimizations`, …) ไม่งั้น Meta รีมิกซ์รูปพัง

**กับดักอื่น:** API แก้ชุดโฆษณาได้ **1 คำสั่ง/30 วินาที** · หน้าต่าง Chrome ถูกย่อเล็ก (611×273) ทำให้ป๊อปอัพไม่ขึ้นและสกรีนช็อตค้าง — **เปิดแท็บใหม่/ขยายเต็มจอแก้ได้**

## ⚠️ ค้างไว้
- **ยังไม่ยืนยันธุรกิจ** → ยังไม่รู้ว่ากดเปิดแล้วจะส่งถึงคนจริงไหม (ข้อความ Meta พูดถึง "การส่งถึงคนในพื้นที่ที่เลือก")
- อายุชุด A 20-65 vs ชุด B 22-65 (A ติดมาจากต้นแบบ แก้ไม่ได้เพราะ Advantage+ ล็อก) — ต่างเล็กน้อย ไม่ถึงกับเทียบกันไม่ได้
- เหตุการณ์คอนเวอร์ชั่นของทั้ง 2 ชุด = ของต้นแบบเดือน ส.ค. (พิกเซล + custom event `conversion`) แก้ไม่ได้ด้วย API
