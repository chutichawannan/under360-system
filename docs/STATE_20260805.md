## 3. 🪤 กับดักที่ทำให้ "ระบบพร้อม" ไม่เท่ากับ "ใช้งานได้"

**`kitchen_queue.html:582`** → `if(mm.stock_total!=null) patch.stock_total=val;`
**เมนูที่ `stock_total = null` (ไม่จำกัด) ครัวกรอก "ผลิตได้จริง" เท่าไหร่ก็ไม่มีผล** — เลขขายยังคง null = ลูกค้าสั่งไม่ตัดสต็อก (ไม่ใช่บั๊ก แต่ผลข้างเคียงคือเมนูพิเศษหลุดวงจร · S136 = null พอดี)

✅ **วิธีที่ถูก (ไม่ต้องแก้โค้ด):** ① ตั้งเลขในแท็บ **"ตั้งสต็อค"** ก่อน (ครั้งเดียว) → ② ครัวกรอก **"ผลิตได้จริง"** ทุกรอบ → วงจรเดินเอง
📌 `actual_stock` = ผลิต · `stock_total` = ขายได้/เหลือ · **ผลิต − เหลือ = ขาย** ครบวงจรโดยไม่ต้องเพิ่ม field
📊 **ครัวกรอก "ผลิตได้จริง" ไปแล้ว 1/22 เมนู** (A13 · ห้อง 12 verify) — 21/22 ยังไม่มีตัวเลขผลิต = เฝ้า "เหลือ" ไม่ได้

**กฎที่ออกจากแพทเทิร์นนี้ (ทุกห้องใช้):**
1. **output ว่าง ≠ ไม่มีของ** — เช็ค exit code / stderr ก่อนสรุปเสมอ
2. **`.select()` ต้องมี `.limit()` หรือ filter วันที่เสมอ** — ไม่งั้น PostgREST คืนแค่ 1,000 แถวเงียบๆ
3. **ก่อนบอกว่า "ใช้ได้แล้ว" ต้อง query นับแถวจริง** — เครื่องมือพร้อม ≠ มีข้อมูล

2. **commit ทันทีที่ผลิตงานเสร็จ ไม่รอจบ session** · ก๊อปงานสำคัญออกไป scratchpad นอก repo ด้วย
3. **ของหาย → เช็ค `origin/main` ก่อนสรุปว่ากู้ไม่ได้** (ชีทเตียงที่ประกาศว่าหาย = อยู่ครบใน git)
