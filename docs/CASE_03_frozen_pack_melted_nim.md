# 📕 Case 03 — ฟรีซแพ็คค้างขนส่ง 3 วัน ละลายทั้งกล่อง (Nim Express · นครปฐม)

> **6 ส.ค. 2026 · k-track** — ลูกค้าส่งรูป/วิดีโอมาร้องเรียนเอง
> **ระดับ: 🔴 เสียของ 100% + ลูกค้าประจำ + ร้านไม่รู้เรื่องจนลูกค้าทัก**

## ⏱️ ไทม์ไลน์ (จากข้อความลูกค้าโดยตรง — ไม่ได้ตีความเพิ่ม)

| ต่อจากนั้น | ลูกค้าแจ้งให้ส่งใหม่ **5 ส.ค.** + **ขอให้เขียนกำกับว่าส่งช่วงเช้า** |

| | ลูกค้าโทรหาเจ้าหน้าที่ที่มาส่งวันที่ 4 → ตอบว่า **"มาแทนวันเดียว"** และ**ไม่ช่วยประสานงานต่อ** |
| **พฤ. 6 ส.ค.** | ขนส่งเอามาส่ง — **กล่องเละ แฉะมาก อาหารละลายทั้งหมด** |

- **หลักฐาน:** รูป + วิดีโอจากลูกค้า (กล่องยุบ เทปแฉะ น้ำไหลออกจากกล่อง)

## 🔍 สิ่งที่เคสนี้เปิดโปง — ไม่ใช่แค่ "ขนส่งห่วย"

**ของแช่แข็งอยู่ในระบบขนส่ง 3 วัน = ตายแน่นอนตั้งแต่วันที่ 2 แต่ไม่มีใครหยุดมัน**

| # | ช่องโหว่ | ทำไมสำคัญ |
|---|---|---|
| 1 | 🔴 **ร้านไม่รู้เลยว่าของถึงหรือยัง จนลูกค้าทักมา** | ไม่มีการติดตามสถานะพัสดุ ตจว. เลยแม้แต่นิดเดียว — ของอาจตายแล้วอีกกี่กล่องที่เราไม่รู้? |
| 2 | 🔴 **ส่งไม่สำเร็จรอบแรก = สัญญาณอันตรายสูงสุดของของแช่แข็ง แต่ไม่มีใครได้ยินสัญญาณนั้น** | ถ้ารู้ตั้งแต่เย็นวันที่ 4 ยัง**ยกเลิก/ส่งใหม่/แจ้งลูกค้าล่วงหน้า**ได้ · ปล่อยจนวันที่ 6 = ไม่เหลืออะไรให้กู้ |
| 3 | 🔴 **ลูกค้าต้องเป็นคนไล่ตามขนส่งเอง** | ตรงข้ามกับ soul แบรนด์ (*"คนดูแลคน"*) เต็มๆ — ลูกค้าประจำกลายเป็นฝ่ายทำงานแทนเรา |
| 4 | 🟡 ขนส่งไม่โทรแจ้งก่อนเข้า | ต้นเหตุรอบแรก · ของแช่แข็งควรบังคับ "โทรก่อนส่ง" |
| 5 | 🟡 คำขอ "ส่งช่วงเช้า" ที่ลูกค้าขอไว้ ไม่มีผล | คำสั่งพิเศษไม่ถูกส่งต่อ/ไม่ถูกบังคับใช้ |

**🔗 แพทเทิร์นเดียวกับ [CASE_02](CASE_02_supplier_short_delivery.md):** ขาเข้า (Go Wholesale ส่งไม่ครบ) และขาออก (Nim ส่งไม่ถึง) — **ทั้งสองทางเราไม่มีจุดตรวจที่บันทึกได้ว่า "ของถึงจริงไหม"**

## 💸 ผลกระทบ

- **ของเสีย 100%** ทั้งกล่อง — ต้องส่งใหม่หรือคืนเงิน (นัทเคาะ)
- **ลูกค้าประจำ** = มูลค่าตลอดชีพสูง เสียคนเดียวเจ็บกว่าค่ากล่อง
- 🚩 กระทบ positioning โดยตรง: เราชูว่า **"ฟรีซแพ็คทำถูกวิธี ปรุงเสร็จแช่แข็งทันที"** และ **ห้ามดิสอาหารแช่แข็ง** — แต่ประสบการณ์ลูกค้าปลายทางพังที่ขั้นขนส่ง ไม่ใช่ที่ครัว

---

## ❓ ที่ต้องรู้ก่อนแก้เชิงระบบ (รอนัท)

1. **ส่งแบบไหน** — น้ำแข็งแห้ง / กล่องโฟม / เจลเย็น? **ของอยู่ได้จริงกี่ชั่วโมง?**
2. **Nim ให้ tracking number ไหม** และเรามีที่เก็บเลขพัสดุในระบบหรือเปล่า (ตอนนี้ `orders` ไม่มีช่องนี้)
3. **เกิดบ่อยแค่ไหน** — เคสแรก หรือเคยมีแล้วแต่ไม่ได้จด?
4. **ตอนนี้ใครตอบลูกค้าเคสแบบนี้** — พลอย / แอดมิน / นัท?
5. **เคลมกับ Nim ได้ไหม** — มีสัญญา/ประกันของเสียหายหรือเปล่า?
6. **นโยบายชดเชย** — ส่งใหม่ฟรี / คืนเงิน / ให้เลือก?

## 💡 ทางแก้เชิงระบบ (ยังไม่ทำ — รอตอบ 6 ข้อบน)

- **ขั้นต่ำสุดที่ได้ผลทันที:** เก็บ **เลขพัสดุ + วันส่ง** ทุกออเดอร์ ตจว. → ใครสักคน (หรือระบบ) เช็คสถานะ **เย็นวันถัดไป** → ส่งไม่สำเร็จ = **โทรหาลูกค้าก่อนที่ลูกค้าจะโทรมา**
- ต่อยอด: เตือนอัตโนมัติเมื่อพัสดุแช่แข็งค้างเกิน N ชั่วโมง (ของแช่แข็งมี "นาฬิกาตาย" ที่ระบบควรรู้)
- 🔗 ต่อกับ **บอทครัวใน LINE** ได้ตรงๆ: ของถึง/ไม่ถึง แจ้งในกลุ่ม → เก็บลงระบบ → นัทเห็นในหน้าคอนโซล
