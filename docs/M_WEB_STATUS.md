## 🔴 Wix — ยังยกเลิกไม่ได้ (นัทถาม 31 ส.ค. · ตรวจแล้ว)

**คำถาม:** ยกเลิก Wix Premium จะกระทบอะไรไหม
**คำตอบ: กระทบ — เพราะ Wix ยังเป็นคนถือ DNS ของโดเมนอยู่**

```
$ nslookup -type=NS 360foodbox.com
360foodbox.com  nameserver = ns0.wixdns.net
360foodbox.com  nameserver = ns1.wixdns.net
```
เว็บวิ่งบน Vercel แล้วก็จริง (A record = `216.198.79.1`) — **แต่คนที่ชี้ทางให้คือ Wix**
→ ถ้าบัญชี Wix มีปัญหา/หมดอายุ **โดเมนหาทางไป Vercel ไม่เจอ = ดับทั้งเว็บ** ไม่ใช่แค่หน้า Wix เก่าหาย

**ลำดับที่ปลอดภัย (ทำตามนี้เท่านั้น):**
1. ย้าย DNS ออกจาก Wix ก่อน → ชี้ nameserver ไป Vercel (หรือผู้ให้บริการ DNS อื่น)
2. รอ 24–48 ชม. เช็คว่าเว็บ + redirect 23 เส้นยังทำงาน
3. **ค่อยยกเลิก Premium**

⚠️ **โดเมนต่ออายุ 9 ธ.ค. 2026** — คนละเรื่องกับ Premium **ห้ามยกเลิกโดเมนเด็ดขาด**
📌 **นัทสั่ง 31 ส.ค.: ยังไม่ยกเลิก · ให้เตือนก่อนถึงวันต่ออายุ**
