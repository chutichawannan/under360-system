## 🅲 Kidneycare — อาหารผู้ป่วยโรคไต (สปินออฟ) ⭐

> **เอกสารเต็ม: `kidneycarebrief.md` (นัทส่งเข้ามา 9 ส.ค.) · เว็บ `kidneycare.html` เขียนเสร็จแล้ว**

| | |
|---|---|
| รายได้ | **฿10,000-20,000/เดือน · เสถียร** |
| งบการตลาดที่ใช้ | **฿0 — ไม่เคยโปรโมทเลยสักครั้ง** |
| ทีม | พลอย (ครัว) + **คุณอิ๊ง หัวหน้านักโภชนาการโรงพยาบาล (รับจ๊อบ)** + แอดมินชุดเดิม |
| ใช้ทรัพยากรร่วม | ครัวเดียวกัน · แอดมินชุดเดียวกัน · **เพิ่มแค่นักโภชนาการ** |
| สินค้า | แพ็ก 1 สัปดาห์ · 2 หรือ 3 มื้อ/วัน · เลือกจากเมนู 50+ ครัวปรับสูตรตามผลเลือด |

**🏰 ทำไมไลน์นี้พิเศษกว่าทุกไลน์ (มุมมอง pm):**
1. **คู่แข่งลอกไม่ได้** — ต้องมีนักโภชนาการอ่านผลเลือดจริง · คู่แข่ง 42 รายในชีทเรา **ไม่มีใครทำได้สักเจ้า**
2. **ลูกค้าไม่เปรียบเทียบราคา** — เป็นเรื่องสุขภาพ ไม่ใช่เรื่องกินอร่อย
3. **ซื้อซ้ำโดยธรรมชาติ** — โรคไตเป็นโรคเรื้อรัง ไม่ใช่คอร์สลดน้ำหนักที่จบแล้วหาย
4. **โตได้โดยไม่ต้องแย่งลูกค้ากับใคร** — คนละสนามกับสงครามอาหารคลีน

**🔴 คอขวดที่ต้องแก้ก่อนขยาย:**
- **ทุกเคสผ่านมือคุณอิ๊งคนเดียว** → ออเดอร์โตแล้วตันตรงนี้ก่อนแน่นอน
  → ทางแก้ในเอกสาร: ทำ **เทมเพลตตามระยะโรค** แล้วให้อิ๊งปรับเฉพาะเคสที่ผิดจากแบบ
- **เมนู 50 รายการยังไม่แท็กว่าใช้กับระยะไหนได้** (ยังไม่ฟอก = จำกัดโปรตีน / ฟอกแล้ว = ต้องเพิ่มโปรตีน — คนละทิศกันเลย)
- **PDPA** — เก็บข้อมูลสุขภาพ ต้องมีคำยินยอม + วิธีเก็บ/ทำลาย
- **เว็บกดส่งแล้วยังไม่มีอะไรวิ่งไปหาใคร** (ยังไม่ต่อระบบรับข้อมูล)
