## 6. ของที่ CC ทำเสร็จแล้ว (อย่าทำซ้ำ)
- **audit ทั้งระบบ 24 จุด + แก้หมด** → `docs/AUDIT_PRE_CUTOVER.md`

- **บอทผู้ช่วยครัวในกลุ่ม LINE** — `api/line-webhook.js` (เก็บแชททั้งหมด + ตอบยอดสั่งเมื่อถูกถาม) · **รอนัทรัน SQL + ใส่ token**
- **backup ข้อมูล** — `scripts/backup_data.sh` + scheduled task ทุกจันทร์ (ครั้งแรก 65,417 แถว)

## 8. 🎓 บทเรียนที่ CC เก็บได้ (ห้ามพลาดซ้ำ)
1. **ห้าม `cp` ไฟล์จาก working tree ทับตอน deploy** — เคยทำ favicon หายทั้งไฟล์แบบเงียบ → แก้ใน worktree ที่ base จาก origin เท่านั้น
2. **pipe บัง exit code** — `cmd | tail` คืน exit ของ `tail` → เคย push ไฟล์ครัวที่ syntax พังขึ้น main · ต้องเก็บ exit code ก่อน pipe
3. **ข้อมูลเก่าคือศัตรู** — CC เคยรายงานงานที่ U ทำเสร็จแล้วว่า "ยังค้าง" 3 รายการ + บอกว่า Lalamove ยังไม่มี key ทั้งที่ใช้งานได้จริง → **verify กับ DB/โค้ดจริงก่อนพูดทุกครั้ง**
4. **ข้อมูลเทสที่ใช้ชื่อจริง = ระเบิดเวลา** (ดูข้อ 4)
5. **ตรวจก่อนรายงานบั๊ก** — เกือบรายงานบั๊กผิดให้ U เพราะ innerText ดึงมาแล้วดูติดกัน ที่จริงเป็นชิปแยกสวยงาม
