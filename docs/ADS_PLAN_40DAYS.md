# 🎯 แผนแอด 40 วัน — เป้า 50 ลูกค้าใหม่ (1 ก.ย. → 11 ต.ค. 2026)

> **นัทสั่งเอง 1 ก.ย.:** *"ไปคิดแผนมาละกัน ออพติไมซ์เองเลย"* + *"ในอีก 40 วันเราต้องการลูกค้า 50 คน"* + *"ยิงแอดธรรมดาควบคู่กับแอดเจ"*
> **ทุนที่จมไปแล้ว ~฿1,600 · ได้กลับมา ฿0** — แผนนี้ต้องถอนทุนคืนให้ได้ ไม่ใช่แค่ "ลองใหม่"

---

## 🧠 ข้อสรุปที่เปลี่ยนแผนทั้งหมด

รอบที่แล้ว **8 คนเดินมาถึงหน้าสั่งของแล้วไม่ซื้อสักคน** — ผมเคยสรุปว่า "คอขวดอยู่ปลายทาง" แต่ยังไม่ได้บอกว่า**ทำไม**

**เพราะเราขอมากเกินไปในคลิกเดียว**
คนแปลกหน้าที่เพิ่งเห็นเราครั้งแรก ถูกขอให้ **จ่าย ฿1,280 · ล็อกอิน LINE · กรอกที่อยู่ · เลือกวันส่ง** ทั้งหมดในนัดแรก
คู่แข่งอย่าง CaloriesKiller ถึงต้องอัด **"12 ปี" + "หุ่นเปลี่ยนกว่า 50,000 คน"** ลงในรูป — เพราะเขารู้ว่าคนแปลกหน้าไม่ซื้อถ้ายังไม่เชื่อใจ

### → เปลี่ยนหน้าที่ของแอด
| เดิม | ใหม่ |
|---|---|
| แอดมีหน้าที่ **ปิดการขาย** | แอดมีหน้าที่ **เก็บคนเข้ามาถือคูปอง + เป็นเพื่อนใน LINE** |
| ราคาของคำว่า "ตกลง" = ฿1,280 | ราคาของคำว่า "ตกลง" = **฿0** |
| คลิกแล้วไม่ซื้อ = เงินหายถาวร | คลิกแล้วไม่ซื้อ = **ยังอยู่ใน LINE เรา ตามต่อได้ฟรีตลอดชีวิต** |

**นี่คือเหตุผลที่ต้องรอระบบเก็บคูปองเสร็จก่อนยิง** — ไม่ใช่แค่ "มีโปรเสริม" แต่มันคือ**ตัวรับคนที่ยังไม่พร้อมซื้อ** ซึ่งรอบที่แล้วเราไม่มีเลย 86 คนจึงหายไปหมด

**และมันตรงกับจุดแข็งจริงของร้าน** — เราชนะเพราะพลอย/แอดมินคุยกับลูกค้าเองได้ ไม่ได้ชนะเพราะหน้าเว็บสวย → หน้าที่ของแอดคือ**พาคนมาให้ถึงมือคน** ไม่ใช่พยายามปิดการขายแทนคน

## 📐 ตัวเลขเป้าหมาย (คิดถอยหลังจาก 50 คน)

| ขั้น | จำนวน | สมมติฐาน |
|---|---|---|
| คนคลิกแอด | ~1,200 | จากงบด้านล่าง |
| **เก็บคูปอง + เป็นเพื่อน LINE** | ~200 | 15% ของคนคลิก |
| **ใช้คูปองซื้อจริง** | **50** | 25% ของคนเก็บคูปอง |

⚠️ **เลข 25% เป็นสมมติฐาน ยังไม่เคยวัดกับร้านเรา** — ถ้าจริงต่ำกว่านี้ ตัวที่ต้องแก้คือ **ข้อความตามใน LINE** ไม่ใช่ตัวแอด · เลขนี้จะรู้จริงหลัง 10 วันแรก

**งบรวมทั้งแผน ~฿11,700** → ถ้าได้ 50 คน × AOV ฿1,280 = **~฿64,000**
⚠️ กำไรจริงฟันธงไม่ได้ (มาร์จิ้นยังเป็นตัวเลขเดา รอ statement ห้อง f)

## 🗓️ 4 เฟส

### เฟส 0 — 1-4 ก.ย. · **ใช้เงิน ฿0** (เฟสห้ามข้าม)
| # | งาน | ใคร | ทำไมข้ามไม่ได้ |
|---|---|---|---|
| 1 | 🔴 **Meta API อ่านอย่างเดียว** | นัท 5 นาที (passkey) | **รอบที่แล้วผมยิงจบแคมเปญโดยไม่รู้เลยว่าใช้เงินไปเท่าไหร่** — ห้ามเกิดซ้ำ |
| 2 | ระบบเก็บคูปองใช้ได้จริง | นัท (เย็นนี้/พรุ่งนี้) | ทั้งแผนวางบนตัวนี้ |
| 3 | บรีฟรูป 3 แบบ | ผมเขียน → เอไอตัวอื่นทำ | นัทยืนยันเอง: ผมทำได้แค่เลย์เอาท์ + บรีฟ |
| 4 | หน้า `/pack` ขึ้นจริง | M | ปลายทางที่ตรงกับแอด |
| 5 | ชุดแอดเจ | ผม | **เดดไลน์นัท 4 ก.ย.** |
| 6 | โหลดใบเสร็จ Meta ส.ค. | ผม/นัท | กฎบัญชีใหม่จากพี่ปืน — เก็บตอนจ่าย ไม่ใช่ตอนสิ้นเดือน |

### เฟส 1 — 5-8 ก.ย. · **฿150/วัน (~฿600)** · เทสรูป
**ตัวแปรเดียวคือรูป** — กลุ่มเดียวกัน (Lookalike ที่ทำได้ 13%) · ข้อความเดียวกัน · 3 ชิ้นงาน:
| | รูป | สมมติฐานที่กำลังทดสอบ |
|---|---|---|
| B1 | กราฟฟิกเดิม | ตัวควบคุม (ของที่รู้ผลแล้ว) |
| B2 | **กองแพคจริง 21 ชิ้น / ตู้เย็นเต็ม** | "เห็นของเยอะ = คุ้ม" · CK ทำไม่ได้เพราะขายรายวัน |
| B3 | **คนจริงถือ/หยิบของกิน** | นัทวิเคราะห์เอง + ตรงกฎแบรนด์ที่รอบก่อนผมทำผิด |

**ไม่ได้วัดยอดขายในเฟสนี้** — วัดว่ารูปไหนหยุดนิ้วได้ + ได้ CPC จริงมาคิดงบต่อ
**กติกาตัดวันที่ 4:** เก็บตัวชนะ ปิดอีก 2 ตัว

### เฟส 2 — 9-25 ก.ย. · **฿300/วัน (~฿5,100)** · สเกล + รีทาร์เก็ต
- ยิงรูปตัวชนะเต็มงบ · ปลายทาง `/pack` · จบที่ **เก็บคูปอง**
- เปิดกลุ่มรีทาร์เก็ต (คนเข้าเว็บแล้วยังไม่ซื้อ) เมื่อครบ ~1,000 คน — **กลุ่มนี้ถูกที่สุดเสมอ**
- **ไม่ยิงลูกค้าเก่าอีก** (รอบก่อน 0% จาก 17 คน) → คนกลุ่มนั้นใช้ broadcast LINE ถูกกว่ามาก

### เฟส 3 — 26 ก.ย.-11 ต.ค. · **~฿400/วัน (~฿6,000)** · เจ
**เจคือช็อตที่ดีที่สุดในแผนนี้ ไม่ใช่ของแถม** เพราะ:
- **มีเส้นตาย** (10-18 ต.ค.) — คนตัดสินใจเร็วขึ้นเองโดยเราไม่ต้องเร่ง
- **กินติดกัน 9 วัน = ซื้อเป็นคอร์ส ไม่ใช่กล่องเดียว** → AOV สูงกว่าปกติมาก
- **เจตนาซื้อชัด** — คนเสิร์ช "อาหารเจ" คือคนที่จะกินเจแน่นอน ไม่ใช่คนเลื่อนผ่าน
- **เรามีของจริง 180 เมนูย้อนหลัง + คะแนนจากใบสั่งซื้อจริง 355 คอร์ส** — คู่แข่งคลีนแทบไม่มีใครทำเจจริงจัง
- **คูปองที่แจกในเฟส 1-2 มาใช้ตรงนี้พอดี** — เก็บ ก.ย. → ใช้ ต.ค.

## 🔁 กระทืบซ้ำ (retargeting) — นัทสั่งเพิ่ม 1 ก.ย.

### ⚠️ ข้อเท็จจริงที่ต้องรู้ก่อน
**Meta ยิงตรงใส่ "คนที่แอดไลน์เรา" ไม่ได้** — LINE ไม่ปล่อยรหัสที่ Meta เอาไปจับคู่คนได้
เราจับเขาได้ 2 ทางเท่านั้น: **เบอร์โทร** (ถ้าเคยสั่งของ) หรือ **พิกเซลตอนเขาเข้าเว็บ**

### 🧮 ฐานคนจริงที่มี (นับจาก DB 1 ก.ย. 2026)
| กลุ่ม | จำนวน | เครื่องมือที่ถูก | ค่าใช้จ่าย |
|---|---|---|---|
| แอดไลน์ + เคยซื้อ (มีเบอร์) | **7,912** | LINE broadcast แบบแบ่งกลุ่ม | ~ฟรี |
| แอดไลน์ ไม่เคยซื้อ | ~20,000 ใน OA | LINE broadcast | ~ฟรี |
| **เข้าเว็บแล้วหายไป ไม่ได้แอดไลน์** | ~5,061 events (ส.ค.) | 🎯 **Meta retarget** | จ่าย |

### 🔑 หลักที่ใช้ตัดสิน
> **จ่ายเงินให้ Meta ไปหาคนที่อยู่ใน LINE เราแล้ว = จ่ายซ้ำในสิ่งที่ได้ฟรี**

รอบที่แล้วพิสูจน์แล้ว: ยิงลูกค้าเก่า 17 คน **กด 0 คน** เพราะเขาสั่งผ่านริชเมนูตรงได้อยู่แล้ว

- **Meta = จ่ายเฉพาะกลุ่มที่ไม่มีทางอื่นไปถึง** → คนเข้าเว็บแล้วหายไปเฉยๆ
- **คนที่แอดไลน์แล้ว = กระทืบด้วย broadcast แบ่งกลุ่ม** (ห้องเอิธถือ RFM segment อยู่แล้ว)
- ⚠️ ข้อจำกัด LINE: แพ็กเกจโปร 35,000 ข้อความ/เดือน · ผู้ติดตาม 23,319 → **ยิงรวมทั้งฐานได้เดือนละครั้งครึ่ง** แต่ยิงแบบแบ่งกลุ่ม 1,000-2,000 คน ทำได้อีกเยอะ → **ยิ่งตอกย้ำว่าต้องแบ่งกลุ่ม ไม่ใช่ยิงรวม**

### 💎 รายชื่อลูกค้ามีค่ามาก — แต่ใช้คนละแบบ
อัปรายชื่อเข้า Meta **ไม่ใช่เพื่อยิงใส่เขา แต่เพื่อสร้าง Lookalike** = ให้ Meta ไปหา "คนหน้าตาเหมือนลูกค้าดีของเรา"

- ⭐ **ใช้ VIP เป็นเมล็ดพันธุ์** (ซื้อเกิน ฿10,000 · ~162 คน) ดีกว่าใช้ทั้ง 7,912 — เมล็ดคมกว่า ผลชัดกว่า
- รอบที่แล้ว Lookalike ทำได้ **13%** ทั้งที่ยังใช้เมล็ดหยาบ

🔴 **ต้องนัทอนุญาตก่อน** — อัปเบอร์ลูกค้าเข้า Meta = ส่งข้อมูลส่วนบุคคลออกนอกบ้าน (Meta เข้ารหัสก่อนส่งก็จริง แต่เป็นการตัดสินใจของเจ้าของธุรกิจ ไม่ใช่ของผม)

## 📉 ความเสี่ยงที่ผมมองเห็นและไม่ปิดบัง
1. **25% ใช้คูปองเป็นตัวเลขที่ยังไม่เคยพิสูจน์** — ถ้าได้ 10% ต้องได้คนเก็บคูปอง 500 คน = งบบานเกินแผน → **จุดตัดสินคือวันที่ 10 ก.ย.**
2. **ยังไม่มีรูปจริงในมือเลยสักใบ** — ทั้งแผนหยุดถ้าไม่มีรูป (M ยืนยันแล้วว่าไฟล์ reference ไม่มีอยู่จริง)
3. **ยังอ่านตัวเลขเงินไม่ได้** — ถ้า Meta API ไม่ผ่าน ผมจะบินตาบอดเหมือนเดิม **ผมไม่ยิงถ้ายังอ่านเงินไม่ได้**
4. **เจกินกำลังครัวช่วงเดียวกับของปกติ** — ต้องให้ห้องครัวเคาะกำลังผลิตก่อนขายจริง
