> สถานะ: **11/50 คอร์ส · ต้องได้อีก 2.6 คอร์ส/วัน** · ตอนนี้ทำได้ 0.8/วัน
> รูปที่ขายได้ตอนนี้ 2 ใบ **เป็นแนวเดียวกันทั้งคู่** (บอกข้อมูลครบในรูปเดียว) → ลิสต์นี้เติมเฉพาะมุมที่ยังไม่มีใครเล่น

## 🥇 ใบที่ 1 — ชวนสงสัย (ของนัทเอง)
| | |
|---|---|
| **ภาพ** | ช้อนตักอาหารเจโคลสอัพ เห็นเนื้ออาหารชัด พื้นหลังเบลอ **ห้ามมีราคา ห้ามมีวันที่ ห้ามมีโลโก้ใหญ่** |
| **ข้อความ** | **หากปีนี้ตั้งใจจะกินเจ** *(ประโยคค้าง ไม่จบ)* |
| **แก้ข้อกังวล** | ไม่ได้แก้ข้อกังวล — ใบนี้ทำหน้าที่ **หยุดนิ้ว** อย่างเดียว ให้คนกดเข้าไปหาคำตอบเอง |
| **สูตรที่ใช้** | นอกเล่ม (นัทคิดเอง) |

⚠️ ใบนี้จะวัดผลคนละแบบกับใบอื่น — **ดูที่คนกดเข้าหน้า ไม่ใช่คนจองทันที**

## 🥈 ใบที่ 2 — คนจริงในครัว
| | |
|---|---|
| **ภาพ** | ครัวเราตอนทำงานจริง มีคนอยู่ในภาพ มือกำลังจัดกล่อง กล่องเรียงเป็นตั้ง **ถ่ายจากมือถือได้เลย ไม่ต้องจัดฉาก** |
| **ข้อความ** | **ครัวเราทำเอง ทุกกล่อง** |
| **แก้ข้อกังวล** | *"ร้านนี้มีตัวตนจริงไหม หรือรับของคนอื่นมาขาย"* — แอดเราทุกใบเป็นอาหารนิ่ง ไม่มีคนสักคน |
| **สูตรที่ใช้** | ภาค 1 ข้อ 7 (เอาของจริงที่มีแต่เรา) |

## 🥉 ใบที่ 3 — มีคนจองไปแล้ว
| | |
|---|---|
| **ภาพ** | กล่อง/ชุดคอร์สเรียงพร้อมส่ง หรือใบปะหน้ากล่องที่มีชื่อผู้รับ (เบลอชื่อ) |
| **ข้อความ** | **จองแล้ว 11 ที่ เหลือ 39** *(ตัวเลขต้องอัปเดตวันที่ทำรูป)* |
| **แก้ข้อกังวล** | *"มีใครซื้อจริงไหม"* — หน้า `/jay` ตอนนี้ไม่มีรีวิว ไม่มีหลักฐานคนซื้อสักชิ้น |
| **สูตรที่ใช้** | ภาค 1 ข้อ 3 (ตัวเลขจับต้องได้) |

🔴 **ตัวเลขต้องจริง ณ วันทำรูป** — ถ้าเลขขยับแล้วรูปยังโชว์เลขเก่า = เสียความน่าเชื่อถือทันที

## ใบที่ 4 — เจแล้วโปรตีนพอไหม
| | |
|---|---|
| **ภาพ** | วัตถุดิบโปรตีนเจวางเรียงให้เห็นเป็นกองจริง — เต้าหู้ · ฟองเต้าหู้ · เห็ด · ถั่ว · เทมเป้ ถ่ายมุมกด |

## ถ้าทำได้แค่ 3 ใบ
**1 (ชวนสงสัย) · 2 (คนจริงในครัว) · 3 (มีคนจองแล้ว)**
เหตุผล: ทั้งสามเป็นมุมที่ **ไม่เคยมีในแอดเราสักใบจาก 94 ใบ** — ใบที่เหมือนของเดิมจะไปแย่งประมูลกับตัวเราเอง

## เช็คก่อนยิงทุกใบ
- ข้อความบนรูป **≤7 คำ** · ไม่มี "ถูกที่สุด/ดีที่สุด" · ไม่ดิสของแช่แข็ง · ไม่มี "เลือกวันส่งได้"
- คอร์สเจ = **30 เมนู · กิน 10–18 ต.ค. · ปิดจอง 7 ต.ค.** (อย่าสลับตัวเลขกับ "10 วัน" ที่รวมวันล้างท้อง)
- **รูปทุกใบผ่านตานัทก่อนขึ้นเสมอ**
