# 📕 Case 02 — ครัวได้สินค้าไม่ครบ เพราะ Go Wholesale ส่งไม่ครบ

> **บันทึก 5 ส.ค. 2026 · k-track** — นัทแจ้งจากหน้างานครัว
> ⚠️ **ยังเป็นหัวข้อ ไม่ใช่เคสเต็ม** — รอรายละเอียดจากนัท (ดู "ข้อมูลที่ยังขาด" ท้ายไฟล์) · ห้ามสรุปสาเหตุก่อนได้ข้อมูลครบ

---

## สิ่งที่รู้ตอนนี้

- **ซัพพลายเออร์ Go Wholesale ส่งของไม่ครบ** → ครัวได้วัตถุดิบไม่ครบตามที่สั่ง

## 🔍 สิ่งที่บอกได้ทันทีจากข้อมูลที่มีอยู่แล้ว — **นี่ไม่ใช่เหตุบังเอิญครั้งเดียว**

ตอนทำแผนที่ทีมครัว (5 ส.ค. · [KITCHEN.md](KITCHEN.md)) นัทอธิบายหน้าที่ **โม๋ข่อง** ไว้เองว่า:

> *"...**ทวงของโกโฮลเซลว่ามาส่งหรือยัง**"*

→ **การทวงของ Go Wholesale ถูกจัดเป็น "งานประจำ" ของพนักงาน 1 คนอยู่แล้ว**
= ปัญหานี้เกิดถี่พอที่จะต้องมีคนคอยตามเป็นกิจวัตร **ก่อนที่จะมีใครเรียกมันว่าปัญหา**

⚠️ นี่คือแพทเทิร์นเดียวกับ [CASE_01](CASE_01_wrong_box_count.md): **งานที่คนแบกไว้เงียบๆ จนดูเหมือนไม่มีปัญหา** — จนวันหนึ่งมันหลุด

## 🔗 ต่อกับปัญหาเช้า 8:00–9:00 ที่บันทึกไว้แล้ว

KITCHEN.md บันทึกไว้ว่า ครัวเข้า 08:00 แต่ **ผักมาถึงเกือบ 09:00** → ต้องเอาของเหลือวันก่อนมาทำไปพลาง

**ของ "มาช้า" กับของ "มาไม่ครบ" = อาการเดียวกัน คนละหน้า** — ทั้งคู่คือ *ครัวเริ่มงานโดยไม่รู้ว่ามีของอะไรอยู่จริง*
→ แปลว่าปัญหานี้ไม่ใช่เรื่อง "ซัพพลายเออร์ห่วย" อย่างเดียว แต่คือ **เราไม่มีจุดตรวจรับของที่บันทึกไว้ได้**

---

## ❓ ข้อมูลที่ยังขาด (รอนัทเติมจากหน้างาน)

1. **ขาดอะไร กี่รายการ** — ของสดหรือของแห้ง? รายการไหนที่ขาดบ่อยที่สุด?
2. **รู้ตอนไหนว่าไม่ครบ** — ตอนรับของหน้าบ้าน หรือตอนจะหยิบไปทำแล้วไม่มี?
3. **ใครเป็นคนตรวจรับ** — มีคนเซ็นรับ/เช็คทีละรายการไหม หรือรับแล้ววางเลย?
4. **เกิดถี่แค่ไหน** — ทุกสัปดาห์? ทุกครั้ง?
5. **แล้วครัวทำยังไงต่อ** — ทวงให้ส่งเพิ่ม / ซื้อเองที่ตลาด / เปลี่ยนเมนู / งดขายเมนูนั้น?
6. **กระทบลูกค้าหรือยัง** — เคยทำให้เมนูไหนหายจากออเดอร์จริงไหม?
7. **สั่งของทางไหน** — แอป / LINE / โทร? มีหลักฐานว่าสั่งอะไรไปบ้างเก็บไว้ไหม?

## 💡 สมมติฐานเรื่องระบบ (ยังไม่ยืนยัน — ห้ามเอาไปสร้างอะไรก่อนตอบ 7 ข้อบน)

- ถ้า**ไม่มีบันทึกว่าสั่งอะไรไป** → เถียงกับซัพไม่ได้เลย ได้แค่ "รู้สึกว่าขาด"
- ถ้ามีจุด**เช็ครับของ** (ถ่ายรูป + ติ๊กรายการ ตอนของถึง) → ได้ทั้งหลักฐานทวงซัพ **และ** ครัวรู้ทันทีว่าวันนี้ทำเมนูไหนไม่ได้
- 🔗 ต่อกับบอทครัวได้ตรงๆ: ของขาด → พิมพ์บอกในกลุ่ม → เก็บลงระบบ → นัทเห็นในหน้าคอนโซล **โดยไม่มีใครต้องโทรหาใคร**
