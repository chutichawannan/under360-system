## ⏳ รอนัทเคาะ
| เรื่อง | ต้องการอะไร |
|---|---|
| **แพลนเมนู 2 สัปดาห์ล่วงหน้า** | ทำเสร็จแล้ว รอเคาะก่อนเขียนลง DB |

| **"รู้ใจลูกค้า" vs "สั่งของอัตโนมัติ"** | เลือกว่าเอาทางไหนก่อน (ผมเชียร์ "รู้ใจลูกค้า" ทำได้เลย ข้อมูลพร้อม) |
| **สั่งของ +30%** | จะเปลี่ยนวิธีสั่งเป็น "รายชนิดโปรตีน" จริงไหม |
| **ลิสต์เจ 20+20** | ของใหม่เกินครึ่งใช้เห็ดแทนเนื้อ จะสลับเป็นเต้าหู้/แพลนท์เบสบ้างไหม |
