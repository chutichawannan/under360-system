# 🎬 บรีฟถ่ายคลิปมือถือ — แพคกับข้าว (ส่งพลอย)

> **ใช้มือถือถ่ายเองพอ ไม่ต้องกล้อง ไม่ต้องแต่งหน้า ไม่ต้องพูด**
> ใช้เวลาจริงประมาณ **15-20 นาที** ถ่ายรวดเดียวจบ

---

## 🎯 คลิปนี้เอาไปทำอะไร (อ่านแค่ย่อหน้านี้พอ)

เราจะเอาไปยิงโฆษณา **ไม่ใช่เพื่อขายทันที** แต่เพื่อ**เก็บคนที่หยุดดูเอาไว้ตามต่อ**
Facebook ให้เราตามคนที่ "ดูวิดีโอ" ได้ แต่**ตามคนที่เห็นรูปนิ่งไม่ได้** — คลิปสั้นๆ ของพลอยเลยมีค่ามากกว่ารูปสวยๆ

**เพราะงั้นไม่ต้องสวย ต้องจริง** — ยิ่งดูเหมือนถ่ายเล่นๆ ยิ่งได้ผล

## 📱 ตั้งค่าก่อนถ่าย (ทำครั้งเดียว)

| | |
|---|---|
| **แนวตั้ง** | ถือมือถือตั้ง ห้ามถือนอน |
| **แสง** | ถ่ายกลางวัน หันหน้าเข้าหาหน้าต่าง · **อย่าให้หน้าต่างอยู่ข้างหลังของ** |
| **ห้ามซูม** | อยากได้ใกล้ = เดินเข้าไปใกล้ ไม่ใช่กดซูม (ซูมแล้วภาพแตก) |
| **นิ่ง** | จับสองมือ หรือพิงโต๊ะ/ผนัง |
| **ยาว 10-15 วิ** | ต่อคลิป · **อย่าให้เกิน 20 วิ** |
| **ถ่ายซ้ำ 2-3 รอบ** | ต่อคลิป เผื่อเลือก |

## 🎥 4 คลิปที่ขอ (ถ่ายได้กี่คลิปก็ส่งมาเท่านั้น ไม่ครบไม่เป็นไร)

### คลิป 1 — เปิดตู้เย็น/ตู้แช่ เห็นแพคเรียงเต็ม ⭐ ตัวสำคัญสุด
เริ่มที่**ประตูตู้ปิดอยู่** → เปิดออก → เห็นแพคเรียงเต็ม → ค้างไว้ 3 วิ
> **ทำไม:** ลูกค้าอยากรู้ว่า "ซื้อทีนึงได้เยอะแค่ไหน" — ภาพนี้ตอบได้ในวินาทีเดียว

### คลิป 2 — มือหยิบแพคขึ้นมาพลิกดู
หยิบแพค 1 ชิ้นขึ้นมา พลิกช้าๆ ให้เห็นทั้งของข้างในและแบรนด์บนซอง
> **ทำไม:** คนแปลกหน้าอยากเห็นของจริงในมือคน ไม่ใช่กราฟฟิก

### คลิป 3 — กองแพคเต็มโต๊ะ
วางแพคทั้งชุดกองบนโต๊ะ → มือค่อยๆ เรียง/นับทีละชิ้น
> **ทำไม:** เห็นปริมาณเทียบกับมือคน = รู้เลยว่าคุ้ม

### คลิป 4 — กินจริง
ฉีกซอง → เทใส่จาน/อุ่น → **กินคำแรก** (ใครกินก็ได้ ไม่ต้องเป็นพลอย)
> **ทำไม:** คู่แข่งเจ้าที่ยิงหนักสุดใช้ภาพคนจริงทุกใบ — เราไม่เคยใช้เลย

## ⏱️ กฎข้อเดียวที่สำคัญที่สุด: **1 วินาทีแรก**

**ต้องเริ่มที่ "ของ" ทันที** — ห้ามมีอินโทร ห้ามมีหน้าคนพูดนำ ห้ามมีโลโก้ขึ้นก่อน
คนเลื่อนผ่านใน 1 วินาที ถ้าวินาทีแรกไม่มีอาหาร = จบ

## ❌ ไม่ต้องทำ (ทำแล้วเสียของ)

- ❌ **ไม่ต้องใส่ตัวหนังสือ / สติกเกอร์ / ฟิลเตอร์** — เราใส่ทีหลังเอง ใส่มาแล้วเราแก้ไม่ได้
- ❌ ไม่ต้องใส่เพลง
- ❌ ไม่ต้องจัดจานสวยแบบนิตยสาร — **จัดสวยเกินคนไม่เชื่อ**
- ❌ ไม่ต้องครอปเป็นสี่เหลี่ยมจัตุรัส
