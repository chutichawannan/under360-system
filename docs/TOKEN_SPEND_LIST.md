# 💸 ลิสต์ของสิ้นเปลือง token — และลำดับที่จะตัดถ้าต้องประหยัด

> **นัทสั่งจดเอง 15 ส.ค. 2026:** *"จดไว้ด้วยนะ ถ้าวันนึงฉันบ่นห้องไหนก็ตามว่าต้องการประหยัดโทเคน **นี่คือ 1 ในลิสต์สิ้นเปลือง**"*
> **วิธีใช้:** นัทบ่นเรื่องประหยัดเมื่อไหร่ → เปิดไฟล์นี้ → ตัดจากบนลงล่าง (เรียงตาม "ตัดแล้วเจ็บน้อยสุดก่อน")
> ⚠️ **ห้ามตัดเงียบๆ** — ตัดแล้วต้องบอกนัทว่าตัดอะไรไป และเสียอะไรไปแทน

## 📊 ทะเบียนของที่กินโทเคน

| # | รายการ | กินเท่าไหร่ | ตอนนี้ | ตัดแล้วเสียอะไร |
|---|---|---|---|---|
| **1** | 🌆 **พี่ปืนกวาดรอบเย็น** (`pi-puen-evening-sweep` · 18:23 น.) | ~เท่ารอบเช้า = **โทเคนเพิ่มเท่าตัว** | 🟢 เปิด (นัทเลือกทาง C · 15 ส.ค.) | สรุปเย็นหาย · เหลือแค่รอบตี 4 + **ตัวนับความเคลื่อนไหวสดบนการ์ด** (= ทาง A) → **ยังรู้ว่าตกข่าวไปเท่าไหร่ แค่ไม่มีคนย่อยให้** |
| **2** | 🔬 **การไล่อ่านเอกสารทุกไฟล์ลึกๆ** (แบบ 15 ส.ค. · 126 ไฟล์ × 20 บรรทัด) | สูงมาก แต่เป็น **one-shot** | ⚪ ทำครั้งเดียวจบแล้ว | ไม่เสียอะไร ถ้าไม่ทำซ้ำโดยไม่จำเป็น |
| **3** | ☀️ **พี่ปืนกวาดรอบเช้า** (`pi-puen-daily-sweep` · 04:11 น.) | ปานกลาง-สูง | 🟢 เปิด | **ตัดเป็นอันสุดท้าย** — เป็นแกนของ "หัวหน้าที่ทันสมัย" ถ้าตัดตัวนี้ ห้อง pm กลับไปเป็นแค่ห้องแชทธรรมดา |

## 🪜 ลำดับการตัด (ถ้าโทเคนตึง)

```
ขั้น 1  ปิดรอบเย็น → เหลือ "ทาง A" (รอบเช้า + ตัวนับสดบนการ์ด)   ← ตัดอันนี้ก่อนเสมอ
ขั้น 2  ลดรอบเช้าเหลือ วันเว้นวัน หรือเฉพาะ จ/พ/ศ
ขั้น 3  ตัดขั้นที่ 3 ของรอบเช้า (ปลุกห้อง) → เหลือแค่กวาด+สรุป
ขั้น 4  ปิดรอบเช้า → เหลือแค่ตัวนับสดบนการ์ด (ไม่มีคนย่อยให้)
```

**หลักที่ใช้เรียง:** ตัดของที่ **"มีทางแทนที่แล้วยังรู้เรื่องอยู่"** ก่อน · เก็บของที่ **"ตัดแล้วตาบอด"** ไว้ท้ายสุด

---

## 🧠 เหตุผลที่เลือกทาง C ตอนนี้ (15 ส.ค. 2026)

นัทเลือก **C = รอบเช้า + รอบเย็น + การ์ด 2 ชั้น** เพราะ **"token เหลือ"**
พร้อมสั่งไว้ล่วงหน้าว่า **"ถ้าหมดค่อยลดเหลือ A ย้อนกลับแบบนี้แทน"**

→ **นี่คือการตัดสินใจที่ถูกออกแบบให้ถอยได้** ไม่ใช่ทางเดียว · ตัวเลือก A ยังอยู่ครบ ไม่ต้องรื้ออะไร แค่ปิด task รอบเย็น

## ➕ วิธีเติมรายการใหม่

เจอของที่กินโทเคนเยอะและ **มีทางประหยัดกว่า** → เติมลงตาราง พร้อมตอบ 3 ช่อง:
**กินเท่าไหร่ · ตัดแล้วเสียอะไร · มีอะไรมาแทนได้**
⚠️ ถ้าตอบช่อง "มีอะไรมาแทน" ไม่ได้ = **อย่าใส่ไว้ในลิสต์ตัด** เพราะตัดแล้วตาบอด ไม่ใช่ประหยัด
