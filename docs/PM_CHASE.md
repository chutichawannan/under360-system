## 📏 กติกาของไฟล์นี้

1. **นัทพูดคำว่า "ฝากทวง / ไปตาม / อย่าลืม" → เติมแถวที่นี่ทันที** ไม่ต้องรอสรุปท้ายเทิร์น
2. **ทวงแล้วต้องนับรอบ** — ทวง 3 รอบไม่ตอบ = ยกให้นัทตัดสินว่าจะเปลี่ยนคนทำไหม
3. **ห้องตอบแล้ว → ย้ายลงปิดแล้ว พร้อมบันทึกว่าใช้เวลากี่วัน** — ตัวเลขนี้บอกว่าระบบเราช้าตรงไหน
4. ⛔ **ห้ามทวงโดยไม่มีอะไรใหม่ให้เขา** — ทวงพร้อมข้อมูลที่ช่วยให้เขาทำได้ง่ายขึ้นเสมอ
