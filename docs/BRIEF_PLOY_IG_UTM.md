## 🎯 ทำไมถึงส่งเรื่องนี้มา

วันนี้ (29 ส.ค.) ฝั่งนัทยิงแอด Facebook ไป 2 ชุด แล้วไล่ดูว่าออเดอร์แต่ละใบมาจากไหน **เจอสิ่งนี้:**

| แหล่ง | คนเข้าเว็บวันนี้ | ออเดอร์ |
|---|---|---|
| **Instagram (organic — ไม่เสียเงิน)** | **11 ครั้ง** | **1 ใบ ฿1,350** ← **ลูกค้าใหม่** |
| Facebook Ads (เสียเงิน) | 28 ครั้ง | 0 ใบ |

**IG ที่พลอยทำอยู่ ได้ลูกค้าใหม่จริง โดยไม่เสียค่าโฆษณาสักบาท**

**แต่เราไม่รู้ว่ามาจากโพสต์ไหน** — ระบบเก็บได้แค่ป้ายกว้างๆ ว่า `ig/social` เท่านั้น (ช่องชื่อแคมเปญว่างเปล่า)
เพราะลิงก์ในไบโอ IG เป็นลิงก์เปล่า ไม่มีป้ายกำกับ · และ Instagram ไม่บอกว่าคนกดมาจากโพสต์ไหน (ส่งมาแค่ `l.instagram.com`)

**ผลคือ:** โพสต์ที่ทำเงินจริงกับโพสต์ที่ไม่มีใครสนใจ **หน้าตาเหมือนกันหมดในรายงาน** → พลอยเลือกไม่ได้ว่าควรทำคอนเทนต์แบบไหนเพิ่ม

## 📏 กติกาตั้งชื่อ (สำคัญ — ผิดแล้วข้อมูลเสีย)

| กฎ | เหตุผล |
|---|---|
| **ใช้ตัวอักษรอังกฤษ ตัวเลข และ `-` เท่านั้น** | ระบบตัดอักขระอื่นทิ้งอัตโนมัติ · ภาษาไทยจะหาย |
| **ห้ามเว้นวรรค** | ใช้ `-` แทน |
| **ใส่วันที่ต่อท้ายเสมอ** (เช่น `-0829`) | โพสต์เรื่องเดียวกันคนละวัน จะได้แยกออก |
| **`utm_source=ig` และ `utm_medium=social` ห้ามเปลี่ยน** | ตัว 2 ตัวนี้คือกุญแจที่ระบบใช้แยก IG ออกจาก FB — ถ้าเปลี่ยน ข้อมูลจะไปปนกับช่องทางอื่น |
| **1 โพสต์ = 1 ชื่อ ห้ามใช้ซ้ำ** | ใช้ซ้ำ = ยอดกองรวมกัน แยกไม่ออก |

⚠️ **ถ้าใช้ตัวย่อลิงก์ (bit.ly / lnk.bio / Linktree)** ต้องให้ปลายทางเป็นลิงก์ติดป้ายด้านบน **ไม่ใช่ลิงก์เปล่า** ไม่งั้นป้ายหายระหว่างทาง

## 🎁 พลอยจะได้อะไร

พอมีป้ายแล้ว ฝั่งนัทจะดึงรายงานแบบนี้ให้ได้ — **เป็นบาทจริง ไม่ใช่ยอดไลก์:**

```
โพสต์ "แพคกับข้าว 29 ส.ค."   →  คนกดเข้าเว็บ 34  →  สั่งจริง 3 ใบ  →  ฿4,050
โพสต์ "Meal Plan 28 ส.ค."     →  คนกดเข้าเว็บ 12  →  สั่งจริง 0 ใบ  →  ฿0
สตอรี่ 27 ส.ค.                →  คนกดเข้าเว็บ 45  →  สั่งจริง 1 ใบ  →  ฿1,350
```

→ **รู้ว่าคอนเทนต์แบบไหนขายได้จริง** ไม่ใช่แค่ยอดไลก์/ยอดวิว
→ ทำซ้ำอันที่เวิร์ค เลิกอันที่ไม่เวิร์ค **โดยไม่ต้องเดา**

## 🔧 ทำงานร่วมกันยังไง

**พลอยไม่ต้องพิมพ์ลิงก์เอง** — บอกฝั่งนัทว่าจะโพสต์เรื่องอะไร วันไหน → **ฝั่งนัททำลิงก์ให้ พร้อมก๊อป**

> 🔴 **เหตุผลที่ห้ามพิมพ์เอง:** พิมพ์ผิดตัวเดียว ป้ายเพี้ยน → ได้ข้อมูลขยะ **ซึ่งแย่กว่าไม่มีข้อมูล** เพราะเราจะตัดสินใจจากตัวเลขที่ผิด
> (กติกานี้เขียนไว้ในกระดานกลางนัท-พลอยแล้ว: *"ขอลิงก์จากฝั่งนัท อย่าพิมพ์เอง"*)

**ขั้นตอน:**
1. พลอย/Claude ของพลอย บอกมาว่า **จะโพสต์อะไร วันไหน กี่ชิ้น**
2. ฝั่งนัทส่งลิงก์ติดป้ายกลับให้ **พร้อมใช้ ก๊อปวางได้เลย**
3. พลอยเอาไปใส่ในโพสต์/ไบโอ/สตอรี่
4. ฝั่งนัทดึงรายงานให้เป็นระยะ **ว่าโพสต์ไหนทำเงินเท่าไหร่**
