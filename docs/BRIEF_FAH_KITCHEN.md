## 🔴 ขั้นที่ 3 — ข้อห้ามรายคน (จุดที่พลาดแล้วเสียลูกค้า)

**อ่านคอลัมน์ Notes ทุกแถว** แล้วแปลงเป็นคำสั่งที่ครัวทำตามได้:

| ตัวอย่างที่เจอจริง | ต้องเขียนในใบว่า |
|---|---|
| ❌ไม่กินพริกหยวก | *"มีมี่ — เมนู 1 ตัดพริกหยวก ใช้ซูกินี/แครอทแทน"* |
| ❌ไม่ทานเนื้อวัว | *"คุณมอส — ใช้หมูบดแทนเนื้อวัว 1 กล่อง"* |
| ขอข้าวไรซ์เบอร์รี่ทั้งหมด | *"อุษณี — ข้าวไรซ์เบอร์รี่ทุกกล่อง (ทั้ง 7)"* |
| ❌ไม่ทานหมู | *"นวภัท — ไม่ได้เมนู 4-5 · ได้เมนู X แทน"* |

**กฎ:**
- ต้องขึ้น **2 ที่**: กล่องแดงบนสุด (ภาพรวม) **+ แถบชมพูใต้บรรทัดเมนูที่เกี่ยว** (ตรงจุด)
- เขียนเป็น**ประโยคจบในตัว** *"มีมี่ — ตัดพริกหยวกออก 1 กล่อง"* ไม่ใช่ป้าย+ตัวเลขแยก
- **ลำดับความสำคัญ: ของแพ้/ไม่กิน > ทุกอย่าง** — ชั่งเกิน 20g ยังพอรับได้ แต่ใส่หมูให้คนไม่กินหมู = เสียลูกค้า

## 🎨 ขั้นที่ 4 — รูปแบบใบ (นัทปรับมา 5 รอบจนลงตัว)

### ใบผลิต (จัดตาม **เมนู**)
```
1. อกไก่ Piri Piri                          [15]   ← ยอดรวม
🥗 มันฝรั่งอบ + พริกหยวก/ซูกินี · 🫒 ~8g      ← ผัก+น้ำมัน ต่อท้ายชื่อ (บรรทัดเดียว)
──────────────────────────────────────────
LC      อกไก่ 120g · มันฝรั่ง                 5   ← ยอดรวมจริง ห้ามให้ครัวหักลบเอง
  มีมี่ — ตัดพริกหยวก 1 กล่อง                    ← แถบชมพู ไม่มีเลขคอลัมน์ขวา
HP      อกไก่ 170g · มันฝรั่ง                 4
HYROX   อกไก่ 170g · มันฝรั่ง ~300g           6
```

**กฎเหล็ก:**
- **3 บรรทัดหลักเท่านั้น** (LC/HP/HYROX) — ห้ามแตกบรรทัดย่อยเพิ่ม (นัทบอก "ดูยากเข้าไปอีก")
- เลขขวา = **ยอดรวมจริง** ครัวดูเลขเดียวเตรียมเนื้อได้เลย
- ผักเคียง + น้ำมัน = **ต่อท้ายชื่อเมนู** ไม่ใช่บรรทัดใหม่
- น้ำมันรำข้าว ~3–12g/เมนู (คุมไขมันทั้งกล่อง 12–18g) · แซลมอนใส่น้อยสุด (ปลามันเอง)

### ใบจัดของ (จัดตาม **ลูกค้า**)
```
มีมี่                                    [7 กล่อง]
LINE: Mimi · HT-1243770593              ← ต้องมีเลขออเดอร์
🔴 เมนู 1 ตัดพริกหยวกออก
☐ 1  อกไก่ Piri Piri · อกไก่
☐ 2  สเต๊กไก่พริกไทยดำ · อกไก่
```
- **ติ๊กได้** (localStorage) · เรียง LC → HP → Hyrox · ของแถม (Gel) ขึ้นแถบเหลือง

### ทั้ง 2 ใบ
- **3 ภาษา: ไทย / ไทใหญ่ / พม่า** (ปุ่มบนสุด) — พนักงานครัวอ่านได้
- **ตัวเลข/กรัม = สากล ห้ามแปล** · โปรตีน/คาร์บ/ข้อห้าม = แปล
- ขึ้น banner เตือน "คำแปล AI ให้พนักงานตรวจ" เมื่อไม่ใช่ไทย
- **กระชับ**: แถวสูง ~29px · ฟอนต์ 13–14px · mobile-first (เทสที่ 375px)
- ฟอนต์ Noto · single-file HTML · ไม่มี dependency

## ⚠️ บทเรียนที่เสียเวลาไปแล้ว (อย่าทำซ้ำ)

1. **อ่านชีทผิดแถว** เพราะแอดมินเพิ่มคน → สรุปว่า "ไม่มีติ๊ก" ทั้งที่ติ๊กครบ → **เช็คชื่อลูกค้าให้ตรงก่อนอ่านคอลัมน์เมนูเสมอ**
2. **เจอข้อมูลไม่ตรงแล้วรื้อเอง** → นัทต้องสั่ง revert · **ที่ถูก: รายงานก่อน รอไฟเขียว**
3. **ปล่อยช่องว่างในใบ** (เขียน "รอเลือก") → เสี่ยงครัวไม่ทำ = ไม่มีของส่ง · **ต้องกำหนดให้ครบเสมอ**
4. **แตกบรรทัดเยอะเกิน** เพื่อความละเอียด → นัทอ่านไม่ไหว · **3 บรรทัดพอ รายละเอียดไปอยู่แถบชมพู**
5. `git show origin/main:file` **พังเงียบบน Windows** (path separator) → ใช้ commit hash แทน
