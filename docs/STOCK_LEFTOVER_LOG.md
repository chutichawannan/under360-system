# 🥬 สมุดจดของเหลือ — วัตถุดิบคงเหลือในครัว

> **เกิดขึ้นเพราะนัทพูดเอง 22 ส.ค. 2026:** *"เรามีคนช่วยสั่งของแล้ว **แต่เรายังไม่มีคนจดของเหลือเลย** ... **นี่คือตัวอย่างงานที่งอกมาแล้วฉันไม่รู้จะจดไปที่ไหน**"*
>
> **PM ตรวจแล้วยืนยัน: ก่อนไฟล์นี้ ไม่มีที่จดของเหลือเลยทั้งระบบ** — ไม่มีไฟล์ ไม่มีตาราง DB (`ingredients` · `ingredient_stock` · `stock_counts` = ไม่มีสักตัว)
>
> **ไฟล์นี้ = ที่พักชั่วคราว** จนกว่าจะมีตารางจริงใน DB · **แต่มีที่พักดีกว่าไม่มี** — ของที่ไม่มีบ้านคือของที่หาย

---

## 📌 กติกาใช้ไฟล์นี้

1. **จดดิบก่อน ปรับทีหลัง** — ครัว/นัทส่งมาแบบไหน ลงแบบนั้น **ห้ามแปลงหน่วยเองแล้วทับของเดิม**
2. **ทุกครั้งต้องมีวันที่** — ของเหลือไม่มีวันที่ = ใช้ประเมินอะไรไม่ได้เลย
3. **หน่วยไม่ชัด = ติดธง ⚠️ ห้ามเดา** — เดาผิดแล้วเอาไปคำนวณสั่งของ จะสั่งผิดทั้งรอบ
4. **ห้ามลบรอบเก่า** — ต้องเทียบข้ามรอบได้ ถึงจะรู้ว่าของไหนเหลือประจำ

## 🔴 สิ่งที่ยังไม่มี — ต้องเติมก่อนของนี้จะใช้งานได้จริง

| ขาดอะไร | ทำให้อะไรทำไม่ได้ |
|---|---|
| **หน่วยมาตรฐาน** (กรัม/กก./ชิ้น/ถุง — ถุงละกี่กรัม) | รวมยอด · เทียบข้ามรอบ · คำนวณอัตโนมัติ |
| **จดรอบไหนของวันไหน** (เช้า/เย็น · ก่อนผลิต/หลังผลิต) | แยกไม่ออกว่า "เหลือ" หรือ "ยังไม่ได้ใช้" |
| **ใครนับ** | ตรวจสอบย้อนหลังไม่ได้ |
| **อายุของ (shelf life)** | ไม่รู้ว่าของที่เหลือ **ยังใช้ได้อีกกี่วัน** → ตัวนี้คือตัวตัดสินว่าต้องรีบใช้หรือทิ้ง |
| **ตารางจริงใน DB** | ตอนนี้เป็นไฟล์ md — คนอ่านได้ แต่ระบบเอาไปคำนวณไม่ได้ |

## 🎯 ปลายทางที่ควรเป็น

```
ครัวนับของเหลือ  →  จดที่เดียว  →  ฟ้าเทียบกับแผนผลิตพรุ่งนี้  →  buyer หักออกจากยอดสั่ง
                                          ↓
                                  ของไหนเหลือประจำ = สั่งเกินประจำ
```

**วันนี้ยังทำไม่ได้เพราะ:** ไม่มีสูตร (C1) · ไม่มีอายุของ (C2) · ไม่มีหน่วยมาตรฐาน (ใหม่)
