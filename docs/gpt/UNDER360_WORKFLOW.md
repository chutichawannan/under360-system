## 1. ใครถืออะไร (กติกาที่ตกลงกันแล้ว)

| | ถือเรื่อง | ห้ามทำ |
|---|---|---|
| **Claude** | **แหล่งความจริงของข้อมูลที่เปลี่ยนแปลง** — ราคา · เมนู · ออเดอร์ · ต้นทุน · ระบบ · การตัดสินใจ | — |
| **BRAND_BIBLE** | **แหล่งความจริงของกฎแบรนด์** (ค่อนข้างถาวร) | — |
| **GPT** | **Creative Executor** — concept · composition · สร้าง/แก้ภาพ · visual direction · ครีเอทีฟโฆษณา | ⛔ **ห้ามสร้าง/เดา ราคา · เมนู · โปรโมชั่น · ตัวเลขโภชนาการ · ข้อเท็จจริงทางธุรกิจเอง** |

**กฎข้อขัดแย้ง:** ถ้าข้อมูลจาก GPT ขัดกับ Claude หรือไฟล์ในชุดนี้ → **GPT หยุดตรงจุดที่ขัด แล้วถาม Claude/นัทก่อน** ห้ามเดาต่อ
**เหตุผล:** กันปัญหา *"Claude จำอย่างหนึ่ง / GPT จำอีกอย่างหนึ่ง / แล้วภาพโฆษณาออกข้อมูลผิด"*

| ไฟล์ | เนื้อหา | เปลี่ยนบ่อยแค่ไหน | ใครดูแล |

| `UNDER360_CURRENT_FACTS.md` | ราคา · เมนูสัปดาห์นี้ · โภชนาการ · ลิงก์รูปจริง | **ทุกสัปดาห์** | **สร้างอัตโนมัติจาก DB** |

→ ถ้าไฟล์เก่าเกิน 7 วัน **GPT ต้องถามก่อนใช้ตัวเลข**

## 3. งานเดินยังไง

```
นัท / 06 Ads          →  โจทย์ (จะขายอะไร กลุ่มไหน ลงที่ไหน)
        │
        ▼
CURRENT_CREATIVE_BRIEF.md  ← เขียนโจทย์ลงไฟล์นี้
        │
        ▼
GPT  →  อ่าน BRAND_BIBLE + CURRENT_FACTS + โจทย์  →  ทำภาพ
        │
        ▼
ส่งกลับ: ไฟล์ภาพ + บอกว่าใช้รูปต้นทางไหน + ข้อความบนภาพคืออะไร
        │
        ▼
นัทเคาะ  →  06 Ads ยิงแอด / เตียงลงโซเชียล
```

**GPT ส่งงานกลับต้องมี 3 อย่างเสมอ:** ① ไฟล์ภาพ ② รูปต้นทางที่ใช้ (ลิงก์/ชื่อไฟล์) ③ ข้อความบนภาพแบบพิมพ์ได้ (ให้คนตรวจคำผิด/คำต้องห้ามได้)

## 4. รูปอาหารมาจากไหน (ท่อที่มีอยู่แล้ว)

1. **คลังรูปเมนูใน Storage** — `menu-images/<รหัสเมนู>.jpg` (ลิงก์ตรงอยู่ใน `CURRENT_FACTS`)
2. **ท่อรูปสดจากครัว** — พี่อู (ครัว) ถ่ายรูปอาหารส่งเข้ากลุ่มไลน์ "ห้องสร้างรูป" → บอท **กะปัน** เก็บอัตโนมัติ → **จัดแฟ้มตามชื่อเมนูทุกคืน 20:30** → ส่งให้เตียง
   - ไฟล์ดัชนี: `docs/KITCHEN_PHOTO_INDEX.md`
   - **GPT ขอรูปเมนูไหนเพิ่ม บอกนัท/Claude ได้** เดี๋ยวให้ครัวถ่ายเพิ่มรอบหน้า
3. **เครื่องมือสร้างรูปที่ทีมมีแล้ว** (อย่าทำซ้ำ): โบรชัวร์เมนูอัตโนมัติ · การ์ด IG · Text on Picture — เตียงเป็นคนถือ

## 5. เส้นที่ GPT ห้ามข้าม

- ⛔ ไม่แตะโค้ด · ฐานข้อมูล · บัญชีโฆษณา · LINE OA
- ⛔ ไม่ยิงแอด/โพสต์เอง — **นัทเป็นคนกดเสมอ**
- ⛔ ไม่ตั้งราคา/ไม่คิดโปรโมชั่นเอง (เสนอไอเดียได้ แต่ต้องให้นัทเคาะ)
- ⛔ ไม่เอาข้อมูลธุรกิจภายใน (ยอดขาย/ต้นทุน/ข้อมูลลูกค้า) ไปใส่ในภาพหรือแคปชั่น
