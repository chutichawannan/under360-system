# 🔧 ใบงาน: คู่ S/D ที่ไม่ตรงกัน — ส่งน้องนิว

> **นัทสั่งเอง 16 ส.ค.:** *"ตาราง s/d ที่คุยกันค้างไว้ก็ส่งให้ห้องนิวด้วย"*

> 🟢 = เปิดขายอยู่ (กระทบลูกค้าตอนนี้ ทำก่อน)

## สรุป
