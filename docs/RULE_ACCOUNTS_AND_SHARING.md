## 📌 กฎย่อยที่ต่อเนื่องกัน

1. **ธุระส่วนตัว / เอกสารครอบครัว / ข้อมูลการเงิน — ห้ามขึ้น repo ทุกกรณี** (repo push GitHub) → เก็บใน Drive แล้วแชร์ หรือเก็บใน `~/.claude/SECRETARY.md`
2. **repo `under360-system` เป็น private** → ลิงก์ `raw.githubusercontent.com` เปิดไม่ได้ **อย่าเสนอให้ใครเปิด**
3. **ของที่ต้องใช้ข้าม 2 เครื่อง ต้องผ่านอินเทอร์เน็ตเท่านั้น** — Google Docs · เว็บของร้าน · Supabase · **ห้ามอ้าง path ในเครื่อง** (เช่น `C:\Users\...`) เพราะอีกเครื่องไม่มีไฟล์นั้น
4. **ก่อนเอาไฟล์ขึ้น URL สาธารณะ** ต้องเช็คก่อนว่ามีตัวเลขธุรกิจ/ข้อมูลลูกค้าไหม — ถ้ามี **ตัดออกก่อน**
