## 8. 🛠 วิธีทำงานที่ใช้จริงในห้องนี้ (ทำตามนี้แล้วไม่พัง)

```
1. git worktree add --detach $WT origin/main     ← ห้ามแก้ในทรีหลัก (ห้องอื่นใช้ร่วมกัน งานหายมาแล้ว 2 รอบ)
2. แก้ไฟล์
3. node scripts/check-html-js.js <file.html>     ← ทุกครั้ง ไม่มีข้อยกเว้น
4. git commit → git fetch && git rebase origin/main
5. push เข้า branch → แล้วค่อยขึ้น main
6. รอ Vercel deploy → curl เช็คว่าโค้ดใหม่ขึ้นจริง → เทสบน Chrome จริง
```

**🪤 กับดักที่โดนซ้ำๆ ในห้องนี้ (จำไว้ จะประหยัดเวลาไปเยอะ)**
1. **แบ็กสแลชหายตอนเขียนไฟล์ผ่าน heredoc** — `\s` `\b` `\n` ในโค้ด JS โดน shell กิน (โดนมาแล้ว 4 ครั้ง · ครั้งนึงทำ regex ครัวพังเงียบ) → **เขียนสคริปต์แพตช์ด้วยเครื่องมือเขียนไฟล์ ห้ามใช้ heredoc กับโค้ดที่มีแบ็กสแลช**
2. **ประกาศตัวแปรทีหลังแล้วใช้ก่อน** — `var` ไม่ error แต่เป็น `undefined` เงียบๆ (โดน 3 ครั้ง: `packed`, `stale`) · `const` จะพังทั้งหน้า (เกือบทำร้านสั่งของไม่ได้ 24 ส.ค.)
3. **PostgREST คืนแค่ 1000 แถว** ถ้าไม่ใส่ `.limit()` — ไม่มี error ให้เห็น
4. **`stock_total = null` แปลว่าไม่จำกัด ไม่ใช่ 0**
5. **`output ว่าง ≠ ไม่มีของ`** — เช็ค exit code/stderr ก่อนสรุป
6. **เทสด้วยการเรียกฟังก์ชันตรงๆ ไม่พอ** — ต้องกดบนหน้าจริง (เคยพลาดเพราะเรียก `renderCard()` เอง เลยไม่เห็นว่าปุ่มไม่อัปเดตตอนติ๊ก)
