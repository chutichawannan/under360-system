# กติกางานร่วม Codex และ Claude

สถานะ: เจ้าของยืนยันให้ใช้ 25 กันยายน 2569 — รอ Claude รับทราบและยืนยันการปรับระบบของตน

1. ใช้ข้อมูลสด Meta เป็นหลักเรื่องค่าตั้งแอด ใช้สถานะชำระในฐานข้อมูลเป็นหลักเรื่องยอดขาย ข้อมูลบริการจากเจ้าของล่าสุดมีลำดับเหนือข้อสรุปเก่าของ AI หากระบบขัดกันบันทึกและตรวจให้ตรง
2. Git เก็บสถานะล่าสุดและ history เพื่อใช้ข้ามเครื่องได้ ใช้ docs/ads-operations ใน repo under360-system เป็นแหล่งกลาง เก็บลิงก์จาก Ads Project ไม่สร้างสำเนาที่แก้ได้อิสระสองชุด
3. Git ไม่ใช่ live database หรือระบบล็อกการแก้แอด ก่อนลงมืออ่านค่าจริง ระบุเจ้าของการเปลี่ยนแปลง/งานค้าง และตรวจว่าอีกฝั่งไม่ได้ทำอยู่ หากชนกันหยุดการเขียนรายการนั้น
4. ทุกการแก้มี actor, IDs, timestamp, before/after, เหตุผล, งบ, ผลอ่านกลับ และ rollback ห้ามเขียนว่าทำสำเร็จเพียงเพราะเสนอไว้
5. Token/secret และข้อมูลลูกค้าไม่เข้า Git ใช้ secret store แยก ต้องอ่านได้เฉพาะเครื่องที่ได้รับสิทธิ์
6. ตกลง allowlist/เจ้าของชุดทดลองกับ watchdog ก่อนเปิดแอด ห้ามปิดระบบป้องกันทั้งบัญชี และห้ามให้สอง AI ปรับงบชุดเดียวกันอัตโนมัติโดยไม่ประสาน
7. มีเพดานงบต่อวันและรวมช่วงทดลอง ไม่ตีความอิสระทางเทคนิคเป็นสิทธิ์ใช้เงินไม่จำกัด ตอนนี้ 300 บาท/วัน 7 วันยังเป็นข้อเสนอในเอกสาร
8. ผลต่างความเห็นให้ตัดสินด้วยหลักฐาน/ทดลอง ไม่ใช้การเห็นด้วยของ AI สองตัวเป็นหลักฐานความถูกต้อง
9. ข้อมูล handoff เสนอ Catalog เดิม under360 ID 637948280523796 (ต้องอ่าน Meta ยืนยันก่อนเขียน); ชุดสินค้า GPT-* ไม่ใช่สร้าง catalog GPT-* ใหม่ ข้อความเก่าที่สับสนชื่อเป็นข้อกำหนดตกค้าง
10. UTM source=fb medium=paid; campaign ผูกสินค้าหรือการทดลองอย่างคงที่ เช่น pack2026/mp2026 ไม่ใช้ jay2026 กับทุกสินค้า; content ระบุชิ้นงาน gpt_* ประสานตัวจับคู่ยอดให้รองรับก่อนเปิด

## วิธีอัปเดต
- ดึง Git ล่าสุดก่อนเริ่ม ตรวจ working tree และไม่ทับงานค้าง
- ADS_CURRENT.md เป็นสถานะล่าสุด พร้อมเวลาตรวจและแหล่งข้อมูล ADS_HISTORY.md บันทึกต่อท้าย
- commit/push เฉพาะไฟล์งานตนเอง ห้าม force push และห้ามใส่ Token หรือข้อมูลลูกค้า
- ก่อนแก้บัญชีต้องรับทราบผู้รับผิดชอบจากอีกฝ่าย Git เพียงอย่างเดียวไม่รับประกันว่าไม่มีงานพร้อมกัน
- Codex รับผิดชอบเตรียมชุดการ์ดทดลอง Claude ดูแลแอดเดิม จนกว่าจะตกลงเปลี่ยน
- ความเห็นด้านเทคนิคที่ขัดกันให้ AI ตรวจหลักฐานและบันทึกข้อสรุป ถามเจ้าของเฉพาะข้อเท็จจริงธุรกิจ/วงเงิน/ข้อเลือกที่มีผลสำคัญ
