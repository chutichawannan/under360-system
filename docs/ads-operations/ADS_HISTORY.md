เวลาไทย; ผู้ดำเนินการ; ad/campaign IDs; ก่อน→หลัง; เหตุผล/สมมติฐาน; แหล่งข้อมูล; งบ/เพดาน; ผล API และการอ่านกลับ; วิธีคืนค่า; ผู้รับผิดชอบติดตามผล
