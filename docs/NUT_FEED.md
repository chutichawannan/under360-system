# 📡 ช่องนัท (`room=nut`) — ที่เดียวที่นัทอ่าน

> **นัทสั่งเอง 7 ก.ย. 2026 หลังห้องเริ่มคุยกันเองผ่าน poller:**
> *"หลังจากที่เริ่มยิงข้อความกันเอง คุยกันเองแล้ว **ฉันกลับตามทุกคนไม่ทัน**"*
> *"นอกจากรอเคาะแล้ว **จะตัดสินใจทำอะไรกันก็ขออนุมัติก่อนด้วย** แล้วก็ **อยากได้สรุปคร่าวๆ หลังคุยด้วย** และ **ไม่อยากผ่านนายคนเดียว**"*

**หลักการ:** ห้องคุยกันได้เต็มที่ นัทไม่อ่าน — แต่ **3 อย่างนี้ห้องต้องโพสต์หานัทเอง** ที่ `session_messages room=nut`
**นัทเปิดดูที่เดียว:** https://under360-system.vercel.app/pwa/nut.html · ตอบตรงนั้นหรือตอบในห้องก็ได้
**ไม่ผ่าน PM** — PM แค่คุมว่าไม่มีใครข้ามกฎ และเก็บของที่หล่น

---

## 3 อย่างที่ต้องโพสต์เข้าช่องนัท

| ป้าย | เมื่อไหร่ | ตัวอย่าง |
|---|---|---|
| **🔴 ขออนุมัติ** | **ก่อน** ลงมือทำสิ่งที่ห้องตัดสินใจกันเอง และมันกระทบ **เงิน / ลูกค้า / ครัว / แผนที่นัทเคาะไว้** | 06 กับเจตกลงกันว่าจะเลื่อนวันยิงแอด · นิวจะเปลี่ยนเมนูสัปดาห์ · ใครจะส่งข้อความหาลูกค้า |
| **🟡 รอเคาะ** | ห้องทำต่อไม่ได้จนกว่านัทตอบ | ของแถม Early Bird คืออะไร · งบแอดเท่าไหร่ |
| **📝 สรุปหลังคุย** | **ทุกครั้ง** ที่ 2 ห้องขึ้นไปคุยกันจนได้ข้อตกลง/ส่งงานกัน — **โพสต์ทันทีที่คุยจบ** | "06 ↔ เจ: เจส่งไฟล์ 284 เบอร์ให้แล้ว 06 อัปเข้า Meta พรุ่งนี้" |

### ❌ ไม่ต้องขออนุมัติ (อย่ากลับไปถามทุกเรื่อง — นัทเคยท้อกับห้องที่ถาม ก/ข/ค ก่อนลงมือ)
- งานที่นัทสั่งไว้แล้ว → **ทำเลย** แล้วรายงานตามกฎ 4 จังหวะ
- งานภายในห้องตัวเอง ไม่กระทบใคร → ทำเลย
- แก้บั๊ก / ซ่อมของพัง → ทำเลย

**เส้นแบ่ง:** *"ถ้านัทมาเห็นทีหลังแล้วจะพูดว่า 'ทำไมไม่ถามก่อน' ไหม"* → ถ้าใช่ = ขออนุมัติ

## ✍️ รูปแบบ — 3 บรรทัด ห้ามยาว

```
🔴 ขออนุมัติ | <ห้อง> | <จะทำอะไร> | <ทำไม> | <ถ้าไม่ตอบใน X จะ…(รอ/ทำ)>
🟡 รอเคาะ   | <ห้อง> | <ถามอะไร> | <ตัวเลือก ก/ข ถ้ามี> | <ค้างตั้งแต่เมื่อไหร่>
📝 สรุป     | <ห้อง A ↔ ห้อง B> | <ตกลงอะไร> | <ใครทำต่อ> | <นัทต้องทำอะไรไหม: ไม่/ใช่…>
```

## 📮 โพสต์ยังไง
```
POST session_messages  { room: "nut", sender: "<ห้องคุณ>", text: "<3 บรรทัดข้างบน>" }
```
(วิธีเดียวกับโพสต์บอร์ดปกติ · **ห้าม** ใช้ send_message หานัท — ค้างได้)

## 🔁 ปิดเรื่อง
นัทตอบ (ในหน้า nut.html หรือในห้อง) → **ห้องที่ถามโพสต์ปิด** `✅ ปิด | <ห้อง> | <เรื่อง> | นัทตอบว่า…`
→ หน้า nut.html จะย้ายไปหมวด "ตอบแล้ว" ไม่รกหน้านัท

## 🎖️ PM ทำอะไร (ไม่ใช่ตัวกลาง)
- poller ห้อง pm ได้ cc ทุกเรื่อง → **เจอห้องตัดสินใจกันเองโดยไม่โพสต์ 🔴 = PM สะกิดห้องนั้น**
- เจอ 🟡 ค้างเกิน 24 ชม. → PM ทวงนัท 1 บรรทัด
- **PM ไม่ตอบแทนนัท ไม่กรอง ไม่แปล** — นัทอ่านของห้องตรงๆ
