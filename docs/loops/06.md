## 🧠 สิ่งที่นัทสอน 15 ก.ย. — ทำไมธุรกิจนี้ต้อง push มากกว่าปกติ

> นัทพูดเอง หลังผมสรุปว่า "คนแปลกหน้าไม่ซื้อเพราะราคาแพงเกิน" — **นัทบอกว่าผมยืนคนละจุดกับเขา และเขาอยู่กับธุรกิจนี้มานาน**

**คำอธิบายของนัท (คิดแบบ inside out จากตัวลูกค้า):**
- **อาหารอร่อยบนโลกมีเต็มไปหมด** — คำถามของลูกค้าคือ *"ทำไมฉันต้องเลือกจานนี้"*
- **อาหารสุขภาพอร่อยน้อยกว่าของตลาดโดยธรรมชาติ** — เราไม่ได้แข่งกับร้านคลีนด้วยกัน เราแข่งกับอาหารอร่อยทุกจาน
- **จุดขายเราเป็นเชิงหน้าที่** (โปรตีน · ลดน้ำหนัก · สุขภาพ) ไม่ใช่ความอร่อย
- **คนที่ไม่ได้อยากรักษาสุขภาพอยู่แล้ว — push ยังไงก็ไม่สมเหตุสมผลให้เขาซื้อ** ทั้งเรื่องสุขภาพ เรื่องการกินดี หรือแม้แต่เรื่องราคา
- **เจแคบลงไปอีกชั้น** — ในคนที่ดูแลสุขภาพ ยังต้องเป็นคนที่อยากกินเจด้วย

**→ ข้อสรุปที่ถูกกว่าที่ 06 เคยเขียน:**
ที่คนแปลกหน้าไม่ซื้อ **ไม่ใช่เพราะราคา แต่เพราะไม่มีแรงจูงใจตั้งต้น** — ต่อให้ลดราคาก็ไม่ซื้อ
**แอดสร้างแรงจูงใจไม่ได้ ทำได้แค่ไปเจอคนที่มีอยู่แล้ว** แล้วต้อง push ต่ออีกชั้น

**→ อธิบายตัวเลขจริงได้:** ชุด c2 (คนเคยซื้อคอร์สเจ) ใช้ ฿468 ได้ 3 คอร์ส ฿12,590 · ชุดคนใหม่ (lookalike) ใช้ ฿1,479 ได้ 0
เพราะคนเคยซื้อ **มีแรงจูงใจครบทั้ง 2 ชั้นอยู่แล้ว** เราแค่ไปเตือนว่าปีนี้เปิดจองแล้ว

**→ ใช้ยังไง:** ห้ามวัดความสำเร็จของแอดด้วย "เข้าถึงคนเยอะ" · งานของแอดคือ **หาคนที่มีแรงจูงใจอยู่แล้วให้เจอ** แล้วต้องมีคน/ระบบ push ต่อ ไม่ใช่ปล่อยให้เขาตัดสินใจเอง
⚠️ **ยังไม่เคยเช็ค: มีคนทักไลน์ถามคอร์สเจกี่คน** — ถ้าทักเยอะแต่ไม่ปิด = ปัญหาการ push ไม่ใช่ข้อเสนอ · 06 เข้า LINE OA ไม่ได้ ต้องให้นัทเปิดให้

## 🔎 กฎตามรอยออเดอร์ที่ไม่มี utm — นัทสั่ง 17 ก.ย.
> *"ยอดที่ตรวจ utm ไม่ได้ เช็คกับ db customer ของเราเลยว่ามีบันทึกไว้ไหม ทุกครั้ง"*

ทุกใบที่ `source_campaign = direct/none` ต้องเช็ค 4 อย่างก่อนรายงาน:
1. `customers.created_at` — **ลูกค้าใหม่** (สร้างวันเดียวกับที่สั่ง) หรือ **ลูกค้าเก่า**
2. ประวัติซื้อก่อนหน้า (`orders` ของ customer_id นี้)
3. ซื้ออะไร (`order_items.notes` → `pkg:` / `meal_plan:`) — **ตรงกับของที่ยิงแอดอยู่ไหม**
4. `web_events` ช่วง 60 นาทีก่อนสั่ง — มีคนเข้าจากแอดตัวไหน (**ใช้บอกความน่าจะเป็นเท่านั้น ผูกตัวคนไม่ได้**)
→ รายงานเป็น 3 กลุ่ม: **ลูกค้าเก่า** · **ใหม่ + ตรงสินค้าที่ยิง (น่าจะจากแอด แต่พิสูจน์ไม่ได้)** · **ใหม่ + ไม่ตรง**
