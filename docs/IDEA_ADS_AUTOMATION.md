## ⚖️ ประเมินตรงๆ (ยังไม่ต้องตัดสินใจ)

**สิ่งที่คุ้มจะทำจริง** (ถ้าวันหนึ่งนัทสั่ง):
1. 🥇 **ต่อ Meta Marketing API อ่านอย่างเดียว** → ดึง spend/CTR/CPC รายแอดเข้า DB เอง แล้ว join กับ `orders.source_campaign` = **ได้ ROAS จริงเป็นบาท ซึ่งไม่มีใครในโพสต์นั้นทำได้** (เขาได้แค่ ROAS ที่ Meta เดา)
2. 🥈 **dashboard เทียบแคมเปญเก่า→ใหม่** — ต่อยอดจาก command center ที่มีอยู่
3. 🥉 คำแนะนำอัตโนมัติ "ครีเอทีฟตัวนี้เริ่มเบื่อแล้ว ควรเปลี่ยน" (CTR ตก)

**สิ่งที่ไม่ควรรีบ:**
- ❌ **auto เปิด/ปิด/เพิ่มงบเอง** — เจ้าของไอเดียเองยังบอกว่าพลาดบ่อยและต้องเปิดคอมค้าง · ของเรา *"เงินไหล"* คือความเสี่ยงหลัก **วันจบอัตโนมัติปลอดภัยกว่า**
- ❌ **ซื้อ adsdevil** — ต้องให้สิทธิ์เข้าบัญชีโฆษณา ยังไม่รู้จักเจ้านี้ · และเราต้องการ **ROAS จากยอดขายจริงในหลังบ้านเรา** ซึ่งเครื่องมือภายนอกเข้าไม่ถึง

**เงื่อนไขก่อนเริ่ม:** ยิงแอดรอบนี้ให้จบก่อน มีข้อมูลจริงสัก 5 วัน — ทำ dashboard ตอนไม่มีข้อมูลจะได้หน้าจอสวยที่ว่างเปล่า
