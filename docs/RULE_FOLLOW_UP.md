# 📌 กฎกลาง — เรื่องที่นัทคุยค้าง ห้ามปล่อยหาย

> **นัทสั่งเอง 20 ส.ค. 2026 (คำต่อคำ):**
> *"ถ้านัทเปลี่ยนเรื่องระหว่างคุยให้เก็บเรื่องที่คุยค้างไว้ เก็บใน **สิ่งที่ต้องตามมาคุยด้วยเสมอ** และหากมีหลายเรื่องก็**ต้องตามให้ครบ จนกว่านัทจะปัดงานนั้นตกไป**"*

**บังคับใช้ทุกห้อง ทุกแทร็ค ทุกเอเจนต์ — ไม่มีข้อยกเว้น**

---

## 🧠 ทำไมกฎนี้ถึงเกิด

นัททำงานหลายเรื่องพร้อมกัน มักผ่านมือถือ · **นัทนึกเรื่องใหม่ได้ระหว่างที่กำลังคุยเรื่องเดิม แล้วต้องรีบพูดก่อนลืม**

→ ของที่หายมี **2 อย่าง ไม่ใช่อย่างเดียว:**
1. เรื่องที่กำลังคุยค้างไว้
2. 🔴 **เรื่องที่นัทเพิ่งนึกได้แล้วยังพูดไม่หมด** ← อันนี้ไม่เคยมีใครเก็บ และเป็นตัวที่นัทเสียดายที่สุด

**การเปลี่ยนเรื่องของนัท ≠ การยกเลิกเรื่องเดิม** — เป็นการพักไว้เฉยๆ

---

## ✅ ต้องทำอะไร — 4 ข้อ

### ① นัทเปลี่ยนเรื่อง = **เขียนลงไฟล์ทันที ก่อนเริ่มเรื่องใหม่**
**ห้ามเก็บไว้ในหัวเด็ดขาด** — context เต็มเมื่อไหร่ = หายเกลี้ยง จำข้าม session ไม่ได้

**ที่เก็บ:** `docs/OPEN_LOOPS.md` (กลาง) หรือไฟล์ค้างของห้องตัวเอง — **ขอแค่เป็นไฟล์ ไม่ใช่ความจำ**

```
| เรื่องอะไร | ค้างตั้งแต่เมื่อไหร่ | ค้างตรงไหน | รออะไร/ใครเคาะ |
```

### ② ถามเก็บตกทันที 1 บรรทัด
ถ้ามีเค้าว่านัทกำลังจะพูดอะไรต่อ → *"เรื่องที่นัทเพิ่งนึกได้ จดไว้ให้ก่อนไหมครับ"*
**นี่คือจุดที่กู้ของหายได้มากที่สุด — อย่าข้าม**

### ③ งานใหม่จบแล้ว → **ยกเรื่องที่พักไว้ขึ้นมาเอง**
**ไม่ต้องรอนัทนึกได้** · ยก **ทีละเรื่อง** ไม่ใช่ยกมาทั้งกอง

### ④ ตามให้ครบทุกเรื่อง จนกว่านัทจะปัดตก
**"นัทไม่ตอบ" ≠ "เรื่องจบ"** · เรื่องจะปิดได้ทางเดียวคือ **นัทบอกเองว่าไม่เอาแล้ว/ทำแล้ว**

---

## 🔚 ปิดเรื่องยังไงให้ถูก

| สถานะ | หมายความว่า |
|---|---|
| ✅ **นัทเคาะ/สั่งทำแล้ว** | ปิดได้ → ย้ายลงหมวด "ปิดแล้ว" |
| ❌ **นัทบอกว่าไม่เอา / ปัดตก** | ปิดได้ → **จดเหตุผลไว้ด้วย** |
| ⏸️ นัทเงียบ / ยังไม่ตอบ | **ยังไม่ปิด — ต้องตามต่อ** |
| ⏸️ ห้องคิดเองว่าคงไม่สำคัญแล้ว | **ห้ามปิด** ไม่ใช่สิทธิ์ของห้อง |

🔴 **ห้ามลบทิ้ง** — ปิดแล้วให้ย้ายไปหมวด "ปิดแล้ว" เสมอ จะได้ย้อนดูได้ว่าเคยเคาะว่าอะไร

---

## ⚠️ ที่ต้องระวัง

- ❌ **อย่าทวงรัวทุกเทิร์น** — เขียนไว้ในไฟล์ แล้วยกขึ้นมาเป็นจังหวะ
- ❌ **อย่ายกกลับมาทั้งกอง** — นัทเจอกองใหญ่แล้วจะข้ามอีก
- ✅ **ค้างเกิน 3 เรื่อง** → หยุดยกทีละเรื่อง **เปิดไฟล์ทั้งใบให้นัทเลือกเองว่าจะหยิบอันไหน**
- ✅ **คำถามที่ห้องถามแล้วนัทไม่ตอบ ก็นับเป็นเรื่องค้าง** — จดลงไฟล์เดียวกัน
- ✅ **ขึ้น session ใหม่ → อ่านไฟล์เรื่องค้างก่อนเริ่มงานเสมอ**

---

## 🎖️ พี่ปืน (PM) ทำอะไรเพิ่ม

- **รอบกวาดทุกวันเช็คว่าห้องไหนมีเรื่องค้างที่ไม่ขยับ** → ทวงห้องนั้น
- นัทถามว่า *"เหลืออะไรบ้าง"* → **PM รวบจากทุกห้องมาให้แผ่นเดียว**
- **ห้องปิดเรื่องเองโดยนัทไม่ได้เคาะ = PM เปิดกลับ**

*ต่อยอดจาก skill `skip-turn` (ระดับตัวนัท) — ฉบับนี้ = ระดับทุกห้องของ Under360*

# 📡 ส่วนที่ 2 — รายงาน 4 จังหวะ (แก้ปลายทาง 1 ก.ย. 2026)

> **ที่มา:** นัทเห็นห้องนิวเขียนว่า *"ส่งเข้าห้องเตียงแล้ว (+ แจ้งพี่ปืน ให้รู้ว่างานเดินถึงไหน)"* แล้วบอกว่า **ถูกใจมาก** และถามว่าห้องไหนไม่ทำแบบนี้บ้าง
> **ผลตรวจ: กฎนี้ไม่เคยถูกเขียนไว้เลย** — นิวทำเองด้วยสัญชาตญาณ · ห้องอื่นเลยทำบ้างไม่ทำบ้าง **ไม่ใช่ความผิดใคร แต่คือกฎหาย**

## 🔄 แก้ 1 ก.ย. 2026 — **รายงานกลับ "คนที่สั่งงาน" ไม่ใช่กลับพี่ปืนเสมอไป**

> **นัทชี้เอง:** *"กฎ 4 จังหวะน่าสนใจ แต่**มันต้องเกิดจากการที่นายคุยให้หรือเปล่า ถ้าฉันเข้าไปคุยเองหละ** · เฟสนี้**หลายๆ ห้องยังต้องการฉันอยู่ ถ้าฉันไปคุยเอง จะได้เนื้อๆ มากกว่า** · แต่ฉันชอบ 4 จังหวะนี้นะ **มันทำให้เราทำงานกันโดยอัพเดทกันไปแล้ว**"*

**PM ตั้งผิดเอง** — ตั้งปลายทางเป็นตัว PM ทั้งที่ควรเป็น **คนที่สั่งงาน**

```
ใครสั่งงาน  →  ห้องรายงานกลับ "คนนั้น" 4 จังหวะ
                        └── PM ได้สำเนาไว้ดูภาพรวม
```

| สถานการณ์ | รายงานใคร |
|---|---|
| **นัทเดินเข้าห้องสั่งเอง** | **รายงานนัท** · PM ได้สำเนา |
| **PM จ่ายงาน** | **รายงาน PM** · นัทไม่ต้องอ่าน |
| **ห้องอื่นส่งงานต่อให้** | **รายงานห้องนั้น** · PM ได้สำเนา |

✅ **นัทเข้าไปคุยเองได้เต็มที่ ไม่กระทบอะไร — และยังได้ 4 จังหวะที่นัทชอบ**

---

## 🎯 ทำไมต้องมี
นัทมีห้องต้องคุยเกือบ 20 ห้อง · **ถ้าต้องไล่ถามทีละห้องว่างานถึงไหน = นัทกลายเป็นคอขวดเอง**
**รายงาน 4 จังหวะ = งานไม่หายระหว่างทาง · และคนที่สั่งงานรู้เองโดยไม่ต้องไล่ถาม**

## ⏱️ แจ้ง 4 จังหวะนี้เท่านั้น (ไม่ต้องรายงานทุกขั้น)

| จังหวะ | แจ้งว่าอะไร |
|---|---|
| **① รับงานแล้วเริ่มทำ** | "รับแล้ว กำลังทำ คาดว่าเสร็จ…" |
| **② ส่งงานต่อให้ห้องอื่น** | "ส่งให้ห้อง X แล้ว" ← **สำคัญที่สุด** เพราะนี่คือจุดที่งานหายบ่อยที่สุด |
| **③ เสร็จ / ขึ้น main** | "เสร็จแล้ว + หลักฐาน (commit/ตัวเลข)" |
| **④ ติด / ไม่ทัน / ต้องรอใคร** | "ติดที่… ต้องการ…" ← **ยิ่งติด ยิ่งต้องบอกเร็ว** |

## 🚫 ไม่ต้องแจ้ง
รายละเอียดวิธีทำ · ทุก commit · ทุกครั้งที่คิดอะไรออก — **คนสั่งงานดูภาพใหญ่ ไม่ได้ดูขั้นตอน**

## ✍️ รูปแบบ — 3 บรรทัดพอ

```
[ห้องคุณ → <คนที่สั่งงาน>] <เรื่องอะไร>
สถานะ: รับแล้ว / ส่งต่อให้ X / เสร็จ (หลักฐาน) / ติดที่ Y
ต่อไป: <ใครทำอะไรต่อ>
```

## 📮 ส่งยังไง
**ยิงตรงหาคนที่สั่งงาน** ด้วย `mcp__ccd_session_mgmt__send_message`
· **นัทสั่ง → รายงานนัท** · **PM สั่ง → รายงาน PM** · **ห้องอื่นสั่ง → รายงานห้องนั้น**
· **ทุกกรณี cc `pm` ไว้ด้วย** เพื่อให้ PM เห็นภาพรวม (บอร์ด `session_messages` room=`pm` ก็ได้ ไม่ต้องยิงตรง)

## 📊 พี่ปืนวัดยังไง
เทียบ **"ทำงานล่าสุดเมื่อไหร่"** กับ **"บอกพี่ปืนล่าสุดเมื่อไหร่"**
🟢 ห่าง < 6 ชม. · 🟡 6-24 ชม. · 🔴 เกิน 24 ชม. หรือไม่เคยเลย
**ห้องที่ 🔴 = พี่ปืนจะไปถาม ไม่ใช่ไปตำหนิ** — ส่วนใหญ่แปลว่าติดอะไรอยู่แล้วไม่ได้บอก
