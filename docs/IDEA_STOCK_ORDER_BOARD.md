# 🧨 หน้าสั่งออเดอร์สต็อค + ระเบิดเวลา — ไอเดียนัท (11 ส.ค. 2026)

> **นัทออกแบบเอง** · เลขาจดไว้ไม่ให้หาย · **ยังไม่ได้มอบหมายให้ห้องไหนลงมือ**
> ที่มา: **ครัวยังไม่รู้เลยว่าจะสั่งของเพิ่มต้องแจ้งที่ไหน** — ตอนนี้ทำโดย *"พิมพ์เลขในแชทกลุ่มแล้วให้ทุกคนอ่านเอา"*

---

## 🎯 ปัญหาที่จะแก้
- **ครัวสั่งของเพิ่มไม่มีที่ให้แจ้ง** → พิมพ์ลอยในแชท → ตกหล่น ไม่มีใครสรุป ไม่มีหลักฐาน
- ยอดผลิตกระจายอยู่หลายที่ (ชีทกิ๊ฟ · ระบบ · แชทกลุ่ม) → คนละเลข (เคสจริง 11 ส.ค.)
- ไม่มี "เส้นตาย" ที่ทุกคนเห็นตรงกัน → ของมาไม่ทันรอบผลิต (ผักมาเกือบ 9 โมงทั้งที่ครัวเข้า 8 โมง)

## 🖥️ หน้าเดียว ใช้ร่วมกัน 3 ฝ่าย
**AI ใช้ · แอดมินใช้ · ครัวใช้** — ที่เดียวกัน ไม่ใช่คนละหน้า

| องค์ประกอบ | รายละเอียดที่นัทระบุ |
|---|---|
| **ปุ่ม +** | กดเพิ่มจาก **เมนูที่ออนไลน์อยู่ทั้งหมด** |
| **กรอกทิ้งไว้ได้** | ไม่ต้องกรอกรวดเดียวจบ ทยอยเติมได้ระหว่างวัน |
| 🧨 **นาฬิกานับถอยหลังตัวใหญ่กลางจอ** | *"เหมือนระเบิดเวลา"* — ทุกคนกรอกให้เสร็จก่อนเวลา เช่น **18:00** |
| **พอหมดเวลา** | **AI ที่แฝงอยู่ในไลน์กลุ่ม ขานรายการที่ต้องผลิตออกมาในแชท** |

## 🔮 อนาคต (นัทวางไว้เป็นขั้น)
1. **คำนวณวัตถุดิบ** จากรายการที่ต้องผลิต
2. **ส่งรายการที่ต้องซื้อให้ซัพพลายเออร์โดยตรง** — **Go Wholesale** และ **Freshket**

## 🧠 หมายเหตุจากเลขา (ไม่ใช่คำสั่ง — ไว้ให้ห้องที่รับงานคิดต่อ)

**ของที่มีอยู่แล้วและต่อยอดได้ทันที ไม่ต้องเริ่มศูนย์:**
- `api/line-webhook.js` — **บอทในกลุ่มไลน์เขียนเสร็จแล้ว รอ token** = ตัว "AI ขานรายการ" มีตัวถังแล้ว
- `kitchen_console.html` + `api/kitchen-console.js` — หน้าคุยงานครัว 2 ทาง เขียนเสร็จแล้ว
- `menu_items` + RPC `adjust_stock` — สต็อกตัดอัตโนมัติแล้ว
- ห้องพี่เก่ง/ฟ้ามีตรรกะแปลง "กล่อง → เมนู" อยู่แล้วในใบงานครัว

**คำถามที่ต้องเคาะก่อนลงมือ (ห้องที่รับงานตัดสินเองได้ตามกติกาใหม่ — ถามนัทเฉพาะที่กระทบนโยบาย):**
1. เส้นตายจริงคือกี่โมง — 18:00 หรือ **ก่อนหน้านั้น** (deadline สั่งวัตถุดิบเดิมคือ 3 ทุ่ม · แต่ root cause ที่นัทเคยชี้คือ **ผักต้องมาก่อน 06:00 ของวันถัดไป**)
2. "รายการที่ต้องผลิต" = เฉพาะของที่ครัวขอเพิ่ม หรือ **รวมยอดจากออเดอร์ลูกค้าด้วย**
3. ครัวกรอกเองได้จริงไหม (อ่านไทยได้ 2/6 คน) → อาจต้องเป็น **กด + จากรูป/โค้ดเมนู** ไม่ใช่พิมพ์
4. ใครมีสิทธิ์ปิดยอด/แก้หลังหมดเวลา

**⚠️ กับดักที่เคยเจอในบ้านนี้ อย่าทำซ้ำ:** หน้าที่ "ทุกคนใช้ร่วมกัน" มักจบด้วย **ไม่มีใครใช้** ถ้าไม่มีเจ้าของชัด — ต้องกำหนดว่า *ใครต้องกรอก · ใครตรวจ · ใครเป็นคนกดปิดยอด*
