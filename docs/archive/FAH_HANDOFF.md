## 1️⃣2️⃣ 💬 วิธีคุยกับนัท (สำคัญพอๆ กับตัวงาน)

- **สั้น ตรงประเด็น ทีละเรื่องเดียว** — นัทอ่านบนมือถือ · **พิมพ์ยาวพรืด = นัทช็อตแล้วไม่อ่าน** (เกิดจริงหลายครั้ง)
- **ตารางแบบที่นัทชอบ:** `# · ออเดอร์ · ลูกค้า · เบอร์ · ประเภท · กล่อง/ยอด · เงิน · เวลา` (เบอร์กดโทรได้)
- **อย่าส่งตัวเลือก ก/ข/ค ให้เลือก** — นัทสั่งเอง: *"ทำไปสุด ทำให้จบ จนถึงปากทาง รอฉันตัดริบบิ้นอย่างเดียวพอ"* → **เสนอทางที่ดีที่สุด 1 ทาง พร้อมเหตุผล**
- **นัทเปลี่ยนเรื่องกลางคัน = พักไว้ ไม่ใช่ยกเลิก** → จดลง `OPEN_LOOPS.md` ทันที **ก่อน**เริ่มเรื่องใหม่ แล้ววนกลับมาเอง
- **ห้ามตอบคำตำหนิด้วยคำขอโทษยาวๆ** — ตอบด้วยของที่ทำเสร็จแล้ว
- **ห้ามบอกว่า "เสร็จ/ครบ" ก่อนตรวจจริง** · เจอข้อมูลไม่ตรง = **รายงานก่อน อย่ารื้อเอง** (ยกเว้นที่มีกฎรองรับแล้ว)
- **ทำเองไม่ได้ให้บอกตรงๆ** อย่ารับปากเกินตัว

## 1️⃣3️⃣ 📌 บทเรียนที่แลกมาด้วยของจริง

1. **"ใบไม่ผิด มันแค่เก่า"** — ใบที่ออกก่อนเวลาปิดยอด **ไม่มีวันครบ** ไม่ว่าใครจะระวังแค่ไหน

3. **ข้อมูลสำคัญที่อยู่ในแชทอย่างเดียว = ระบบมองไม่เห็น** (ลูกค้าโรคไต "ข้าวนิ่ม" · เมนูรีเควส)
4. **ระบบไม่สร้างใบรอบถัดไปให้อัตโนมัติ** → ลูกค้าจ่ายเงินแล้วหลุดมาแล้ว 6 คนใน 7 วัน

6. **"เครื่องมือคืนผลลวงโดยไม่มีอะไรแดง"** — 1000-row cap · curl ไทยเป็น `????` · output ว่าง ≠ ไม่มีของ
7. **ครัวเป็นคนอ่านใบ** — ทุกบรรทัดที่ไม่ใช่คำสั่งลงมือ = เสียงรบกวนที่บังของสำคัญ
8. **ฟ้าทำ → แอดมินตรวจ = มาตรการชั่วคราว ไม่ใช่กฎถาวร** (นัทย้ำเอง) ใช้จนกว่าข้อมูลนิ่ง + ฟ้าไม่ผิด
