## ✅ สิ่งที่มีแต่นัททำได้ — 5 นาที (ทำก่อน แล้วโค้ดค่อยตามมา)

### ขั้นที่ 1 · เอากุญแจจาก Omise
1. เปิด `dashboard.omise.co` → เมนู **Keys**
2. ก๊อป 2 ค่านี้ (มี 2 ชุด: **Test** กับ **Live** — **เอา Live**)
   - `pkey_live_...` ← กุญแจสาธารณะ (ฝังในหน้าเว็บได้ ไม่เป็นความลับ)
   - `skey_live_...` ← **กุญแจลับ ห้ามส่งให้ใครรวมทั้งผม**

### ขั้นที่ 2 · ใส่ใน Vercel
`vercel.com` → โปรเจค `under360-system` → **Settings → Environment Variables** → Add ทีละตัว
```
ชื่อ  OMISE_PUBLIC_KEY    ค่า  pkey_live_...
ชื่อ  OMISE_SECRET_KEY    ค่า  skey_live_...
```
เลือก **Production** · กด Save
⚠️ **ใส่เสร็จบอกผม ผมจะเช็คว่าระบบมองเห็นไหม โดยไม่ต้องเห็นตัวกุญแจ**

## 🤔 3 เรื่องที่ต้องนัทตัดสิน — โค้ดเริ่มไม่ได้ถ้ายังไม่ตอบ

### ① ใครจ่ายค่าธรรมเนียม 2.57%
- **ก. ร้านออกให้** → ลูกค้าเห็นราคาเดิม สะดวกสุด · ร้านเสีย ~฿41 ต่อใบ ฿1,591
- **ข. บวกเพิ่มจากลูกค้า** → ร้านไม่เสีย · **แต่ลูกค้าเห็นราคาไม่ตรงกับที่โฆษณา** และหลายร้านโดนบ่นเรื่องนี้
- **ค. เปิดบัตรเฉพาะออเดอร์ก้อนใหญ่** (เช่น Meal Plan/คอร์ส ฿3,000 ขึ้นไป) → ค่าธรรมเนียมสูงต่อใบ แต่**ปิดการขายก้อนใหญ่ได้ง่ายขึ้นมาก**

**CC เห็นว่า ก. ตรงกับแบรนด์ที่สุด** (ราคาที่โฆษณาต้องเป็นราคาที่จ่ายจริง) — **แต่เป็นเงินร้าน นัทตัดสิน**

### ② เปิดให้จ่ายบัตรกับอะไรบ้าง
ทุกออเดอร์ · หรือเฉพาะคอร์ส/Meal Plan · หรือเฉพาะยอดเกินเท่าไหร่

### ③ ลูกค้าขอคืนเงินทำยังไง
บัตรคืนผ่าน Omise ได้ **แต่ค่าธรรมเนียม 2.57% ไม่ได้คืน** → เท่ากับร้านเสียฟรี
**ต้องเคาะว่า:** คืนเต็มจำนวน (ร้านรับส่วนต่าง) หรือ คืนหักค่าธรรมเนียม · และ **ใครมีสิทธิ์กดคืน** (แอดมินคนไหน / ต้องนัทอนุมัติไหม)
