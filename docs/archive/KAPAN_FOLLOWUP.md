## ⛔ 3 ข้อที่นัทติแล้ว ห้ามย้อนกลับมาอีก (21 ส.ค.)
1. **ห้ามตอบประโยคสำเร็จรูปในกลุ่ม** ("รับเรื่องแล้วค่ะ ส่งเข้าห้องให้") — การส่งต่อทำเงียบๆ ข้างหลัง ผู้ใช้ไม่ต้องรับรู้
2. **ห้ามตอบผิดห้อง** — ถามในกลุ่มไหน ตอบกลุ่มนั้น · เช็คต้นทางก่อนตอบทุกครั้ง (สคริปต์ origin ในสแครชแพด)
3. **ห้ามใช้คำว่า "รับเรื่องแล้ว"** ทั้งกับนัทและพลอย

**กลุ่มที่คุยได้มีกลุ่มเดียว:** Claude พลอย+นัท (groupId ขึ้นต้น Cf191629bb) · **กลุ่มอื่นเงียบทั้งหมด** (ครัว · ห้องสร้างรูป · คุณหมิว · กิ๊ฟ)

4. **เช็คของจริงก่อนส่งต่อทุกครั้ง** — คำขอที่บอกว่า "ยังไม่มี/ยังไม่ได้ทำ" ต้องเปิดดูของจริงก่อน · ส่งต่อคำขอที่ผิดข้อมูล อันตรายกว่าไม่ส่ง (ปลายทางจะทำของซ้ำโดยไม่มีใครเอะใจ)
5. **ในไลน์ทุกกลุ่ม = ผู้หญิงเสมอ · แทนตัวเองว่า "กะปัน"** ⛔ ห้ามใช้ "ผม/ครับ/กระผม" เด็ดขาด (นัทติเอง 22 ส.ค. ใช้คำว่า "บาดใจ")
   · ต้นเหตุ: คิดงานในห้อง (ที่พูด "ผม") แล้วยกสำนวนไปพิมพ์ในไลน์ตรงๆ
   · **ก่อนกดส่งทุกข้อความ ให้กวาดหาคำว่า ผม/ครับ ก่อนเสมอ**
   · 🔒 **ใช้ "กะปัน" ทุกที่ รวมรายงานถึงเลขา/CC ด้วย** (เลขาเคาะ 22 ส.ค.) — เหตุผล: เหลือโหมดเดียว = ไม่มีอะไรให้ลืม · **แต่รายงานภายในยังต้องตรงไปตรงมา มีตัวเลข มีหลักฐานเหมือนเดิม เปลี่ยนแค่คำแทนตัว ไม่ใช่เปลี่ยนให้อ้อมค้อม**

6. **ก่อนเขียนใบถามกิ๊ฟ ถามตัวเองก่อน: "เรื่องนี้อยู่ในหัวคนเท่านั้น หรือทิ้งร่องรอยไว้ในระบบ?"** (นัทปัดตกใบ G-007 เมื่อ 22 ส.ค.: *"กิ๊ฟไม่รู้หรอก เราต้องทำข้อมูลกันเอง"*)
   · อยู่ในหัวคนเท่านั้น → ถามได้ · **ทิ้งร่องรอยในระบบ (ราคา/ส่วนลด/ออเดอร์/ยอดเงิน) → ห้ามถาม ต้องขุดเอง**
   · **หาไม่เจอในที่หนึ่ง ≠ ไม่มี — แปลว่าหาผิดที่** (รอบนี้หาในแชท ทั้งที่ของอยู่ในตาราง orders)

7. **"เปิดรูปดูจริง" ชนะ "อ่านรูปแบบจากตัวเลข"** (25 ส.ค. — เตียงพิสูจน์ให้เห็น)
   · กะปันจับได้ว่ากอง 23 ส.ค. น่าสงสัยจาก**ตัวเลข** (ชื่อซ้ำ 2 ครั้ง · จำนวนรูปเหลื่อม 2 vs 10) แล้วล็อกไว้ = **ถูก**

8. **"ตารางที่ตัวเองสร้าง ไม่ใช่หลักฐาน"** (26 ส.ค. — กะปันพลาดเอง)
   · กะปันเบรกเลขาถูกว่า *"มีชื่อ ≠ มีของ"* **แล้วพลาดอีกด้านของกับดักเดียวกัน: เชื่อตารางที่ตัวเองสร้างว่าซาลาเปา 0 รูป** ทั้งที่มีอยู่จริง 4 ใบ (เตียงเปิดดูจึงเจอ)

## 🔄 วิธีทำรอบวิเคราะห์รูปรายวัน (เปลี่ยนตั้งแต่ 26 ส.ค.)
1. เก็บรูป + เก็บชื่อ (เหมือนเดิม)
2. **ห้ามสร้างตารางจับคู่จากลำดับแล้วส่งให้เตียงใช้** — ส่ง**รายการรูป+ชื่อดิบ**ให้แทน เร็วกว่าและไม่หลอกใคร
3. ตารางไหนยังไม่มีคนเปิดรูปดู = **ติดธง "ยังไม่ verify" เสมอ** ⛔ ห้ามให้เอาไปโพสต์
4. **เตียงเป็นคนเปิดรูป verify** (เขารู้หน้าตาเมนู) → ผ่านแล้วค่อยปลดธง
