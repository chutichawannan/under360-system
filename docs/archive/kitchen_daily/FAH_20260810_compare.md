## 3) ทำไมแต่ละคนถึงขาด/ผิด + วิธีแก้

### 🔴 พีช — หายทั้งคน
**สาเหตุที่เป็นไปได้:** ไม่เคย migrate เข้าระบบเลย (ไม่มีทั้งใน `orders` และ `mp_deliveries` ทุกวันที่ ไม่ใช่แค่ 10 ส.ค.) — ต่างจาก โมจิ/ฝน ที่อย่างน้อยมี sequence ของตัวเองในระบบ พีชไม่มีแม้แต่ 1 แถว
**วิธีแก้ (ทำได้จริง):**
- แอดมินสร้างออเดอร์แทนให้ (ใช้ pattern เดียวกับที่ทำให้ มีมี่/กนกวรรณ/Bright ผ่าน `operation_hub.html` → สั่งแทนลูกค้า) — เร็วสุด ทำได้วันนี้เลย
- ระยะยาว (**ต้องแจ้ง U/CC**): เช็คว่าทำไมเธอไม่เคยเข้า pipeline สร้าง `MP-` order อัตโนมัติเหมือนคนอื่น (โบว์/โอ๋/Milk/วิไลลักษณ์ มี pattern `MP-08xx-0xx` ครบ แต่พีชไม่มีเลยสักใบ) — อาจเป็นชื่อ/เบอร์ไม่ match ตอน sync จากชีท

### 🟡 วิไลลักษณ์ — เกิน 6 กล่อง (13 แทน 7)
**สาเหตุ:** `order_items` ของ `MP-0810-901` มีชุดเมนูซ้ำ 2 รอบ (rอบ 2/3 ปรากฏ 2 ครั้ง ครั้งที่สองขาด LC16) — ลักษณะเหมือน insert ซ้ำตอนสร้างออเดอร์ (อาจเกิดจาก retry/duplicate call ตอน sync จากชีท)
**วิธีแก้:** ต้องลบ 6 รายการที่ซ้ำออกจาก `order_items` ให้เหลือชุดเดียว 7 เมนู (LC01,02,03,06,08,14,16) — **ฟ้าเขียน SQL ให้ แต่ไม่รันเอง ให้นัท/CC ตรวจก่อน:**
```sql
-- ตรวจก่อน (ดูว่าอันไหนคือ 6 แถวซ้ำ)
select id, menu_code, quantity, notes from order_items
where order_id = '658c73e6-a307-40a1-b1a2-3cf0e58d0e01'
order by menu_code;
-- ลบเฉพาะ id ที่ซ้ำ (เลือก 6 id ที่เป็นชุดที่สอง หลัง verify ด้วยตา)
```

### 🟡 Milk — เกิน 1 กล่อง (7 แทน 6)
**สาเหตุ:** `order_items` ของ `MP-0810-015` มี LC01 ตั้ง `quantity=2` (ที่เหลือ qty=1 ปกติ) — ทำให้รวมเป็น 7 ทั้งที่สั่งแค่ 6
**วิธีแก้:** แก้ `quantity` ของแถว LC01 ในออเดอร์นี้จาก 2 → 1 (**เสนอ SQL ให้ตรวจ ไม่รันเอง**):
```sql
select id, menu_code, quantity from order_items
where order_id = 'a5fcc9e1-efa7-4ae3-af35-e43051bdd6f3';
-- แก้ id ของ LC01 ให้ quantity=1
```

### 🔴 โมจิ — มีคิวจริงแต่ order_items ว่างเปล่า
**สาเหตุ:** ระบบสร้างออเดอร์ตามรอบของเธอเอง (sequence 7,10,12,14,17,19,21,24,26,28 ส.ค. — ทุก 2-3 วันต่อเนื่อง ไม่ใช่ผูกกับ Mon/Wed/Fri ของแผนหลัก) — **ไม่เกี่ยวกับแถว "10 Aug" ที่หลงอยู่ในบล็อก 2 ก.ย. ของชีทเลย เป็นคนละกลไก** — แต่ไม่มีใครไปแพลนเมนูให้รอบนี้ (order_items ว่าง)
**วิธีแก้:** ต้อง**ถามนัทก่อน**ว่าโมจิควรได้เมนูชุดไหนวันนี้ (เธอไม่อยู่ในบล็อกสะอาดของชีท เลยไม่รู้ core เธอควรเป็นชุดเดียวกับ 9 คนบนไหม) — ถ้าตอบว่า "ใช่ ให้กินชุดเดียวกับกลุ่ม HP" → เติม HP01,02,03,06,08,14,16 เข้า `order_items` ของ `MP-0810-020`

### 🟡 ฝน — จัดเมนูไม่ครบ (2/7)
**สาเหตุ:** เหมือนโมจิ — มี sequence จริงของตัวเอง (5,7,10,12,14,17,19,21,24 ส.ค.) แต่ order_items มีแค่ HP11+HP14 (ไม่ตรงกับ core 7 เมนูของกลุ่มอื่นเลย)
