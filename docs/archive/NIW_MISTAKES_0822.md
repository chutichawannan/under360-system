## 🎓 บทเรียนหลัก — "เขียน DB สำเร็จ ≠ ลูกค้าเห็น"

ผม PATCH แล้ว query อ่านกลับทุกครั้ง เห็น `is_available=true ✅` แล้วรายงานว่าเสร็จ
**แต่ `is_available` เป็นแค่ 1 ใน 5 เงื่อนไขที่ทำให้เมนูโผล่หน้าลูกค้า**

เมนูจะขึ้นหน้าลูกค้าได้ ต้องครบ **5 ช่อง**
1. `is_available = true`
2. `category` ตรงกับแท็บที่ลูกค้าเปิด (`no_special` = ข้าวกล่อง · `pack_regular` = โปรตีนแพค)
3. `subcode` = ชื่อเล่น S1-S8 / D1-D5 **และของสัปดาห์ก่อนต้องถูกลบ**
4. `kitchen_data.menu_special_weeks[code]` = วันจันทร์ของสัปดาห์นั้น (ป้าย "สัปดาห์หน้า 24-30")
5. `image_urls[0]` + `kcal/protein/carb/fat`

⚠️ **แพทเทิร์นเดิมที่ซ้ำ:** คืนก่อนหน้าเพิ่งเจอ "แซลมอนไปอยู่ช่องเกี๊ยว" ตอนเรนเดอร์ดูด้วยตา แล้วเขียนบทเรียนว่า *"ชื่อไฟล์ถูก ≠ รูปถูก"*
**แต่ไม่ได้เอากฎเดียวกันมาใช้กับเมนู** — ผิดซ้ำที่ชั้นเดียวกันภายใน 24 ชม.

## ✅ กฎที่มีผลตั้งแต่สัปดาห์หน้า

1. 🔴 **ห้ามตั้ง `is_available=true` เองเด็ดขาด** เตรียมได้ทุกอย่าง แต่สวิตช์นี้นัทกดคนเดียว
2. 🔴 **ก่อนบอกว่า "ขึ้นแล้ว" ต้องเปิดหน้าลูกค้าจริงแล้วดูด้วยตา** — ไม่ใช่ query DB แล้วสรุป
3. 🔴 **รัน `node scripts/niw/check_week_live.mjs` ทุกครั้ง** ตรวจครบ 5 ช่องข้างบน + เทียบกับสัปดาห์เก่า
4. **แก้ข้อมูลหลายแถว ต้องลิสต์รายการออกมาดูก่อนเสมอ** ห้าม PATCH ด้วยเงื่อนไขกว้าง ๆ
5. **หาไม่เจอ ให้พูดว่า "หาไม่เจอ"** ห้ามพูดว่า "ไม่มี"
