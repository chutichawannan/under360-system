4. เรนเดอร์อัตโนมัติ (ถ้าต้องทำจากเครื่อง): Chrome `--headless=old --disable-gpu --hide-scrollbars --window-size=1040,<สูง> --virtual-time-budget=12000 --screenshot=out.png "file:///<path>"`
