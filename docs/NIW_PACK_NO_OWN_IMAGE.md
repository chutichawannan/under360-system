# แพคกับข้าว (D) ที่ยังไม่มีรูปของตัวเอง

> นัทสั่ง 11 ก.ย. 2026: *"ทำ list เมนูที่เป็นแพ็คกับข้าวแต่ว่าไม่มีรูปเป็นของตัวเองไว้ เผื่อในอนาคตจะให้ chatgpt generate ภาพที่มีแต่กับข้าวให้อย่างจริงจัง"*
> นัทยืนยันพร้อมกัน: รูปที่ติดข้าว/ติดของที่ไม่มีมาบ้าง **ใช้ได้ ไม่มีปัญหา** — ลิสต์นี้ไว้ทำรูปให้สวยขึ้นทีหลัง ไม่ใช่ของเสีย
> วิธีตรวจ: ดาวน์โหลดรูปจริงทุกตัวแล้วเทียบไฟล์ (sha1) ไม่ได้ดูแค่ชื่อไฟล์ · D ทั้งหมด 114 ตัว · ตรวจ 11 ก.ย. 2026
