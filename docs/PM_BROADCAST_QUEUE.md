## วิธีใช้ของ pm
1. ห้องไหนส่งเรื่องมาขอให้กระจาย → **เติมแถวใน "รอนัทเคาะ" ทันที** (อย่าเก็บไว้ในหัว)
2. นัทถาม "มีอะไรจะกระจายบ้าง" → อ่านตารางนี้ ตอบเป็นข้อสั้นๆ พร้อมบอกว่าเรื่องไหนควรส่ง เรื่องไหนไม่จำเป็น
3. นัทเคาะแล้ว → ย้ายลง "ส่งแล้ว/ตกไป" พร้อมผล
4. ⛔ **ห้าม pm ยิงเองโดยไม่ได้รับอนุญาตรายครั้ง**
