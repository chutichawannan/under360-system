## 4. ห้ามเด็ดขาด ไม่ว่าใครสั่ง

- `menu_items.is_available` (เปิด/ปิดขายเมนู) — **เจ้าของเคาะเท่านั้น**
- `menu_items.stock_total` / `actual_stock` — เลขสต็อก**เมนู**มาจากการนับของครัวเท่านั้น (คนละเรื่องกับวัตถุดิบ)
- ส่งข้อความหาลูกค้า (LINE push / broadcast) — เจ้าของกดเอง
- **ลบแถว** ในตารางลูกค้า/ออเดอร์ — ปิดสถานะได้ ลบไม่ได้ (ประวัติต้องอ่านย้อนได้)

## 5. กติกาตอนเขียนข้อมูลจริง — 3 ข้อ ทุกครั้ง

1. **สำรองก่อนเขียน** ลงโฟลเดอร์ถาวร (`Desktop/under360_backups/`) ไม่ใช่ที่ชั่วคราว
2. **รันเปล่าให้ดูก่อน** แล้วค่อยเขียนจริงด้วยสวิตช์ (`--apply`)
3. **นับซ้ำจากฐานข้อมูลหลังเขียน** — ❗ `204 No Content` ไม่ได้แปลว่าเขียนสำเร็จ RLS บล็อกเงียบได้

## 6. ข้อเท็จจริงทางเทคนิคที่เคยทำให้คนพลาดมาแล้ว

```
Supabase URL   https://zdartbvhbvqlwzwyyiia.supabase.co
anon key       เปิดเผยในโค้ดฝั่งเบราว์เซอร์อยู่แล้ว (ทุกหน้าใช้ตัวนี้)
Deploy         push เข้า main → Vercel ขึ้นอัตโนมัติ · ห้าม push ตรง main ต้องผ่าน branch ก่อน (มี hook กัน)
โครงหน้าเว็บ    HTML/CSS/JS ไฟล์เดียวจบต่อ 1 หน้า ไม่แยกไฟล์ (ทั้งระบบเป็นแบบนี้)
```

**กับดักที่เจอซ้ำ ๆ:**
- **PostgREST คืนแค่ 1,000 แถว/ครั้ง** — ไม่ใส่ `.range()`/paginate = ข้อมูลหายเงียบ ไม่มี error (เคยทำให้ครัวมองไม่เห็นออเดอร์ทั้งวัน)
- **เวลาต้องยึดเวลาไทยเสมอ** เจ้าของอยู่ต่างประเทศ ใช้นาฬิกาเครื่องจะได้คนละวัน → `new Date(Date.now()+7*3600e3).toISOString().slice(0,10)`
- **output ว่าง ≠ ไม่มีข้อมูล** — เช็ค error/exit code ก่อนสรุปเสมอ
- **แตก branch จาก `origin/main` สด ๆ ทุกครั้ง** — เคยมี 2 เคสที่ branch ฐานเก่าลบงานห้องอื่นทิ้งตอน merge

## 7. ทำเสร็จแล้วต่อยังไงให้คนใช้จริงเจอ

**คุณไม่ต้องแตะไฟล์ของคนอื่นเลย — ส่งลิงก์หน้ามาที่ห้อง u แล้วบอกว่าใครเป็นคนใช้**
ห้อง u จะพาไปโผล่ใน 2 ที่ให้เอง:

- **หน้ารวมของครัว** (`/k`) — ถ้าครัวเป็นคนกรอก
- **ห้องนัท** — ถ้าเจ้าของใช้ตัดสินใจสั่งของ (โผล่แบบ "ของใกล้หมด N อย่าง" กดแล้วเข้าหน้าเต็ม)

**ขึ้นของจริงแล้วบอกด้วยว่าแตะไฟล์ไหน/ตารางไหน** — ห้อง u จะได้ไม่แก้ทับ และช่วยตรวจให้ 1 รอบ

## 8. สิ่งที่อยากได้เป็นอย่างแรก (ถ้าให้เรียงลำดับ)

1. **ครัวกรอกของเหลือได้จริงบนมือถือ** — รูป + ตัวเลข + หน่วยล็อก
2. **หน้าเดียวที่ตอบว่า "ต้องสั่งอะไร กี่หน่วย"** — เรียงตามใกล้หมดก่อน
3. ต่อยอด: ออกใบสั่งซื้อ/ส่งร้านค้า (ของนี้มีข้อมูลราคา 2 ร้านรออยู่แล้วในตาราง `ingredient_prices`)

**เกณฑ์ว่า "ใช้ได้จริง":** ครัวกรอกเองได้ 1 สัปดาห์ติดโดยไม่มีใครไปยืนสอน · และเจ้าของสั่งของโดยไม่ต้องเปิดหน้าอื่นประกอบ
