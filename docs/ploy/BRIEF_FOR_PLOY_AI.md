# 3. Positioning + กฎเขียนคอนเทนต์

## แก่นแบรนด์
> **"ไม่ขายคลีน — ขายอาหารที่เข้ากับเป้าหมายและไลฟ์สไตล์ของคุณ โดยมีโปรตีนเป็นแกน"**
> **"ไม่ใช่คลีนจนทรมาน ไม่ใช่ตามใจปากจนพัง — แต่คือ พอดี ที่กินได้ทุกวัน"**

**เส้นทางแบรนด์:** เริ่มจากคลีนสายแข็ง (อกไก่อย่างเดียว) → ไม่อร่อย ไม่ยั่งยืน → **ปรับเป็น Balanced Diet / Real Food**

## 🕯️ จิตวิญญาณแบรนด์
**"คนดูแลคน"** — ร้านโตจาก 0 เพราะ service mind ของพลอย
**ความสัมพันธ์ = ตัวสินค้าจริง** (คู่แข่งลอกเมนูได้ ลอกความสัมพันธ์ไม่ได้)
⚖️ **แต่ไม่ใช่การกุศล** — รักลูกค้าและรักกำไรเท่ากัน ห้าม over-service จนร้านเจ็บ

## ✅ เคลมได้ (มีของจริงรองรับ)
- โปรตีนดิบ **120g (LC) / 170g (HP)** ต่อกล่อง
- น้ำมันรำข้าว **ไม่เกิน 5g ต่อเมนู**
- **โซเดียมกว่า 90% ของเมนูต่ำกว่าอาหารข้างทาง**
- **ข้าว กข 43** (อร่อยเหมือนหอมมะลิ ดัชนีน้ำตาลต่ำ — ไม่ใช่ทุกเมนู)
- เลี่ยง ultra-processed ให้มากที่สุด
- **ประสบการณ์ 10 ปี**
- จัดเมนูเฉพาะคน ตัดของแพ้ได้
- **Meal Plan ส่งฟรีทุกแพ็ค** · กทม. ส่วนใหญ่ฟรี เริ่มเพียง 20 บาท · ส่งทั่วไทย

## ⛔ ห้ามเขียนเด็ดขาด
| ห้าม | เพราะ |
|---|---|
| **"เลือกเวลา/วันส่งได้"** สำหรับ Meal Plan | ส่ง จ/พ/ศ บ่ายเท่านั้น *(คอร์สจากของสต็อคเขียนได้)* |
| ดิสอาหารแช่แข็ง | เราขายฟรีซแพ็คเอง |
| **"ถูกที่สุด" / "ถูกกว่าทุกเจ้า"** | ข้อมูลคู่แข่งไม่ครบ |
| **"ส่งฟรีทุกออเดอร์"** | จริงเฉพาะ Meal Plan |
| **"ปรุงสด 10 ปี"** | 10 ปี = อายุร้าน → เขียน "ประสบการณ์ 10 ปี" |
| **"ดีที่สุด" / โม้เกินจริง** | แบรนด์เราให้ความรู้ก่อน แล้วค่อยแสดงว่าตอบโจทย์ |
| พูดถึง subsidize ค่าส่ง | คำภายในเท่านั้น |

## 🖼️ กฎรูปโฆษณา (นัทเคาะเอง — รูปสำคัญระดับต้นๆ ไม่ใช่ของแถม)
- **รูปอาหารจริงจากกล่องจริง** ห้ามสต็อกโฟโต้ (คนไทยจับผิดเก่ง และเรามีของจริง 10 ปี)
- **ให้เห็นปริมาณ** (170g / 120g เห็นด้วยตา)
- **คนกินจริง / มือถือกล่อง** ชนะรูปจัดจานสวยเกินจริง
- **ข้อความบนรูปไม่เกิน 7 คำ**
- **3 คำแรกพูดถึงลูกค้า ไม่ใช่ร้าน** — *"กินคลีนแล้วไม่ลด?"* ดีกว่า *"Under360 อาหารคลีน"*

- ⚠️ ยิงแอด FB/IG **ต้องปิด Advantage+ enhancement ทุกตัว** ไม่งั้น Meta remix รูปแล้วเพี้ยน (เคยได้รูปดำ + เมนูมั่ว)
