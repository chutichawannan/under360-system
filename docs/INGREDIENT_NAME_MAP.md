# 🔗 ตารางจับคู่ชื่อวัตถุดิบ — เรา ↔ Freshket ↔ GO

> ทำโดยห้อง **f** 16 ก.ย. 2026 · นัทสั่ง: *"ลิสวัตถุดิบทั้งจากเฟรชเก็ตและโก ขึ้นมาเพื่อแมชชื่อสินค้า ว่าวัตถุดิบเรา โก เฟรชเก็ต ใช้ชื่อแบบไหนกัน"*
> **เป้า:** ทำลิสต์ให้ตรงกัน → หน้าเช็คสต็อกแม่นขึ้น → อนาคตต่อเป็นเครื่องมือสั่งวัตถุดิบได้

## 🔴 สิ่งที่เจอทันทีที่เอามาวางข้างกัน — **3 ปัญหาที่ต้องแก้ก่อนทำเครื่องมือ**

### ① ชื่อไม่ตรงกันสักเจ้า
| เราเรียก (พิมพ์สั่งในแชท) | Freshket เรียก | GO เรียก |
|---|---|---|
| อกไก่ | **อกไก่ติดหนัง** | **อกไก่เนื้อล้วนติดหนัง 1 กก.** |
| สะโพกไก่ | สะโพกไก่ | **สะโพกไก่ติดกระดูก 1 กก.** |
| ปลากระพง | **ปลากะพงแล่ (แช่แข็ง)** ← สะกด "กะ" | — |
| แครอท | **แครอท ขนาด 3-4 ลูก/กก. คัดขนาด** | **มันแครอท 1 กก.** |
| เห็ดออรินจิ | — | **เห็ดออรินจินอก ใหญ่ แพ็ค 1 กก.** |

→ **จับคู่อัตโนมัติด้วยชื่อตรงๆ ไม่ได้** ต้องมีตารางกลางที่คนเคาะครั้งเดียว

### ② หน่วยบรรจุคนละแบบ → **เทียบราคาตรงๆ ไม่มีความหมาย**
· Freshket ขายเป็น **แพ็ค 250 ก. / 500 ก. / 1 กก.** แล้วแต่ตัว
· GO ขายเป็น **กก. / แพ็ค / ลัง**
· ตัวอย่าง: พริกชี้ฟ้าแดง Freshket ฿27 **แต่เป็นแพ็ค 250 ก. = ฿108/กก.**
→ **ตารางกลางต้องมีคอลัมน์ "หน่วยจริง" และ "฿ ต่อ กก." เสมอ** ไม่งั้นเทียบเจ้าผิดทุกครั้ง

### ③ ของชนิดเดียวมีหลายเกรด ราคาต่างกันเท่าตัว
**ไข่ไก่ ใน Freshket มี 13 แบบ** (เบอร์ 1/2/3/4 × มีฝา/ไม่มีฝา × ตราเบทาโกร/ทั่วไป) ราคา ฿130–414
**อกไก่ใน Freshket มี 4 แบบ** ฿85 / ฿101 / ฿500 / ฿575 (ลอกหนัง แพงกว่าติดหนัง)
→ **ต้องระบุว่า "เราใช้เกรดไหน" ไม่ใช่แค่ชื่อของ** ไม่งั้นเครื่องมือสั่งของจะสั่งผิดเกรด

## 🔧 วิธีดึงรายการสินค้าจากทั้ง 2 เจ้า (จดไว้ ทำซ้ำได้)

**Freshket** — หน้า `freshket.co/reorder?categoryId=<id>` = สินค้าที่เราเคยซื้อ พร้อมชื่อทางการ + ขนาดบรรจุ + ราคาป้าย
· รหัสหมวด: `86` ผักผลไม้ · `48` เนื้อสัตว์ · `44` ปลา/ทะเล · `53` ไข่ · `84` นม/เครื่องดื่ม · `85` แช่แข็ง · `87` ขนม · `83` ปรุงสำเร็จ · `77` เครื่องปรุง/อบ · `74` ของแห้ง · `76` เบเกอรี่ · `75` ของใช้ · `80` เครื่องดื่ม
· ⚠️ **แสดงหน้าละ 24 ชิ้น** — หมวดผักมีเกิน ต้องเลื่อน/แบ่งหน้าเพิ่ม
· API เบื้องหลัง `api.freshket.co/baseApi/Orders/SearchFavItems` (POST `{category_id, current_page, page_size}`) — **เรียกตรงจากหน้าเว็บไม่ได้ ติด CORS/auth** ต้องแกะจาก DOM

**GO** — หน้า `gowholesale.store/th/my-account/reorder` (แท็บ "สั่งซื้ออีกครั้ง")
· ⚠️ **ต้องคลิกแท็บก่อน ไม่งั้นรายการไม่ render**
· โชว์เฉพาะออเดอร์ `WP-` (สั่งออนไลน์เอง) · ออเดอร์ `XB-` (สั่งผ่านเซลล์ = ก้อนใหญ่) **ไม่โผล่**

## ⏭️ ที่ต้องทำต่อ (ยังไม่เสร็จ — พูดตรงๆ)
1. **ดึง Freshket ให้ครบทุกหมวด** (ตอนนี้ได้ 4 หมวด: ผัก ผลไม้บางส่วน · เนื้อ · ปลา · ไข่)
2. **เติมช่องว่างฝั่ง GO** — ต้องได้รายการสินค้าจากออเดอร์ `XB-` ซึ่งเว็บไม่โชว์ → ขอใบกำกับรายเดือนจากเซลล์
3. **ให้นัทเคาะ "เกรดที่ใช้"** ของ 3 ตัวที่มีหลายเกรด: ไข่ไก่ (เบอร์อะไร) · อกไก่ (ติดหนัง/ลอกหนัง) · พริกยักษ์ (เบอร์รอง/ชน 3 สี)
4. แล้วค่อยล็อกเป็นตารางกลาง 1 ชุด ให้หน้าเช็คสต็อก + เครื่องมือสั่งของใช้ร่วมกัน
