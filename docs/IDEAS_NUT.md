# 💡 คลังไอเดียของนัท — ที่ที่ของไม่หาย

> **นัทสั่งเอง 20 ส.ค. 2026 (คำต่อคำ):**
> *"พอมันมีของที่คิดเพิ่มได้เยอะมากๆๆๆ แล้ว อยู่ในลิส เคลียร์ออกไปไม่หมด มันเหมือนชนกำแพง **นายช่วยเก็บลิสไว้ทั้งหมดให้ทีนะ ฉันเป็นห่วงกลัวว่าที่คิดได้จะหายไปหมด**"*

**กฎของไฟล์นี้:**
- ทุกไอเดียที่นัทพูดออกมา **จดทันที ไม่ต้องรอสั่ง ไม่ต้องประเมินก่อนว่าดีไม่ดี**
- **จดให้ครบเจตนา ห้ามย่อจนเหลือ bullet เดียว** — นัทพิมพ์ยาว = ตั้งใจให้เก็บครบ
- ⛔ **ห้ามลบ** ไอเดียที่ตัดสินใจไม่ทำแล้ว → ย้ายลงหมวด "เคาะแล้วไม่ทำ" พร้อมเหตุผล
- ไอเดียที่เริ่มลงมือแล้ว → ย้ายไป `docs/OPEN_LOOPS.md` (ที่นั่นคือของที่กำลังเดิน ที่นี่คือของที่ยังไม่เริ่ม)
- 🔕 **มีไอเดียกองอยู่ที่นี่เยอะ ≠ งานค้าง** — นี่คือคลัง ไม่ใช่รายการที่ต้องเคลียร์ให้หมด **นัทไม่ต้องรู้สึกผิดกับมัน**

## 🆕 20 ส.ค. 2026 — เปลี่ยนวิธีขาย Meal Plan: โชว์ปฏิทินเมนู + ให้ลูกค้าเลือกเอง

**นัทพูดเอง:**
> *"ฉันคิดว่าฉันจะเปลี่ยนแพลนการขาย MP เล็กน้อย คือ **มีแพลนเมนูให้ลูกค้าดูเลยว่าวันไหนเป็นเมนูอะไร** ฉันไม่รู้ว่ามันจะดีไม่ดีนะ ทีแรกคิดว่าจะ **คิดไว้ 10 เมนูให้ลูกค้าเลือกได้ จะเลือกซ้ำก็ได้** แต่เงื่อนไขคือ **เมนูอาหารทะเลเลือกได้ไม่เกิน 4** และ **สัตว์บกเลือกได้สุดเลย** ทีนี้มันต้องรื้อระบบเล็กน้อยสำหรับการสั่ง เพราะมันต้องมีหน้าจอโชว์ว่าวันไหนเป็นเมนูอะไร ให้เลือกได้"*

### กติกาที่นัทเคาะไว้แล้ว
| | |
|---|---|
| ลูกค้าเห็นอะไร | **ปฏิทินเมนู — วันไหนเป็นเมนูอะไร ดูได้ก่อนตัดสินใจซื้อ** |
| ตัวเลือกที่ให้ | **~10 เมนู** |
| เลือกซ้ำ | **ได้** |
| เพดานอาหารทะเล | **ไม่เกิน 4** |
| เพดานสัตว์บก | **ไม่จำกัด** |
| ขอบเขตงาน | *"ต้องรื้อระบบเล็กน้อย"* — ต้องมีหน้าจอใหม่สำหรับดู+เลือก |

### ⚠️ สิ่งที่ต้องรู้ก่อนเริ่ม (เลขาบันทึกไว้ ไม่ใช่การคัดค้าน)
1. **ทับกับสเปคน้องนิวที่ล็อกไว้แล้ว** — ของเดิมคือ *ครัวเลือกเมนู แล้วแอดมิน/AI assign ให้ลูกค้า* + ลูกค้า request ได้ 2 เมนู/สัปดาห์ พร้อม "เซอร์ไพรส์" เป็นจุดขาย · ของใหม่คือ **ลูกค้าเลือกเองเกือบทั้งหมด** = คนละปรัชญา → **ต้องเคาะว่าจะเอาอันไหน ห้ามทำทั้งสองแบบพร้อมกัน**
2. **กระทบกำลังผลิตครัวโดยตรง** — Meal Plan คือ **ทำสด** ครัวได้เปรียบจากการทำเมนูเดียวกันหลายกล่องพร้อมกัน · ถ้าลูกค้าเลือกอิสระ ครัวอาจต้องทำหลายเมนูจำนวนน้อยๆ ในเช้าเดียว **ต้องถามนัทในฐานะหัวหน้าครัวว่ารับไหวแค่ไหน**
3. **โควตาอาหารทะเล 4 = ต้นทุน** — เดาว่ามาจากราคาวัตถุดิบทะเลแพงกว่า **ยังไม่ยืนยันกับนัท**
4. **จุดดีที่ชัดมาก** — ปฏิทินเมนูตอบคำถามที่ลูกค้าลังเลที่สุดก่อนจ่ายเงินหลักพัน: *"แล้วฉันจะได้กินอะไรบ้าง"* · ตอนนี้ตอบไม่ได้เลย = **น่าจะช่วยปิดการขายจริง แม้จะไม่เปลี่ยนเรื่องให้เลือกเองก็ตาม**
5. **ทำครึ่งเดียวก่อนได้** — ① โชว์ปฏิทินเมนูอย่างเดียว (ไม่ให้เลือก) = งานเบา ได้ผลด้านการขายทันที · ② ให้เลือกเอง = งานหนัก รื้อระบบ **แยกทำได้ ไม่ต้องรอกัน**

**สถานะ:** 🟡 ยังไม่เริ่ม — รอนัทเคาะว่าเอาแค่ ① หรือเอา ② ด้วย
**เจ้าของเมื่อเริ่ม:** u (LIFF ลูกค้า) + k/ฟ้า (กำลังผลิต) + niw (ชนกับสเปคเดิม)
