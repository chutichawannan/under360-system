## 📅 3 ช่วง

### ช่วง 1 · 17–~20 ก.ย. — "ไม่แตะ รอพ้นเรียนรู้"
- ไม่แก้ N ไม่แก้ C (นัทเคาะแล้ว)
- เตรียมของช่วง 2 ให้พร้อม:
  - ครีเอทีฟ **"เหตุผลใหม่"** 1–2 ชิ้นให้นัทเคาะ (ตามหลัก Andromeda: เพิ่มเหตุผล ไม่ก๊อปตัวเดิม)
    - *ปิดรับจอง 7 ต.ค.* (มีรูป I080 อยู่แล้ว)
    - *จอง 50 คนแรก ได้แก้วสลัดฟรี* (ต้องทำรูปใหม่)
  - กลุ่มคนเคยแวะ /jay — สร้างแล้ว รอ Meta เติมคน
- ⚠️ **~20 ก.ย. ค่าแอดจะทะลุ ฿10,000 = ด่านที่ต้องนัทเคาะใหม่**

### ช่วง 2 · N พ้นเรียนรู้ → 30 ก.ย. — "เปิดคนเคยแวะ + ขยายตัวที่คุ้ม"
- เปิด **เจ · คนเคยแวะ** ฿300/วัน · ใช้รูปเหตุผลใหม่ ไม่ใช้ c2/I096 ซ้ำ · ⏳ รอนัทเคาะงบ
- ชุดไหนค่าแอดต่อคอร์ส **ต่ำกว่า ฿1,380** → เพิ่มงบครั้งละ **ไม่เกิน 20%** ทุก 3 วัน
- ชุดไหน **ใช้ ฿1,500 แล้วยังไม่ได้คอร์ส** → เสนอนัทปิด
- Collection ad = ทำคู่ขนาน ไม่ใช่ตัวหลัก (ตกลง 1 ช่องแล้ว: "30 มื้อ ตกมื้อละ ฿139")

### ช่วง 3 · 1–7 ต.ค. — "โค้งสุดท้าย"
- คนตัดสินใจตอนใกล้หมดเวลา → **ย้ายน้ำหนักไปคนเคยแวะ + ข้อความ "เหลืออีก X วัน"**
- ไม่เปิดชุดใหม่แล้ว (ไม่ทันพ้นเรียนรู้)
- **7 ต.ค. เที่ยงคืน ปิดแอดเจทุกตัว**
