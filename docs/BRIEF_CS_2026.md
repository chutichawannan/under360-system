> **นัทสั่งเปิดเอง 1 ก.ย. 2026:** *"ตอบลูกค้าละกัน **อันนี้เป็นพาร์ทใหญ่** นายควรจะให้ฉัน**แยก session** เพราะ**ต้องผ่านการเทรนก่อน**ด้วย"*

## 🕯️ อ่านข้อนี้ก่อนอย่างอื่น — ไม่งั้นจะทำผิดทางทั้งห้อง

**จิตวิญญาณแบรนด์ Under360 = "คนดูแลคน"** (นัทเล่าเอง)
ร้านโตจาก 0 เพราะ **พลอยตอบลูกค้าเอง** · ลูกค้าดีใจทุกครั้งที่พลอยตอบ → **ความสัมพันธ์ = ตัวสินค้าจริง**
และบทเรียน Hato: **พอมีชั้นกั้นระหว่างเรากับลูกค้า → ลูกค้าหาย**

### 🔴 กฎออกแบบที่ห้ามข้าม
```
automate หลังบ้าน  =  ✅ ถูก   (คืนเวลาให้คนไปคุยกับลูกค้ามากขึ้น)
automate บทสนทนา   =  ❌ ผิด   (แทนที่คน = ทำลายตัวสินค้า)
```
**ห้องนี้มีไว้ช่วยกิ๊ฟตอบได้ทั่วถึงขึ้น ไม่ใช่มีไว้ตอบแทนกิ๊ฟ**

## 🧩 งานนี้มี 2 ครึ่ง — **อย่ารวมกัน**

### ① ลูกค้าทักเข้ามา (inbound)
- **แชท `chat.line.biz` อ่านได้เต็ม** ✅ (เอิธ verify แล้ว 22 ก.ค. ผ่าน get_page_text) — **เคยเข้าใจผิดว่าอ่านไม่ได้**
- → **ปลดล็อก "Agent QA แอดมิน"** = อ่านแชทจริง แล้วบอกว่าตอบดี/ตอบพลาดตรงไหน
- 🔴 **แท็กลูกค้าพึ่งไม่ได้** — ~95% ไม่เคยถูกแท็ก / แท็กมั่ว · แท็ก *"ติดตาม"* จริงๆ แปลว่า *"ยังไม่ซื้อ ต้องอัดโปร"* ไม่ใช่ที่ทุกคนเข้าใจ
- → **ห้ามสร้างอะไรที่พึ่งแท็ก** ใช้ข้อมูลออเดอร์แทน

### ② เราส่งหาลูกค้า (outbound) — **ข้อที่นัทค้างไว้ว่ายังไม่เคลียร์**
> **นัทพูดเอง:** *"**เราไม่เคยเทรนกันเลย** เราต้องมา clarify กัน **ยังไม่ต้องทำ**"*

## 🎓 "เทรน" ในที่นี้คืออะไร — นัทเน้นเอง

**ไม่ใช่เทรน AI — คือเทรนคนกับตกลงกันให้ตรงก่อน**

| ต้องตกลงอะไร | ทำไม |
|---|---|
| **ลูกค้าถามอะไรบ่อยสุด** | ยังไม่มีใครเคยรวบรวม |
| **คำตอบมาตรฐาน = อะไร** | กิ๊ฟกับเพอรี่ตอบไม่เหมือนกัน = ลูกค้าได้คำตอบต่างกัน |
| **น้ำเสียงแบบไหนคือของร้าน** | ต้นแบบคือวิธีที่พลอยตอบ |
| **เคสไหนห้ามให้ AI แตะ** | ร้องเรียน · ของผิด · เงิน · สุขภาพ/โรคไต |
| **เคสไหนต้องส่งต่อใคร** | โรคไต→คุณอิ๊ง · เงิน→f · ของพัง→ครัว |

## 🎯 3 อย่างแรกที่ห้องนี้ควรทำ

**1. ไปอ่านแชทจริงใน `chat.line.biz`** — อย่าเดาว่าลูกค้าถามอะไร **ของจริงเปิดดูได้**
**2. ทำรายการ "คำถามที่เจอบ่อย + คำตอบที่ใช้อยู่จริง"** ให้นัท/กิ๊ฟตรวจ ← **นี่คือ "การเทรน" ที่นัทหมายถึง**
**3. เช็คว่าใบยืนยันที่ส่งอยู่ตอนนี้ เขียนว่าอะไร และมันถูกไหม** — มันส่งจริงอยู่แล้ว

⚠️ **ห้ามยัดหลายเรื่องให้นัทในเทิร์นเดียว** — นัทบอกเอง: *"มันเยอะจนทนไม่ไหวแล้ว ขอเคลียร์ทีละเรื่อง"*
