## 🔐 ตอบเรื่อง "ซ่อนหลังบ้านไว้ใน 360foodbox.com ปลอดภัยไหม"

### ❌ ซ่อนด้วยชื่อลิงก์ = ไม่ใช่ความปลอดภัย
ลิงก์ลับกันได้แค่คน "บังเอิญเจอ" · กันคนที่ตั้งใจหาไม่ได้ · และหลุดง่ายมาก (แชร์ในแชท · ประวัติเบราว์เซอร์ · Referer)

### 🔎 ของจริงคือ: หน้าเว็บเราป้องกันด้วย **RLS** ไม่ใช่ด้วย URL
`anon key` อยู่ในหน้าเว็บอยู่แล้ว → **ใครถอดออกไปยิง Supabase ตรงก็ได้ข้อมูลเท่ากัน ไม่ต้องหาหน้าหลังบ้านเจอด้วยซ้ำ**
→ **ย้ายหน้าไปซ่อนที่ไหนก็ไม่เปลี่ยนความเสี่ยงข้อนี้เลย**

### ✅ สรุปคำตอบ: **เอาไว้บน `360foodbox.com` ได้ ไม่ผิด** แต่ต้องมี 3 ชั้นนี้

| ชั้น | ทำอะไร | ด่วนแค่ไหน |
|---|---|---|
| 1 | **กัน Google เก็บหน้า** — `noindex` + `robots.txt` disallow | 🔴 **ก่อนขึ้นจริง** |
| 2 | **โทเค็น/ความลับอยู่ฝั่ง server เท่านั้น** | 🔴 **ก่อนขึ้นจริง** |
| 3 | **ล็อกอินจริง** (Google login + allowlist อีเมล ตามที่วางไว้ใน CLAUDE.md) แทน PIN | 🟡 ตามหลังได้ |

### ⏰ ทำไมต้องรีบกว่าเมื่อก่อน
**เรากำลังจะยิงแอดพาคนแปลกหน้า + บอตเข้าเว็บเยอะขึ้น** — โดเมนที่เคยเงียบกำลังจะมีคนเดินผ่านเยอะ
โดยเฉพาะ **ตัวเลขค่าแอด/ยอดขาย = ความลับทางธุรกิจ** ถ้าโผล่ใน Google คู่แข่ง 42 รายในชีทเราอ่านได้หมด

### 📌 หมายเหตุระดับความเสี่ยง (ให้จัดลำดับถูก)
หน้านี้เก็บ **ตัวเลขโฆษณา ไม่ใช่ข้อมูลส่วนตัวลูกค้า** → เสี่ยงต่ำกว่า `orders`/`customers` มาก
**เรื่อง RLS ของตารางลูกค้าเป็นงานใหญ่กว่าและอยู่ที่ U** — บรีฟนี้ไม่ได้ขอให้แก้ตรงนั้น แค่ชี้ว่ามันคือรูจริง ส่วนชื่อลิงก์ไม่ใช่
