## 0. กติกาใหญ่ 4 ข้อ (ผิดข้อเดียวคือร้านเจ็บจริง)

1. **`main` = ของจริงที่ลูกค้ากับครัวใช้อยู่ตอนนี้** push แล้วขึ้นเว็บใน 1–2 นาที ไม่มีขั้นตอนตรวจคั่น
2. **ห้าม push ตรงเข้า main** — มี hook กันไว้ ต้องผ่าน branch ก่อนเสมอ · **แตก branch จาก `origin/main` สด ๆ ทุกครั้ง** (เคยมี branch ฐานเก่าลบงานห้องอื่นทิ้งตอน merge มาแล้ว 2 ครั้ง)
3. **1 หน้า = 1 ไฟล์** HTML+CSS+JS อยู่ด้วยกัน ไม่มี build step ไม่มี framework — แก้ไฟล์เดียวจบ
4. **แตะของที่คนใช้อยู่ ต้องเปิดดูด้วยตาก่อนบอกว่าเสร็จ** (เคสจริง 19 ก.ย.: ข้อมูลถูกครบใน DB แต่ลูกค้าเห็นเมนูเดียวจาก 13 เมนู เพราะตั้งหมวดผิด — ถ้าไม่เปิดดู ไม่มีทางรู้)

**ก่อนแก้ไฟล์ของห้องอื่น ให้บอกห้อง u ก่อน 1 บรรทัด** ว่าจะแตะอะไร — u จะบอกว่าชนใครไหม/ใครกำลังแก้อยู่
เหตุผล: มีหลายห้อง (คน + AI) ทำงานบน repo เดียวกันพร้อมกัน ไฟล์เดียวกันแก้ทับกันได้จริง

## 4. งานหน้าตา/กราฟิก — ทำยังไงให้เร็วและไม่ชนกัน

เจ้าของร้านบอกว่าจะให้ทีมคุณช่วยงานด้านนี้ด้วย ระบบรองรับอยู่แล้ว ใช้ทางนี้:

**ทางที่ปลอดภัยที่สุด (ไม่ต้องรอใคร):**
1. ก๊อปหน้าที่จะปรับไปไว้ใน `preview/<ชื่องาน>.html`
2. ปรับหน้าตาเต็มที่ในไฟล์นั้น — ของจริงไม่ขยับสักนิด
3. ส่งลิงก์ให้เจ้าของดู (`under360-system.vercel.app/preview/<ชื่องาน>.html`)
4. เจ้าของโอเค → บอก u/pm → เจ้าของไฟล์เอาไปใส่ของจริงให้ พร้อมรันเทส

**สิ่งที่ต้องรู้ก่อนแตะหน้าตา:**
- **ฟอนต์ทั้งระบบคือ Sarabun** (เจ้าของสั่งเอง — Noto อ่านยาก)
- **หน้าของครัวห้ามเพิ่มตัวหนังสือ** — ครัว 6 คนอ่านไทยออกจริง 2 คน ใช้รูป + ตัวเลข + ปุ่มใหญ่
- **รูปที่ลูกค้าเห็นในนามร้าน ต้องให้เจ้าของเคาะก่อนเสมอ** (รวมรูปเก่าที่มีอยู่ในคลัง)
- หน้าลูกค้า/หน้าครัวออกแบบมาสำหรับ **มือถือก่อน** (กว้าง 375px) ไม่ใช่จอคอม
- รูปเก็บที่ Supabase Storage บัคเก็ต `menu-images` (public) — อัปได้ผ่าน `/pwa/inbox.html`

```
□ ถ้าเขียนข้อมูล — นับซ้ำจากฐานข้อมูลว่าเขียนเข้าจริง
□ บอกห้อง u ว่าแตะไฟล์ไหน/ตารางไหน (กันคนอื่นแก้ทับโดยไม่รู้)
```

## 6. คำที่ใช้ในระบบ (จะได้คุยกันรู้เรื่อง)

| คำ | หมายถึง |
|---|---|
| **LIFF** | หน้าที่ลูกค้าเปิดจากในแอป LINE = หน้าสั่งอาหาร |
| **เมนูสต็อก (No/S/D/A)** | อาหารที่ทำล่วงหน้าแล้วเก็บไว้ขาย |
| **Meal Plan (HP/LC)** | คอร์สอาหารทำสด ส่ง จ/พ/ศ บ่าย |
| **แพค / เซ็ต** | ชุดหลายกล่องขายราคาเหมา |
| **subcode (S1–S8 / D1–D5)** | ชื่อเล่นเมนูประจำสัปดาห์ ครัวกับลูกค้าเรียกแบบนี้ ไม่ได้เรียกรหัสจริง |
| **ของในตู้ / เหลือขายได้** | นับได้ด้วยตา / หักของที่ขายไปแล้วรอจัดออก — **คนละเลข ห้ามสลับ** |
