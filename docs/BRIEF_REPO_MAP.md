## 0. กติกาใหญ่ 4 ข้อ (ผิดข้อเดียวคือร้านเจ็บจริง)

1. **`main` = ของจริงที่ลูกค้ากับครัวใช้อยู่ตอนนี้** push แล้วขึ้นเว็บใน 1–2 นาที ไม่มีขั้นตอนตรวจคั่น
2. **ห้าม push ตรงเข้า main** — มี hook กันไว้ ต้องผ่าน branch ก่อนเสมอ · **แตก branch จาก `origin/main` สด ๆ ทุกครั้ง** (เคยมี branch ฐานเก่าลบงานห้องอื่นทิ้งตอน merge มาแล้ว 2 ครั้ง)
3. **1 หน้า = 1 ไฟล์** HTML+CSS+JS อยู่ด้วยกัน ไม่มี build step ไม่มี framework — แก้ไฟล์เดียวจบ
4. **แตะของที่คนใช้อยู่ ต้องเปิดดูด้วยตาก่อนบอกว่าเสร็จ** (เคสจริง 19 ก.ย.: ข้อมูลถูกครบใน DB แต่ลูกค้าเห็นเมนูเดียวจาก 13 เมนู เพราะตั้งหมวดผิด — ถ้าไม่เปิดดู ไม่มีทางรู้)

**ก่อนแก้ไฟล์ของห้องอื่น ให้บอกห้อง u ก่อน 1 บรรทัด** ว่าจะแตะอะไร — u จะบอกว่าชนใครไหม/ใครกำลังแก้อยู่
เหตุผล: มีหลายห้อง (คน + AI) ทำงานบน repo เดียวกันพร้อมกัน ไฟล์เดียวกันแก้ทับกันได้จริง

## 7. ทำงานร่วมกันยังไง — แตะ repo ได้ ไม่ต้องทำแยก (ห้อง u ตัดสิน 23 ก.ย. 2569)

**คำตอบสั้น: เข้ามาใน repo เดียวกันเลย ทำงานบน branch ของตัวเอง**
ทำแยกข้างนอกแล้วค่อยยกมารวมทีหลัง = เจ็บกว่า เพราะของจะห่างกันขึ้นทุกวัน และตอนรวมจะไม่มีใครรู้ว่าอะไรทับอะไร

### กติกา branch
```
ชื่อ branch     gpt/<ชื่องานสั้น ๆ>      เช่น gpt/ing-stock · gpt/skin-k2
แตกจาก          origin/main สด ๆ เสมอ   (ห้ามแตกจาก branch เก่าที่ค้างไว้)
push ตรง main   ทำไม่ได้ มี hook กันอยู่ — ต้องผ่าน branch ก่อนเสมอ
commit          ภาษาไทยสั้น ๆ บอกว่าทำอะไร
ห้าม            git add -A · force push · rebase งานคนอื่น · แก้ไฟล์ที่ไม่เกี่ยวกับงานตัวเอง
```

### ใครกดขึ้น main ได้บ้าง
| งานที่แก้ | ขึ้น main เองได้ไหม |
|---|---|
| เขตตัวเอง (`pwa/ing_*` · `scripts/ing/*` · ตาราง `ing_*`) | ✅ ได้เลย |
| `preview/*` · `docs/*` | ✅ ได้เลย |
| ไฟล์ของห้องอื่น (🟡 ในตารางข้อ 2) | ❌ push แค่ branch แล้วบอกห้อง u — u ตรวจแล้วรวมให้ |
| 6 ไฟล์แกน (🔴) | ❌ ไม่แตะ แม้แต่บน branch — บอกสิ่งที่อยากได้ ห้อง u ทำให้ |

### 🔒 ตัวกันของจริง (ไม่ใช่แค่ข้อตกลง — ระบบบังคับเอง)
`.githooks/pre-push` ทำงาน 2 ชั้นทุกครั้งที่ push ขึ้น main:
1. **โค้ดที่ไม่เคยผ่าน branch = push ไม่ได้** (ของเดิม)
2. **แตะไฟล์แกน = ต้องรันเทส 60 ชุดผ่านก่อน ไม่ผ่าน push ไม่ได้** (เพิ่ม 23 ก.ย. 2569 เพราะมีทีมนอกเข้ามาช่วยแก้)
   · ไม่ได้แตะไฟล์แกน (เช่นแก้ docs หรือหน้าใหม่ของตัวเอง) = ไม่ต้องรอเทส
   · รันเทสเองไปแล้ว ข้ามได้ด้วย `SKIPTEST=1` · ฉุกเฉินจริงใช้ `HOTFIX=1` แล้วแจ้งบอร์ดทันที

### กันชนกันรายวัน
- **ก่อนแตะไฟล์ที่ไม่ใช่ของตัวเอง เช็คก่อนว่ามีใครเพิ่งแก้ไหม:** `git log -3 --format="%h %ad %s" --date=short -- <ไฟล์>`
- **ขึ้น main แล้วบอกห้อง u 1 บรรทัด** ว่าแตะไฟล์ไหน/ตารางไหน
- เจองานที่ดูทับกัน **หยุดแล้วถามก่อน** — งานซ้ำ 2 ชั่วโมงถูกกว่าของพังในเวลาที่ครัวกำลังใช้
