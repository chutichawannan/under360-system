# 🔗 ตารางกลางวัตถุดิบ — เรา ↔ Freshket ↔ GO

> ทำโดยห้อง **f** 16 ก.ย. 2026 · นัทสั่ง: *"เปิดจากบิลสั่งของทั้ง go และ fresh เอาวัตถุดิบที่ไม่ซ้ำมาทำลิส ... มาแมชชื่อ น้ำหนัก หน่วย เราจะได้รู้ว่าต่อจากนั้นจะทำระบบสั่งของอัตโนมัติยังไง"*
> **ไฟล์ตาราง: [`docs/INGREDIENT_MAP.csv`](INGREDIENT_MAP.csv)** (เปิดด้วย Excel ได้ มี BOM แล้ว)
> สร้างซ้ำได้ด้วย `node scripts/finance/ingredient_map.mjs`

|---|---|---:|---|

## ✅ สิ่งที่ตารางนี้ทำได้แล้ว — **เทียบราคาข้ามเจ้าเป็น ฿/กก. จริง**
แปลงขนาดบรรจุให้เป็นหน่วยเดียวกันหมด (แพ็ค 250 ก. → ฿/กก.) ไม่งั้นเทียบไม่ได้

| วัตถุดิบ | Freshket | GO | ถูกกว่า |
|---|---:|---:|---|
| อกไก่ | ฿85/กก. | ฿84/กก. | เท่ากัน |
| **สะโพกไก่** | ฿105/กก. | **฿98/กก.** | 🟢 GO ถูกกว่า 7% |
| **แครอท** | **฿26/กก.** | ฿55/กก. | 🟢 Freshket ถูกกว่า **เท่าตัว** |

→ **นี่คือแกนของเครื่องมือสั่งของอัตโนมัติ**: รู้ว่าของชิ้นเดียวกันเจ้าไหนถูกกว่า ณ วันนั้น

## ⏭️ 3 ขั้นที่เหลือก่อนทำระบบสั่งของอัตโนมัติได้จริง
1. **เติมชื่อร้านให้ครบ 57 ตัวที่ยังว่าง** — ฝั่ง Freshket ดึงได้อีก (หน้า reorder แสดงหมวดละ ≤24 ยังตกหล่น) · ฝั่ง GO ต้องได้รายการสินค้าจากออเดอร์ `XB-` ที่สั่งผ่านเซลล์ **ซึ่งเว็บไม่โชว์** → ขอใบกำกับรายเดือนจากเซลล์ GO
2. **นัทเคาะ "เกรดที่ใช้" 3 ตัวที่มีหลายเกรดราคาต่างเท่าตัว** — ไข่ไก่ (Freshket มี 13 แบบ ฿130–414) · อกไก่ (ติดหนัง ฿85 vs ลอกหนัง ฿575) · พริกยักษ์
3. **เติมรูป 19 ตัวที่ยังไม่มี** — ไม่งั้นครัวนับไม่ได้จริง
