## 🧭 นิยามที่นัทให้เอง — **อ่านให้ตรง ห้ามตีกรอบให้เล็กลง**

> *"การจะมาจำกัดความว่า creative ในการขาย มันคือรูป หรือลูกไม้ในการขาย **มันจะเป็นการตีกรอบเกินไป** เราต้องช่วยกันคิดไปถึงลึกเลยว่า **คนเราอยากได้อะไร** ไม่ใช่แค่ลูกไม้ตื้นๆ"*

> *"การที่เราจะคิดได้นอกกรอบไปเรื่อยๆ ตราบเท่าที่เราทำไหว **มันคือหนทางการโฆษณาที่ไม่รู้จบ**"*

**ตัวอย่างที่นัทยกเอง — นี่คือ "เบอร์" ที่เขาต้องการ:**

| ตัวอย่างของนัท | ชั้นที่มันทำงาน |
|---|---|
| คนกินเจเพราะ**อยากได้บุญ** → ทำหน้าพระให้กดสักการะ/ร่วมทำบุญบนเว็บ | **แรงจูงใจลึก** ไม่ใช่ส่วนลด |
| ลูกค้าซื้อเพราะ**อร่อยกว่าร้านอื่น** → จ้างเชฟชื่อดังทำ 1 เมนู | **ตัวสินค้าเอง** |
| ลูกค้ากดซื้อแล้ว → **ส่งของกำนัลไปเซอร์ไพรส์ ยืนยันยอดก่อนเลย** | **ประสบการณ์หลังซื้อ** |

🔑 **แก่น: เริ่มจาก "คนคนนั้นอยากได้อะไรในชีวิตเขา" แล้วค่อยย้อนกลับมาว่าเราจะเป็นส่วนหนึ่งของมันได้ยังไง**
❌ ไม่ใช่ "เรามีของนี้ จะพูดยังไงให้เขาซื้อ"

## 🎯 ห้องนี้ถืออะไร

**คิดว่าจะขายด้วยอะไร** — ครอบทุกช่องทาง ไม่ใช่แค่แอด
(แอด · หน้าเว็บ · LINE broadcast · สิ่งที่แอดมินพูด · ของแนบกล่อง · ประสบการณ์หลังจ่ายเงิน · ตัวสินค้าเอง)

### 3 ชั้นที่ต้องคิดให้ครบ (ตามที่นัทยกตัวอย่าง)
```
ชั้น 1  แรงจูงใจลึก        คนซื้อของเราเพราะอะไรจริงๆ — ไม่ใช่เพราะ "อาหารคลีน"
ชั้น 2  ตัวสินค้า          ของที่เราขายควรเปลี่ยนไหม มีอะไรที่ทำให้เขาอยากได้กว่านี้
ชั้น 3  ประสบการณ์        ก่อนซื้อ ระหว่างรอ หลังได้ของ — จุดไหนทำให้เขารู้สึกว่า "เจอร้านที่ใช่"
```

## 📌 ของจริงที่ต้องรู้ก่อนคิด (อย่าเริ่มจากศูนย์)

### พิสูจน์ด้วยเงินแล้ว
· **เส้นตายจริงชนะส่วนลด** — สารทจีนขายเพิ่ม **+35% โดยไม่มีส่วนลดเลย** (`docs/projects/2026-08_SARTJIN.md`)
· **ส่วนลดไม่สร้างความอยาก** — `BDAY08`/`COMEBACK` = **0 ใบ** ทั้งที่ 79% ของบิลถึงขั้นต่ำอยู่แล้ว
· **กลไกที่ต้องรอคนตอบ = ตายเงียบ** — `SALMON` 0 ใบ (ต้องทักแอดมิน) vs `FREEWEEKDAY` มีคนใช้ (กรอกเองได้)
· **ของเสริมวางขายเดี่ยวๆ = 0 ชิ้น** (บ๊ะจ่าง/โบนบรอธ ทั้งสัปดาห์สารทจีน) → ต้องมีกลไกพ่วง
· **ลูกค้าเก่าปิดง่ายที่สุด** — ออเดอร์คอร์สเจใบแรกมาจากกลุ่มนี้

### ตัวเลขที่ชี้ว่าคอขวดอยู่ตรงไหน (9 ก.ย.)
```
102 คนเข้าหน้าคอร์สเจ  →  14 คนกดปุ่ม  →  1 คนจองจริง
        88 คนอ่านแล้วไม่กดอะไรเลย   ← งานของห้องนี้
        13 คนตายที่ประตู LINE       ← M แก้แล้ว
```
**88 คนนั้นคือโจทย์ตั้งต้นของห้องนี้**

### ของที่ร้านมีแต่ไม่เคยใช้เป็นจุดขาย
· **10 ปี · ครัวของตัวเอง · ทำอาหารผู้ป่วยโรคไตที่คู่แข่ง 42 รายทำไม่ได้สักเจ้า**
· **อาหารเด็ก 29 เมนูในระบบ ไม่เคยมีในแผนมาเก็ตติ้งสักฉบับ**
· **พลอยตอบลูกค้าเอง** — ลูกค้ารัก "หัวปักหัวปำ" (นี่คือของที่คู่แข่งลอกไม่ได้)

## ⚖️ กติกาที่ห้ามข้าม

1. **จิตวิญญาณแบรนด์ = "คนดูแลคน"** — เทคโนโลยีต้อง**ขยายสัมผัสมนุษย์ ไม่ใช่แทนที่** (อ่าน `CLAUDE.md` หัวข้อ 🕯️)
2. 🔴 **แต่ไม่ใช่การกุศล** — นัทย้ำเอง: *"เรารักลูกค้าจริง แต่เราก็รักกำไร + ความสบาย + ความอยู่รอดของเราเท่าๆ กัน"* · **ห้ามเสนอของที่ทำให้ร้านหรือคนทำงานเจ็บ**
3. **ครัวมีเพดานจริง** — 6 คน · อ่านไทยได้ 2 · ทำสดได้เฉพาะ จ/พ/ศ · **ความคิดที่ครัวทำไม่ไหว = ความคิดที่ใช้ไม่ได้** ถามห้องครัว/ฟ้าก่อนเสนอ
4. **กฎแบรนด์** — ไม่โม้ว่าดีที่สุด · ให้ความรู้ก่อนขาย · ห้ามดิสของแช่แข็ง · ห้ามเขียน "เลือกวันส่งได้" กับของทำสด
5. **เรื่องศาสนา/ความเชื่อ ต้องให้เกียรติจริง** — ไอเดียหน้าพระ/ทำบุญทำได้ (คนไทยคุ้นกับไหว้พระออนไลน์อยู่แล้ว) **แต่ถ้าทำแบบฉาบฉวยเพื่อขายของ จะเสียมากกว่าได้** · ถ้าทำ ต้องทำจริงจัง (ทำบุญไปที่ไหนจริง บอกได้)
6. **ทุกความคิดต้องตอบได้ว่า "ใครทำ ใช้เงินเท่าไหร่ วัดผลยังไง"** — ไม่งั้นเป็นแค่ความฝัน

เริ่มเล็กสุดได้แค่ไหน :  <เวอร์ชันที่ลองได้ในสัปดาห์นี้>
