# 💰 สมุดรายรับรายจ่าย (ร้าน + ส่วนตัวนัท) — ใบงาน

> นัทขอเอง 12 ก.ย. 2026: *"ฉันอยากจดรายรับรายจ่าย ทั้งของฉันเองและของร้าน"*
> เลขาออกแบบให้ยึดหลักเดียว: **นัทต้องไม่ต้องเปลี่ยนพฤติกรรม** — ทุกวันนี้นัทพิมพ์บอกกะปันในไลน์อยู่แล้ว (เช่น "วันนี้กินแซมาอึลไป 956 บาท") ให้สิ่งนั้นกลายเป็นการจดบัญชีเลย

## หลักการ
1. **ป้อนด้วยการพิมพ์ในไลน์ตามปกติ** — ไม่มีฟอร์ม ไม่มีแอปใหม่ให้เปิด
2. **รายรับของร้านไม่ต้องจด** — ดึงจาก `orders` อัตโนมัติ (มีอยู่แล้ว ผ่าน `scripts/finance/orders.mjs`)
3. **สิ่งที่ต้องจดคือรายจ่าย + รายรับนอกระบบ** (เงินสด · โอนเข้าส่วนตัว · B2B วางบิล)
4. **แยก "ร้าน" กับ "ส่วนตัว" ตั้งแต่ตอนจด** ไม่ใช่มาแยกตอนสิ้นเดือน (กฎบัญชีกลางใน CLAUDE.md)
5. ⛔ ข้อมูลส่วนตัว **ห้ามออกมาเป็นไฟล์ใน repo** — อยู่ใน DB + หน้า PWA ที่ล็อกเท่านั้น

## โครงข้อมูล (ตารางใหม่ `ledger`)
```
at            timestamptz   เวลาที่เกิดรายการ
side          text          'shop' | 'personal'
kind          text          'out' (จ่าย) | 'in' (รับ)
amount        numeric
category      text          วัตถุดิบ · ค่าส่ง · แอด · เครื่องมือ · ค่าแรง · ของใช้ครัว · ส่วนตัว-อาหาร · ส่วนตัว-ลูก ฯลฯ
note          text          ข้อความดิบที่นัทพิมพ์ (เก็บไว้เสมอ ห้ามทิ้ง)
slip_url      text          รูปสลิปที่ส่งตามมา (ถ้ามี)
source        text          'line' | 'manual' | 'import'
created_by    text
```

## ทางเดินข้อมูล
```
นัทพิมพ์ในไลน์ → กะปันจับตัวเลข+คำ → เขียนลง ledger → ตอบสั้นๆ ว่าจดแล้ว (1 บรรทัด ไม่ถามซ้ำ)
รูปสลิปส่งตามมา → แนบกับรายการล่าสุดของคนนั้นอัตโนมัติ
หน้า PWA /pwa/money.html → ดู/แก้/ลบ + สรุปวันนี้·เดือนนี้ แยกร้าน/ส่วนตัว + export CSV ให้คนทำบัญชี
```

**กติกาการเดา:** ถ้าข้อความไม่ชัดว่าร้านหรือส่วนตัว → ลงเป็น `personal` ไว้ก่อน แล้วติดธง `ยังไม่ยืนยัน` ให้แก้ในหน้า PWA ได้ทีเดียวหลายรายการ
· คำที่ชี้ว่า **ร้าน**: วัตถุดิบ · ครัว · Freshket · GO · แก๊ส · ค่าส่ง · Lalamove · ยิงแอด · พนักงาน · ของใช้ร้าน
· **ห้ามกะปันถามย้อนทีละรายการ** (กฎเดิม: ห้ามรบกวนนัทรายข้อความ)

## แบ่งงาน
| ห้อง | ทำอะไร |
|---|---|
| **u-maintainer** | SQL ตาราง `ledger` + RLS · หน้า `pwa/money.html` (อ่าน/แก้/ลบ/สรุป/export · ล็อก PIN เหมือน PWA ตัวอื่น) |
| **kapan** | จับข้อความไลน์ของนัท → เขียน ledger + แนบสลิป · ตอบยืนยัน 1 บรรทัด |
| **f (การเงิน)** | เจ้าของหมวดหมู่ + เอา export ไปคุยกับคนทำบัญชี · ตรวจว่ารายการที่จดพอใช้ยื่นภาษีไหม |

## ที่ยังไม่ทำในเวอร์ชันแรก (กันบานปลาย)
- ไม่ทำ OCR สลิป · ไม่ต่อ API ธนาคาร · ไม่ทำงบกำไรขาดทุนอัตโนมัติ (statement ยังไม่มี)
- ไม่แตะเรื่องภาษี — **ตัวเลขทุกตัวต้องผ่านคนทำบัญชีก่อนใช้จริง**
