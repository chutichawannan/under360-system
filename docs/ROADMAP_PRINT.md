# 🖨 โร้ดแมพระบบพิมพ์ใบจัดของ

> **นัทขอเอง 9 ส.ค. 2026:** *"อยากได้ออพชั่นเพิ่ม ถ้าจะปริ้นบน HT400 ด้วย และสามารถสั่งปริ้นไปที่ครัวได้ และ/หรือ ถ้ามีออเดอร์เมื่อไหร่ ใบปริ้นออกมาเลย ทำได้ไหม"*
>
> **ตอบสั้น: ทำได้ทั้งหมด** แต่ข้อ 2-3 ต้องมี "เครื่องกลางเปิดทิ้งไว้ที่ครัว" — เบราว์เซอร์สั่งเครื่องพิมพ์ข้ามที่ไม่ได้โดยตรง

## 🚦 ทำไมข้อ 2-3 ถึงไม่ใช่แค่ "เพิ่มปุ่ม"

**เบราว์เซอร์พิมพ์ได้เฉพาะเครื่องพิมพ์ที่ต่อกับเครื่องที่เปิดหน้านั้นอยู่** — นัทอยู่อเมริกา กดปุ่มในเบราว์เซอร์ตัวเอง มันจะไปหาเครื่องพิมพ์ที่บ้านนัท ไม่ใช่ที่ครัว

**ทางเดียวที่ทำได้: มี "ตัวกลาง" ตัวเล็กๆ รันค้างไว้ที่ครัว** คอยดูว่ามีงานพิมพ์เข้ามาไหม แล้วสั่งพิมพ์ให้

```
นัท/แอดมิน กดสั่งพิมพ์  →  คิวงานพิมพ์ใน Supabase  →  ตัวกลางที่ครัวเห็น  →  ยิงเข้าเครื่องพิมพ์
        (ที่ไหนก็ได้)              (print_jobs)            (เปิดค้างไว้)         (HT400 ผ่าน LAN)
```

## 📍 P1 — ป้ายแปะกล่องสำหรับ HT400 · **ทำได้เลย ไม่ต้องซื้ออะไร**

ตอนนี้ใบเดียวทำ 2 หน้าที่ (ทั้งจัดของทั้งแปะกล่อง) — **ควรแยก**

| | ใบจัดของ (SUNMI 58 มม.) | ป้ายแปะกล่อง (HT400 4 นิ้ว) |
|---|---|---|
| ใครใช้ | ครัว ตอนหยิบของ | แมส ตอนส่ง |
| มีอะไร | รายการอาหารครบ + จำนวน | **ชื่อ · เบอร์ · ที่อยู่ · เลขออเดอร์ ตัวใหญ่** |
| ไม่ควรมี | — | **ราคา** (ลูกค้าเห็นราคาแปะกล่องแล้วแปลก) |

**ต้องรู้ก่อนทำ:** ป้ายสติกเกอร์ที่จะใช้ **ขนาดกี่ × กี่ มม.** (100×150 ? 100×100 ? แบบต่อเนื่องไม่มีรอยปรุ ?)
สติกเกอร์มีความสูงตายตัว — ถ้าเนื้อหายาวเกิน ใบเดียวจะไหลไป 2 แผ่น

**งาน:** เพิ่มโหมด `?mode=label` ในหน้าเดิม · **ครึ่งวัน** · ไม่มีค่าใช้จ่าย

## 📍 P2 — สั่งพิมพ์ข้ามที่ (นัทกดจากที่ไหนก็ได้ → ออกที่ครัว)

**ต้องมี "ตัวกลาง" เปิดค้างไว้ที่ครัว 1 เครื่อง**

**ตัวเลือกเครื่อง:**
| | ราคา | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **คอมที่ครัวมีอยู่แล้ว** | ฿0 | เริ่มได้ทันที | ต้องเปิดค้าง · ถ้าใครปิดเครื่อง = ไม่พิมพ์ |
| **มินิพีซี / Raspberry Pi** | ~3,000–6,000 | เปิดค้าง 24 ชม. กินไฟน้อย | ต้องซื้อ + ตั้งครั้งแรก |

**สิ่งที่ต้องทำ:**
1. ตาราง `print_jobs` — เก็บ: ออเดอร์ไหน · พิมพ์แบบไหน (ใบจัดของ/ป้าย) · เครื่องไหน · สถานะ (รอ/พิมพ์แล้ว/พลาด) · เวลา
2. ปุ่ม **"ส่งไปพิมพ์ที่ครัว"** ในหน้าออเดอร์ → สร้างงานเข้าคิว
3. **ตัวกลางที่ครัว** — สคริปต์เล็กๆ คอยดูคิวทุก 15 วิ → เจอ → พิมพ์ → ปิดงาน
   · HT400 ต่อ **LAN** → ยิงตรงเข้าเครื่องที่พอร์ต 9100 ได้เลย ไม่ต้องผ่านไดรเวอร์
   · ต้องตั้ง **IP คงที่** ให้เครื่องพิมพ์ ไม่งั้นเราเตอร์รีสตาร์ททีเดียวหาไม่เจอ
4. **หน้าดูสถานะ** — พิมพ์สำเร็จ/ค้าง/พลาด กี่ใบ (ไม่งั้นสั่งไปแล้วไม่รู้ว่าออกหรือเปล่า)

**ต้องระวัง (สำคัญกว่าที่คิด):**
- ⚠️ **เน็ตครัวล่มแล้วกลับมา → คิวค้างพรวดออกทีเดียว 20 ใบ** → ต้องมีเพดาน "ไม่เกิน N ใบ/นาที" + ปุ่มล้างคิว
- ⚠️ **สั่งซ้ำ = พิมพ์ซ้ำ = เปลืองสติกเกอร์** → ต้องกันซ้ำด้วยเลขออเดอร์ ไม่ใช่กันด้วยการกด
- ⚠️ ตัวกลางต้องใช้ **service role key** = คีย์ที่แก้ฐานข้อมูลได้ทั้งหมด → **ห้ามอยู่ในเครื่องที่คนอื่นใช้ร่วม**

**งาน:** ~2–3 วัน (รวมไปตั้งเครื่องที่ครัว) · **ต้องมีคนที่ครัวช่วยเสียบสาย/บอก IP**

## 📍 P3 — มีออเดอร์เข้า → พิมพ์เอง

ต่อยอดจาก P2 ตรงๆ: ตัวกลางตัวเดิมคอยดูออเดอร์ใหม่ด้วย → สร้างงานพิมพ์เอง

### 🛑 แต่ต้องเคาะก่อนว่า "พิมพ์ตอนไหน" — ไม่ใช่ตอนลูกค้ากดสั่ง

**ข้อมูลจริง: ลูกค้า 78% สั่งล่วงหน้า 1-2 วัน** (ดูจาก 983 ใบ · 4,451 กล่อง)
→ ถ้าพิมพ์ทันทีที่สั่ง **ใบจะกองรอ 1-2 วัน** ปนกับของวันนี้ · ลูกค้าแก้ออเดอร์ทีหลัง = **ใบที่พิมพ์ไปแล้วผิด**

**3 จังหวะที่เป็นไปได้ — นัทเลือก:**
| จังหวะ | ดี | เสีย |
|---|---|---|
| **① ทันทีที่ลูกค้าสั่ง** | ครัวรู้ทันทีว่ามีออเดอร์ (เหมือนกระดิ่ง) | ใบกองรอ 1-2 วัน · แก้ออเดอร์แล้วใบผิด · เปลืองกระดาษ |
| **② เช้าวันส่ง ตีพิมพ์รวดเดียวทั้งวัน** ⭐ | ใบตรงกับของจริงเสมอ · ครัวได้ปึกเดียวจบ | ไม่รู้ล่วงหน้าว่ามีออเดอร์เข้า |
| **③ ตอนแอดมินยืนยันการโอน** | พิมพ์เฉพาะใบที่จ่ายแล้วจริง | ใบมาไม่พร้อมกัน กระจัดกระจาย |

**CC แนะนำ ② + กระดิ่งแยก** — อยากรู้ว่ามีออเดอร์เข้า ใช้แจ้งเตือนเข้า LINE ดีกว่าเปลืองกระดาษ
*(แต่นัทเป็นคนตัดสิน — ครัวอาจชอบเห็นใบจริงมากกว่าข้อความ)*

**งาน:** +1 วัน หลัง P2 เสร็จ

## 📍 P4 — แตะเดียวจบบน SUNMI (ยังไม่แนะนำ)

ตอนนี้: แตะ 🖨 → กล่องพิมพ์เด้ง → แตะ "พิมพ์" = **2 แตะ**
จะเหลือแตะเดียวต้องทำ **แอป Android ติดตั้งในเครื่อง** (ใช้ SUNMI Printer SDK)

**CC ไม่แนะนำตอนนี้** — ได้เพิ่มมาแค่ 1 แตะ แต่ต้องดูแลแอปอีกตัวตลอดไป
**เก็บไว้ก่อน** ถ้าครัวใช้จริงแล้วบ่นค่อยทำ
