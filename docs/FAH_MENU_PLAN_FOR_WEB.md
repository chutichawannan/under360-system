## ⚠️ อ่านก่อนเอาไปใช้ (สำคัญ)

1. **นี่คือชุดเมนูที่ครัวผลิตต่อวัน (production pool) — ไม่ใช่กล่องของลูกค้ารายคน** ลูกค้าแต่ละคนได้แค่บางส่วนของรายการนี้ต่อวัน ไม่ใช่ทั้งหมด
2. **Meal Plan (LC/HP) ผลิตเฉพาะ จันทร์ / พุธ / ศุกร์ เท่านั้น** — วันอื่นครัวทำอย่างอื่น (อาทิตย์=เมนูพิเศษประจำสัปดาห์ S1-S8 · อังคาร/พฤหัส=อาหารเด็ก)
3. 🔴 **ห้ามเขียนว่า "เลือกวันส่งได้" สำหรับ Meal Plan** — ระบบล็อกวันส่งเป็น จ/พ/ศ ตายตัว ลูกค้าเลือกวันเองไม่ได้ (ต่างจากคอร์สสต็อค/บันเดิลที่เลือกวันได้) — ดูกฎเต็มใน `docs/BRIEF_FAH_KITCHEN.md` และ skill `under360-brand-copy`
4. ตัวเลข/โค้ดในตารางนี้ = โค้ดสูตรภายใน (LCxx = ไซส์ Low Cal 120g เนื้อดิบ · HPxx = ไซส์ High Protein 170g เนื้อดิบ) เมนูเดียวกัน ต่างแค่ปริมาณ — **โปรโมทคู่กันเสมอ (HP+LC)**
5. บางวัน (7, 9, 11, 14, 16, 28 ก.ย.) มีเมนูมากกว่าวันอื่นเพราะเป็นของที่ผูกกับกล่องลูกค้าคอร์สรายเดือนที่ล็อกไว้ล่วงหน้าแล้ว — ไม่ใช่ความผิดพลาด
6. 🔴 **LC53/HP53 ((Z4) Baked Salmon Butter Lemon) ถูกระงับตั้งแต่ 21 ส.ค. 2026** — ถ้าเห็นโค้ดนี้ในตารางวันที่ 14 ก.ย. เป็นของเก่าที่ค้างอยู่ในระบบรอแอดมินแก้ **ห้ามเอาไปโปรโมทเมนูนี้บนเว็บ**
