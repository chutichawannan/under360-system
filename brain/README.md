# brain/ — สมองกลางของ Under360

ทุกเครื่อง (Claude pc · Mac · Nut pc) และทุกห้อง อ่านโฟลเดอร์นี้ที่เดียว

| ไฟล์ | ตอบคำถาม | แก้เมื่อไหร่ |
|---|---|---|
| `NOW.md` | ทำถึงไหน · ทำอะไรอยู่ · ต้องทำอะไร | **ทุกครั้งที่จบงาน** |
| `RULES.md` | ทำงานกับนัทยังไง | เมื่อนัทสั่งกฎใหม่ หรือตัดกฎ |
| `BUSINESS.md` | ร้านคืออะไร ขายอะไร ใครทำอะไร | เมื่อข้อเท็จจริงเปลี่ยน |
| `HISTORY.md` | ผ่านอะไรมาบ้าง เคาะอะไรเมื่อไหร่ บทเรียน | เมื่อมีเรื่องสำคัญเกิดขึ้น |
| `archive/` | ของเก่าที่ไม่ใช้แล้ว | ย้ายมาเก็บ ไม่ลบทิ้ง |

**กติกา 3 ข้อ**
1. เริ่มงาน `git pull` แล้วอ่าน `NOW.md` · จบงานแก้ `NOW.md` แล้ว push ทันที
2. ของใหม่ต้องมีที่อยู่ในไฟล์เหล่านี้ · **ห้ามสร้างไฟล์จดใหม่กระจายที่อื่น**
3. เรื่องส่วนตัว/ครอบครัว/เงินส่วนตัวของนัท **ห้ามเข้า git** (repo นี้ขึ้น GitHub)
