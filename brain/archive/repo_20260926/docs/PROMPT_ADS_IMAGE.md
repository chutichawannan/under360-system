# 🖼️ พรอมพ์ทำภาพแอด — เทมเพลตที่นัทเคาะแล้ว (10 ก.ย. 2569)

> นัทเป็นคนเขียนพรอมพ์นี้เอง · ผลลัพธ์ที่ได้ = **"สวย อยากได้"** (นัทพูดเอง)
> ใช้เป็นแม่แบบของงานภาพแอดทุกใบต่อจากนี้ · เปลี่ยนแค่ 3 บรรทัดข้อความ

## พรอมพ์ต้นฉบับ (คัดลอกไปใช้ได้เลย)

```
ทำภาพงาน text over picture บนภาพอาหารไทยผสมจีน อาหารจานเดียว มุมกด 45 องศา
ที่จัดแสงธรรมชาติ ฉากขาว ที่มีสไตล์มินิมอล มาให้ที โดยมีข้อความบนภาพ
ข้อความหลักคือ {ข้อความหลัก}
ข้อความรองคือ {ข้อความรอง}
ข้อมูลคือ {บรรทัดข้อมูล}
ทำออกขนาด 3:4 แนวตั้งเท่านั้น ห้ามทำแนวนอน
ตีมสีตัวหนังสือเป็นสีขาว เป็นหลัก และมีเขียว ปนบางประโยค
```

## กฎที่ห้ามเปลี่ยน
- **3:4 แนวตั้งเท่านั้น** — ห้ามแนวนอน
- ตัวหนังสือ **ขาวเป็นหลัก เขียวแซมบางประโยค**
- มุมกด 45 องศา · แสงธรรมชาติ · ฉากขาว · มินิมอล
- อาหารไทยผสมจีน จานเดียว

# 🅱️ พรอมพ์แบบที่ 2 — คอลลาจ 6 ภาพ (นัทเคาะ 10 ก.ย. 2569)

> นัทชอบเหมือนกัน · ใช้คู่กับแบบ 🅰️ (จานเดียว) เพื่อทดสอบว่าคนตอบสนองกับแบบไหนมากกว่า

```
ทำภาพงาน text over picture บนภาพอาหารไทยผสมจีน จำนวน 6 ภาพ เอามาจัดเรียง collage
จนเป็นภาพเต็มใบเดียว ทุกรูปอาหารเป็นอาหารจานเดียว มุมกด 45 องศา ที่จัดแสงธรรมชาติ
ฉากขาว ที่มีสไตล์มินิมอล มาให้ที โดยมีข้อความบนภาพ
ข้อความหลักคือ {ข้อความหลัก}
ข้อความรองคือ {ข้อความรอง}
ข้อมูลคือ {บรรทัดข้อมูล}
```

# 🔴 2 จุดที่ต้องเติมในพรอมพ์ทุกครั้ง (เจอจากภาพตัวอย่างจริง)

## 1. ห้ามมีของที่ไม่ใช่เจ
ภาพตัวอย่างที่ AI ทำมา **มีหมูกรอบผัดกะเพราและไข่ดาว** — ผิดทั้งใบสำหรับแอดอาหารเจ
ต่อท้ายพรอมพ์ทุกครั้ง:
```
อาหารทุกจานต้องเป็นอาหารเจ ห้ามมีเนื้อสัตว์ ห้ามมีไข่ ห้ามมีกระเทียมหรือหอม
ใช้เต้าหู้ เห็ด ผัก โปรตีนเกษตร แทน
```

## 2. ห้ามข้อความซ้ำ
ภาพตัวอย่างขึ้น "คอร์สอาหารเจ" 2 ครั้ง และวันที่/รอบส่ง โผล่ทั้งลอยเดี่ยวและในบรรทัดข้อมูล
ต่อท้ายพรอมพ์:
```
ข้อความแต่ละชุดให้ขึ้นครั้งเดียว ห้ามซ้ำ ห้ามกระจายคำเดียวกันไปหลายตำแหน่ง
```
