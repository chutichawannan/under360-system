# 🍳 กลไกเก็บสูตร — 2 ทางเดินคู่กัน

> **นัทสั่งเอง 31 ส.ค. 2026:** *"ใบจดของเหลือ พวกนี้ก็จะช่วยด้านการคำนวณด้วยว่า **เมนูวันนั้นๆ ใช้อะไรประมาณเท่าไหร่** แล้วคิดถึงความน่าจะเป็นได้ว่า**ใช้เนื้อสัตว์กี่กรัม วัตถุดิบอื่นๆ เท่าไหร่ โดยที่ยุ่งกับสูตรน้อยลง** และคิดแมกคานิคการจดสูตรไว้ให้หน่อย **ฉันจะให้ครัวทยอยบอกสูตร**ดีกว่า"*

---

## 🎯 ปัญหาที่แก้

**สูตรคือตัวขวางใหญ่สุดในระบบ** — ขวางทั้งเส้น `เมนู → วัตถุดิบ → สั่งของ → ของเหลือ → ต้นทุน → กำไร`
**แต่เมนูมี 612 ตัว · มีสูตรในระบบ 4/13 ของชุดสารทจีน** → รอให้ครบก่อนค่อยเดิน = **ไม่มีวันได้เดิน**

🔑 **ทางออกที่นัทชี้: ไม่ต้องรอสูตรครบ — เดิน 2 ทางพร้อมกัน**

---

## 🅰️ ทาง A — **คำนวณย้อนจากของเหลือ** (ได้ทันที ไม่ต้องรอใคร)

```
ของที่ซื้อเข้า  −  ของที่เหลือ   =  ของที่ใช้ไปจริง
ของที่ใช้ไปจริง ÷ กล่องที่ผลิต  =  ปริมาณต่อกล่อง (โดยประมาณ)
```

**ข้อมูลที่ต้องใช้ — มีอยู่แล้วทั้งหมด:**
| ต้องรู้ | มาจากไหน | สถานะ |
|---|---|---|
| ซื้ออะไรเข้ามาเท่าไหร่ | บิล GO / Freshket | ✅ มี (`ingredient_prices` 72 แถว 23 ชื่อ · มีหน่วย) |
| เหลือเท่าไหร่ | **ใบจดของเหลือ** | 🔄 กำลังสร้าง |
| ผลิตกี่กล่อง | `orders` / ใบสั่งผลิต | ✅ มีครบ 100% |

### ⚖️ ความแม่นที่ต้องการ — **ไม่ต้องเป๊ะ**
**ตัวเลขนี้เอาไปใช้ตอบคำถามเดียว: "ต้องสั่งของเท่าไหร่"** ซึ่ง**เผื่ออยู่แล้วโดยธรรมชาติ**
→ **ผิด 10-20% ยังใช้ได้** · **ดีกว่าเดาล้วนแบบทุกวันนี้มาก**
⚠️ **ห้ามเอาไปใช้คิดต้นทุนต่อจานแบบเป๊ะๆ** — อันนั้นต้องรอทาง B

### 🔴 ข้อจำกัดที่ต้องรู้ (ห้ามลืม)
- **วันที่ทำหลายเมนูพร้อมกัน แยกไม่ออกว่าของหมดไปกับเมนูไหน** → ตัวเลขที่ได้คือ **"เฉลี่ยของทั้งวัน"** ไม่ใช่ของเมนูเดียว
- **ยิ่งเก็บหลายวัน ยิ่งแม่นขึ้นเอง** — เมนูที่ทำบ่อยจะโผล่ชัดก่อน
- **ของที่ใช้ข้ามวัน (เครื่องปรุง/ของแห้ง) เพี้ยนง่ายที่สุด** → เริ่มจาก **ผักสด + เนื้อสัตว์** ที่ใช้หมดในวันเดียว

---

## 🅱️ ทาง B — **ครัวทยอยบอกสูตร** (แม่นกว่า แต่ช้ากว่า)

> **นัทเลือกวิธีนี้เอง:** *"ฉันจะให้ครัว**ทยอย**บอกสูตรดีกว่า"* — **คำสำคัญคือ "ทยอย"**

### 🔴 กติกาที่ทำให้มันไม่ตาย
| กฎ | เพราะอะไร |
|---|---|
| **ทีละเมนู ไม่มีเดดไลน์** | ขอครบทีเดียว = ไม่มีใครเริ่ม |
| **ครัวพูด/พิมพ์แบบไหนก็ได้** | ครัวอ่านไทยได้ 2/6 · **ห้ามบังคับฟอร์ม** |
| **ไม่ต้องมีหน่วยเป๊ะ** | *"หมูสามขีด"* · *"น้ำมันสองช้อน"* — **รับไว้ก่อน แปลงทีหลัง** |
| **กะปันเก็บ ไม่ตีความ ไม่ถามกลับ** | ตรงกับกติกาเดิมของกะปัน (เก็บเป็นรอบ ไม่ตอบรายข้อความ) |
| **เริ่มจากเมนูที่ทำบ่อยที่สุด** | 20 เมนูแรกครอบคลุมการผลิตส่วนใหญ่ · **ไม่ต้องไล่ 612 ตัว** |

### 📥 เส้นทางข้อมูล
```
ครัวบอกสูตรในไลน์กลุ่ม  →  กะปันเก็บข้อความดิบ  →  ลงตาราง  →  ฟ้าใช้คำนวณ
      (พูดยังไงก็ได้)        (ไม่แปลง ไม่ถาม)      (แปลงทีหลัง)
```
**เก็บข้อความดิบไว้เสมอ** — แปลงผิดยังย้อนได้ **ถ้าทิ้งต้นฉบับ = แก้ไม่ได้อีกเลย**

---

## 🔀 2 ทางนี้ตรวจกันเอง — **นี่คือส่วนที่ดีที่สุด**

```
ทาง A บอกว่า  แครอทหมดวันละ 7 กก. / 100 กล่อง  =  70 ก./กล่อง
ทาง B บอกว่า  สูตรใช้แครอท 50 ก./กล่อง
                    ↓
        ต่างกัน 40%  →  มีอะไรผิดสักทาง
        · ครัวใช้เกินสูตร?  · ของเสีย/ตัดทิ้งเยอะ?  · จำนวนที่ซื้อไม่ตรง?
```
**→ ช่องว่างระหว่าง 2 ทาง = ตัวชี้จุดรั่วของจริง** และมันโผล่มาเองโดยไม่ต้องมีใครไปสืบ

## 🔴 ตรวจข้อมูลจริง 1 ก.ย. 2026 — **แผน "เริ่มจาก 20 เมนูขายดี" ใช้ไม่ได้**

**เดิม PM เขียนไว้ว่า:** *"เริ่มจากเมนูที่ทำบ่อยที่สุด · 20 เมนูแรกครอบคลุมการผลิตส่วนใหญ่"*
**ผลตรวจ `order_items` (ส่งตั้งแต่ 1 มิ.ย. 2026 · 5,199 แถว · 6,522 กล่อง):**

```
เมนูที่ผลิตจริง             733 ตัว
20 เมนูแรกรวมกัน            1,140 กล่อง = 17% เท่านั้น
ต้องเก็บสูตรกี่เมนูถึงได้ 80%   312 เมนู
```

**→ ร้านนี้ไม่มี "เมนูขายดีไม่กี่ตัว" เพราะเมนูหมุนทุกสัปดาห์โดยตั้งใจ**
ตัวท็อปสุดคือ `No5 เส้นหมี่น้ำยาทูน่า` แค่ 86 กล่อง = **1.3% ของทั้งหมด**

### ✅ แก้เป็น — **เก็บสูตร "ตามสัปดาห์ที่ผลิต" ไม่ใช่ "ตามอันดับขายดี"**
```
สัปดาห์ไหนครัวทำเมนูอะไร  →  เก็บสูตรเมนูนั้นในสัปดาห์นั้น
```
- **สูตรที่เก็บได้ = เอาไปใช้ได้ทันทีในสัปดาห์นั้นเลย** (ไม่ใช่เก็บไว้เฉยๆ รอวันได้ใช้)
- ครัวกำลังทำเมนูนั้นอยู่แล้ว → **บอกสูตรตอนกำลังทำ ง่ายกว่านึกย้อน**
- เมนูหมุนไปเรื่อยๆ → **ผ่านไป 2-3 เดือนก็ครอบคลุมของที่ใช้จริงเองโดยไม่ต้องไล่ 733 ตัว**
- เมนูที่ไม่เคยกลับมาทำอีก = **ไม่ต้องเก็บสูตรเลย** ประหยัดแรงตรงนี้มากที่สุด

### ⚠️ เจอระหว่างทาง — ข้อมูลเมนูซ้ำ/ชื่อไม่ตรงรหัส (คนละเรื่อง แต่จดไว้)
`A2` โผล่ 2 ชื่อ · `No14` กับ `NEW No14` แยกกัน · **`No4` แต่ชื่อขึ้นว่า "No3 ข้าวสะโพกไก่ตุ๋นเกาลัด"**
→ ทำให้นับยอดต่อเมนูเพี้ยน · **ยังไม่แก้ จดไว้ในกองงานก่อน**

## ✅ นัทเคาะ 1 ก.ย. 2026 — **เอาทั้ง ก และ ข** (รายวัน + รายสัปดาห์)

**2 จังหวะนี้ไม่ใช่ทางเลือก — มันคนละหน้าที่กัน**

```
ก (รายวัน)      =  เก็บ        ← ครัวบอกตอนเพิ่งทำเสร็จ ยังจำได้
ข (รายสัปดาห์)  =  ตามของที่ขาด ← เทียบว่าสัปดาห์นี้ทำอะไรไปบ้าง อันไหนยังไม่มีสูตร
```

### 🅰️ จังหวะรายวัน — **แปะท้ายใบจดของเหลือ**
**หลังผลิตเสร็จ ตอนที่ครัวกำลังจดของเหลืออยู่แล้ว** (นัทเคาะจังหวะนี้ไว้ตั้งแต่ 31 ส.ค.)
- **1 วัน = ขอสูตรแค่ 1 เมนู** ไม่ต้องครบทุกเมนูที่ทำวันนั้น
- **พูด/พิมพ์/ส่งเสียงในไลน์กลุ่มก็ได้** — ครัวอ่านไทยได้ 2/6 **ห้ามบังคับฟอร์ม**
- **ไม่มีหน่วยเป๊ะก็รับ** — *"หมูสามขีด"* / *"น้ำมันสองช้อน"* เก็บดิบไว้ก่อน
- **ไม่บอกวันไหนก็ไม่เป็นไร ไม่ต้องทวงรายวัน** ← ทวงทุกวันแล้วครัวจะเลิกบอกไปเลย

### 🅱️ จังหวะรายสัปดาห์ — **เช็คว่าอะไรหลุด**
```
สัปดาห์นี้ครัวทำเมนูอะไรบ้าง  (จาก order_items)
          −
สัปดาห์นี้ได้สูตรมากี่เมนู
          =
รายการที่ยังขาด  →  ถามเฉพาะตัวที่ขาด ไม่ถามซ้ำตัวที่ได้แล้ว
```
- **ถามครั้งเดียวต่อสัปดาห์ ครั้งละไม่กี่ตัว** = ไม่กวนครัว แต่ของไม่หลุด
- เมนูที่ **ไม่กลับมาทำอีกเลย = ตัดทิ้ง ไม่ต้องตาม**

### 👥 ใครทำอะไร
| ใคร | หน้าที่ |
|---|---|
| **ครัว** | บอกสูตรวันละเมนู แบบไหนก็ได้ **ไม่มีเดดไลน์** |
| **กะปัน** | เก็บข้อความดิบ **ไม่ตีความ ไม่ถามกลับรายข้อความ** (ตรงกับกติกาเดิมของกะปัน) |
| **กะปัน (สัปดาห์ละครั้ง)** | ทำรายการ "สัปดาห์นี้ยังขาดสูตรเมนูไหน" → ถามครัวรอบเดียว |
| **ห้อง `k` / ฟ้า** | เอาสูตรที่ได้ไปใช้คำนวณวัตถุดิบ + เทียบกับทาง A |

🔴 **เก็บข้อความต้นฉบับไว้เสมอ** — แปลงผิดยังย้อนได้ ทิ้งต้นฉบับ = แก้ไม่ได้อีกเลย
