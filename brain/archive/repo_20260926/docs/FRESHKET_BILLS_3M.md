## 🔧 วิธีดึง (ทำซ้ำได้ — จดไว้เพราะเสียเวลาหาตั้งนาน)

1. เปิด `freshket.co/Admin/Restaurant/Mybilling` (ต้อง login ค้างใน Chrome + เปิดสิทธิ์ส่วนขยายบนโดเมนนี้)
2. แถวบิล = `document.querySelectorAll('.row.is-read')` · ลูกแต่ละ div เรียง: `วันรับ ~ ผู้ขาย ~ วันสั่ง ~ ช่วงเวลา ~ ยอด+จำนวนรายการ ~ เลขที่บิล`
3. **เปลี่ยนเดือน:** `document.querySelectorAll('select')[1].value='06'` แล้ว `dispatchEvent(new Event('change',{bubbles:true}))` (select[0] = ปี)
4. 🔑 **เปลี่ยนหน้า: ต้องคลิกจริงด้วยเมาส์เท่านั้น** — `.click()` และ MouseEvent สังเคราะห์ **ไม่ทำงาน** · ปุ่มหน้าอยู่ราว `y=683` · หน้า 1 ที่ `x≈726` ห่างกันหน้าละ ~34px
5. เปลี่ยน hash `#order&page=N` ได้ผลเฉพาะตอน**โหลดหน้าใหม่**จาก URL อื่น (เปลี่ยน hash เฉยๆ ไม่รีเฟรช)
6. ⚠️ ส่วนขยายจะบล็อกผลลัพธ์ที่มีลักษณะ query string/cookie → อย่าคืน `location.href`/`href` ตรงๆ
