# 🍳 เตรียมของล่วงหน้า 1 วัน — ฝั่งครัว (k-track)

> **นัทสั่งเอง 18 ส.ค. 2026** (ผ่านกะปัน จากไลน์):
> *"ตอนนี้เราทำสดขึ้นมาแล้วมักจะทำไม่ทันเสมอ อาหารดูไม่สดใหม่เท่าไหร่ ก็เลยวางแผนจะทำล่วงหน้า 1 วัน เหมือนเตรียมทุกอย่างให้เรียบร้อย แล้วเราจะได้มา cooking ที่เดียว **เริ่มวันพฤหัสบดีนี้เลย** ดังนั้น**ต้องรู้ก่อนวันศุกร์ว่าจะสั่งอะไร และยอดเท่าไหร่**"*
>
> **แบ่งงาน:** ห้อง k = ฝั่งครัว (ตัวขวาง · เส้นตาย · ใบเตรียม) · **ห้องฟ้า = เมนู→วัตถุดิบ→ปริมาณ** · **buyer = ซื้อที่ไหน เท่าไหร่**
> เอกสารนี้ไม่แตะฝั่งวัตถุดิบ — ตอบเฉพาะ *"ครัวจะเตรียมล่วงหน้าได้จริงไหม และติดอะไร"*

## ⏰ สิ่งที่ต้องเปลี่ยนจริง = **เลื่อนเส้นตายจัดเมนูขึ้นมา 1 วัน**

```
เดิม     [จัดเมนูวันไหนก็ได้ก่อนวันส่ง] → ตื่นมาทำสดวันส่ง → ส่ง
ใหม่     จัดเมนูเสร็จ ──▶ เตรียมล่วงหน้า ──▶ ปรุงรอบเดียว ──▶ ส่ง
         (เย็นวันก่อนเตรียม)   (1 วันก่อนส่ง)      (เช้าวันส่ง)
```

| วันส่ง | ต้องจัดเมนูเสร็จภายใน | ครัวเตรียมล่วงหน้าวัน |
|---|---|---|
| ศุกร์ | **เย็นพุธ** | พฤหัส |
| อาทิตย์ | **เย็นศุกร์** | เสาร์ |
| พุธ | **เย็นจันทร์** | อังคาร |

🔴 **สำหรับศุกร์ 21 ส.ค. → เส้นตายคือ *เย็นวันพุธ 19 ส.ค.* = พรุ่งนี้**
ตอนนี้ 5 ใบยังว่าง → ถ้าพรุ่งนี้เย็นยังไม่จัด **ระบบใหม่จะล้มตั้งแต่วันแรก** และครัวต้องกลับไปทำสดเหมือนเดิม

**ไม่ตัดสินใจแล้วจะเกิดอะไร:** พฤหัสเช้าครัวมาถึงแล้วไม่มีงานเตรียม → ศุกร์ต้องทำสด 37 กล่องรวดเดียวเหมือนเดิม → *"ทำไม่ทัน อาหารดูไม่สดใหม่"* แบบที่นัทบ่นก็จะเกิดซ้ำ

## 📋 ใบเตรียมล่วงหน้า (แบบร่าง v1) — ครัวใช้จริง

> ⚠️ **คำแปลพม่าด้านล่างเป็นร่างของ AI — ต้องให้คนที่อ่านพม่าได้ตรวจก่อนติดในครัว 1 ครั้ง**
> ตัวเลข · รหัสเมนู (S016 · HP/LC) · หน่วย = **ห้ามแปล ใช้ตัวเลขล้วน** (กฎ `docs/KITCHEN.md`)

```
┌──────────────────────────────────────────────┐
│  📅 ใบเตรียมล่วงหน้า  /  ကြိုတင်ပြင်ဆင်ရန်စာရွက်  │
│  เตรียมวันที่ ____  ➜  ส่งวันที่ ____            │
├──────────────────────────────────────────────┤
│  รวมกล่อง / စုစုပေါင်း သေတ္တာ :   [    ]        │
│      HP [   ]        LC [   ]                │
├──────────────────────────────────────────────┤
│  รหัส    เมนู          จำนวน   ✅เตรียมแล้ว     │
│  ─────   ───────────   ─────   ──────────    │
│  ______  ___________   [   ]      ☐          │
│  ______  ___________   [   ]      ☐          │

**ทำไมต้องมีช่อง "เก็บไว้ที่ไหน" และ "คนตรวจ":**
เตรียมล่วงหน้า = ของค้างคืน 1 คืน → เพิ่มความเสี่ยง 2 อย่างที่ไม่เคยมีตอนทำสด
1. **ที่เก็บไม่พอ** — ตู้ฟรีซ 5+1 รอบตัวอู เต็มอยู่แล้วหรือเปล่ายังไม่มีใครรู้ (ผังตู้ยังเป็น TODO ค้างใน `KITCHEN.md`)
2. **ของเตรียมแล้วหาย/ถูกหยิบไปใช้ผิดวัน** — ไม่มีจุดยืนยันว่าของถึงมือวันรุ่งขึ้นครบ = **เส้นเลือดร่วมของ CASE_01/02/03 อันเดิมเป๊ะ** ("เรารู้ทีหลังเสมอ")

```

⚠️ **ตรวจไม่ได้ว่ากินกล่องเดือนละกี่ใบ** — DB ไม่ได้บันทึกว่าใบไหนใช้กล่องไซส์อะไร
