## 💸 ผลกระทบ

- **ของเสีย 100%** ทั้งกล่อง — ต้องส่งใหม่หรือคืนเงิน (นัทเคาะ)
- **ลูกค้าประจำ** = มูลค่าตลอดชีพสูง เสียคนเดียวเจ็บกว่าค่ากล่อง
- 🚩 กระทบ positioning โดยตรง: เราชูว่า **"ฟรีซแพ็คทำถูกวิธี ปรุงเสร็จแช่แข็งทันที"** และ **ห้ามดิสอาหารแช่แข็ง** — แต่ประสบการณ์ลูกค้าปลายทางพังที่ขั้นขนส่ง ไม่ใช่ที่ครัว

## 🔴 คำตอบจากนัท 6 ส.ค. — **พลิกเคสนี้จาก "อุบัติเหตุ" เป็น "ต้นทุนประจำที่ไม่เคยถูกนับ"**

> **① เคลมกับ Nim: "ยากมาก และส่วนใหญ่ไม่ได้เต็มจำนวน"**
> **② เกิดบ่อยแค่ไหน: "เคยเกิดมาก่อน และบ่อย"**

**สมการที่ได้จาก 2 คำตอบนี้:**
- เกิดบ่อย **×** เคลมแทบไม่ได้ **=** **ร้านจ่ายเองเกือบเต็มทุกครั้ง** (ค่าอาหาร + ค่าส่งขาไป + ส่งใหม่/คืนเงิน + เวลาแอดมิน)
- 🔴 **ก้อนนี้ไม่เคยปรากฏใน P&L เลย** — ต่อกับ f-track โดยตรง (`CLAUDE.md` → 💰 f-track: *"ฝั่งต้นทุนไม่มีที่จดเลย"*) · **"บ่อย" ยังเป็นความรู้สึก ไม่ใช่ตัวเลข → ไม่มีใครรู้ว่าไลน์ ตจว. กำไรจริงหรือขาดทุน**
- ⚠️ **ห้ามฟันธงว่า "ไลน์ ตจว. ไม่คุ้ม" ตอนนี้** (กฎข้อ 0 ของ f-track: แยกตัวเลขออกจากสาเหตุ) — ต้องนับก่อน

### 🔑 บทเรียนที่เปลี่ยนวิธีแก้
**เคลมไม่ได้ = กู้ "เงิน" ไม่ได้ → แต่ยัง**กู้ "ลูกค้า" ได้** ถ้ารู้ทัน**
เคสนี้ที่เจ็บที่สุดไม่ใช่ค่าอาหาร แต่คือ **ลูกค้าประจำรอทั้งวัน 2 วัน แล้วต้องโทรตามเอง** — อันนั้นแก้ได้ฟรีถ้ามีคนเช็คสถานะพัสดุ
→ **โฟกัสไปที่ "รู้ก่อนลูกค้า" ไม่ใช่ "เอาเงินคืนจากขนส่ง"**

## ❓ ที่ยังต้องรู้ (รอนัท)

1. **ส่งแบบไหน** — น้ำแข็งแห้ง / กล่องโฟม / เจลเย็น? **ของอยู่ได้จริงกี่ชั่วโมง?** (ตัวเลขนี้ = เส้นตายที่ระบบต้องรู้)
2. **Nim ให้ tracking number ไหม** และเรามีที่เก็บเลขพัสดุในระบบหรือเปล่า (ตอนนี้ `orders` ไม่มีช่องนี้)
3. **ตอนนี้ใครตอบลูกค้าเคสแบบนี้** — พลอย / แอดมิน / นัท?
4. **นโยบายชดเชย** — ส่งใหม่ฟรี / คืนเงิน / ให้เลือก? (ตอนนี้ทำแบบไหนอยู่)
5. **มีขนส่งเจ้าอื่นที่รับของแช่แข็ง ตจว. ไหม** — เคยลองหรือยัง

## 💡 ทางแก้ — เรียงตามลำดับที่ควรทำ

**ขั้น 1 (ก่อนอื่นเลย): เริ่มนับ** — "บ่อย" ต้องกลายเป็นตัวเลขก่อน ไม่งั้นตัดสินใจอะไรไม่ได้
จดแค่ 4 ช่องต่อเคส: **วันที่ · ปลายทาง · มูลค่าของที่เสีย · ชดเชยยังไง** → 1 เดือนก็เห็นภาพ

**ขั้น 2 (แก้ได้ทันที ไม่ต้องรอข้อมูล): จุดตรวจ "ของถึงหรือยัง"**
เก็บเลขพัสดุ + วันส่ง → เช็คสถานะ**เย็นวันถัดไป** → ส่งไม่สำเร็จ = **โทรหาลูกค้าก่อนที่เขาจะโทรมา**
*(เคสนี้ถ้าทำแค่นี้ ก็ยังเสียของอยู่ดี — แต่ไม่เสียลูกค้า)*

**ขั้น 3 (หลังมีตัวเลข): ค่อยตัดสินใจใหญ่** — เปลี่ยน/เพิ่มขนส่ง · ปรับค่าส่ง ตจว. · หรือทบทวนไลน์ ตจว.

**ต่อยอด:** เตือนอัตโนมัติเมื่อพัสดุแช่แข็งค้างเกิน N ชั่วโมง · 🔗 ต่อกับ **บอทครัวใน LINE** ได้ตรงๆ (แจ้งในกลุ่ม → เก็บลงระบบ → นัทเห็นในคอนโซล)

- **ขั้นต่ำสุดที่ได้ผลทันที:** เก็บ **เลขพัสดุ + วันส่ง** ทุกออเดอร์ ตจว. → ใครสักคน (หรือระบบ) เช็คสถานะ **เย็นวันถัดไป** → ส่งไม่สำเร็จ = **โทรหาลูกค้าก่อนที่ลูกค้าจะโทรมา**
- ต่อยอด: เตือนอัตโนมัติเมื่อพัสดุแช่แข็งค้างเกิน N ชั่วโมง (ของแช่แข็งมี "นาฬิกาตาย" ที่ระบบควรรู้)
- 🔗 ต่อกับ **บอทครัวใน LINE** ได้ตรงๆ: ของถึง/ไม่ถึง แจ้งในกลุ่ม → เก็บลงระบบ → นัทเห็นในหน้าคอนโซล
