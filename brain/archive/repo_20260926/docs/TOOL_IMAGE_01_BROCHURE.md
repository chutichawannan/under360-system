## 🧪 สูตรสำเร็จ 8 ข้อ (บทเรียนที่แลกมาด้วยการลองผิดจริง — อย่าข้าม)

### 1. หน้าเว็บ = ต้นฉบับ · รูป = ผลพลอยได้
ไม่ใช้โปรแกรมกราฟิก ไม่ใช้ไลบรารีข้างนอก — จัดหน้าเป็น HTML/CSS ธรรมดา แล้ว "ถ่ายรูป" ตัวเองออกมาเป็น PNG
วิธี: `XMLSerializer` → ยัดใส่ `<svg><foreignObject>` → โหลดเป็น `Image` → วาดลง `canvas` → `toBlob`
**ข้อดี:** แก้ดีไซน์ = แก้ CSS · ไม่มี dependency ให้พังในอนาคต

### 2. 🔤 ต้อง **ฝังฟอนต์** ลงไฟล์เสมอ — ห้ามพึ่งฟอนต์ในเครื่อง
🔴 **ข้อนี้เสียเวลามากที่สุด** — เครื่องนัท **ไม่มี Sarabun และไม่มี Noto Sans Thai** ติดตั้งอยู่
ผลคือทั้งเว็บและไฟล์ตกไปใช้ `Leelawadee UI` ของ Windows แบบเงียบๆ (นัทจับได้เอง: *"เหมือน noto sans ไม่มาด้วย"*)

**วิธีที่ถูก:**
1. โหลดฟอนต์จาก Google Fonts เข้าหน้าเว็บ (`<link>` ปกติ)
2. ตอนจะออกไฟล์ → `fetch` ไฟล์ CSS ของ Google → หา url `.woff2` ทุกตัว → แปลงเป็น **data URI** → เอา CSS ที่ฝังฟอนต์แล้วนี้ยัดเข้า `<style>` ในไฟล์ SVG
   (ดูฟังก์ชัน `embeddedFontCss()` ในโค้ด — ตอนนี้ฝัง 12 น้ำหนัก ~388KB)

**เพราะอะไร:** รูปที่วาดจาก SVG **โหลดอะไรจากอินเทอร์เน็ตไม่ได้เลย** ถ้าไม่ฝัง ฟอนต์จะกลายเป็นอะไรก็ได้ที่เครื่องคนนั้นมี → ไฟล์เดียวกันเปิดคนละเครื่องได้คนละหน้าตา

### 3. ประกาศฟอนต์ที่ "กล่องรูป" ไม่ใช่ที่ `body`
ตอนออกไฟล์เราตัดเอาเฉพาะ `#page` ออกมา — **กฎที่เขียนไว้ที่ `body` จะไม่ติดไปด้วย** ตัวหนังสือจะกลายเป็นฟอนต์มีหัวเชิงทันที
→ ประกาศ `font-family` ที่ `#page` **และ** ที่ div ครอบใน SVG (2 ชั้น กันพลาด)
⚠️ เป็นบั๊กที่ **ดูบนเว็บอย่างเดียวไม่มีวันเจอ** ต้องเปิดไฟล์ที่เซฟออกมาดูเท่านั้น

### 4. 🔍 วาดใหญ่ 3 เท่าแล้วค่อยย่อ
จอนัทตั้งสเกล 150% → เว็บถูกวาดละเอียดกว่าไฟล์ที่ export ตรงๆ ตัวหนังสือในไฟล์เลย "ดูไม่เหมือนบนจอ" ทั้งที่ฟอนต์เดียวกัน
→ วาดลง canvas ขนาด **×3** ก่อน แล้ว `drawImage` ย่อลงมาให้ได้ขนาดจริง (`imageSmoothingQuality="high"`)
ได้ขอบตัวอักษรเนียนเท่าที่ตาเห็นบนจอ **โดยขนาดไฟล์ยังเป๊ะตามที่สั่ง**

### 5. รูปทุกใบต้องแปลงเป็น data URI ก่อนถ่าย
`<img src="https://...">` ที่ชี้ออกไปข้างนอก **จะกลายเป็นช่องว่างในไฟล์** → ต้อง `fetch` มาแปลงเป็น base64 ก่อน แล้วค่อยคืนค่าเดิมหลังถ่ายเสร็จ

### 6. โลโก้ใช้ **SVG ฝังในหน้า** ไม่ใช่ไฟล์รูป
- ไฟล์ PNG ที่ได้มารอบแรก **ความทึบต่ำมาก** (พิกเซลทึบเต็มมีแค่ 436 จุด) → ออกมาซีดเหมือนลายน้ำ ดันความทึบเท่าไหร่ก็ได้แค่ "รอยเปื้อนที่เข้มขึ้น"
- แก้ด้วยการขอ **ไฟล์ SVG ตัวจริง** แล้ว `fetch` มา **แปะเป็นเวกเตอร์ในหน้า** (ไม่ใช่ `<img>`) → คมทุกขนาด และติดไปกับไฟล์ที่ export ด้วย
- 🪄 ทริก: ใช้ `getBBox()` **ตัดขอบว่างรอบโลโก้อัตโนมัติ** (ไฟล์จาก Illustrator มักมีที่ว่างรอบเยอะ ถ้าไม่ตัดโลโก้จะดูลอยและเล็กเกินไป)
- ไฟล์โลโก้: `web/img/u360_logo.svg`

### 7. ขนาดไฟล์ = **กว้างล็อก สูงยืดตามเนื้อหา**
นัทสั่ง: *"ไซส์ด้านข้างต้อง 1040 เป๊ะ แนวตั้งเท่าไหร่ก็ตามนั้น"*
→ `width` คงที่ 1040 · `height` อ่านจาก `getBoundingClientRect()` ตอนถ่าย
ห้ามล็อกความสูงตายตัว (เมนู 13 ตัวกับ 20 ตัวความสูงไม่เท่ากัน — ล็อกไว้แล้วเนื้อหาจะโดนตัดหรือเหลือที่ว่างโหว่)

### 8. อยากให้นัทเซฟง่าย → **ส่งเป็นลิงก์ ไม่ใช่ให้ไปกดเอง**
อัพไฟล์ขึ้น Supabase Storage (`menu-images/brand/...`) แล้วส่ง URL ให้ — เปิดจากมือถือกดค้างเซฟได้ · ส่งต่อในไลน์ได้เลย
> นัทพูดเอง: *"ส่งเป็นลิงก์ให้เถอะ ฉันจะได้เซฟได้"*

## ✅ วิธีตรวจว่า "เสร็จจริง" (ห้ามเชื่อสายตาบนเว็บอย่างเดียว)

| ตรวจอะไร | วิธีวัด |
|---|---|
| ฟอนต์ในไฟล์ = ฟอนต์บนจอไหม | วัดความกว้างกล่องตัวอักษรบนจอ เทียบกับความกว้างหมึกจริงในไฟล์ (ต่างกันไม่เกิน ~5px = ตัวเดียวกัน) |
| เครื่องนี้มีฟอนต์นั้นจริงไหม | เรนเดอร์ข้อความเดียวกันด้วยชื่อฟอนต์นั้น เทียบกับ default — **ถ้ากว้างเท่ากันเป๊ะ = ไม่มีฟอนต์นั้น กำลังใช้ของหลอก** |
| รูปติดครบไหม | นับ `naturalWidth > 0` ทุก `<img>` |
| โลโก้ติดไหม | นับพิกเซลสีเขียวแบรนด์ในโซนหัวกระดาษ (ต้องไม่มีจุดเทา/ดำปน = ไม่ใช่รอยเปื้อน) |
| ขนาดเป๊ะไหม | อ่าน `naturalWidth/Height` ของไฟล์จริงที่อัพขึ้นไปแล้ว |

## 🚀 งานที่เตียงต่อยอดได้ทันที (เสนอ ไม่ใช่สั่ง)

1. **แม่แบบเพิ่ม** ใช้สูตรเดียวกันเป๊ะ เปลี่ยนแค่ CSS: IG จัตุรัส 1080×1080 · Story 1080×1920 · ใบแทรกในถุง (นัทอยากทำแพคเกจจิ้ง/คูปองพรีเมียม)
2. **ปุ่มเดียวออกครบชุด** — กดครั้งเดียวได้ทั้งโบรชัวร์ + การ์ด IG + สตอรี่ พร้อมลิงก์
3. **ตัวหนังสือโปรโมทบนภาพ** (เช่น "สั่ง 3 กล่องส่งฟรี") ให้พิมพ์ในช่องแล้วขึ้นบนรูปเลย
4. **ทำอัตโนมัติรายสัปดาห์** — พอนิวเซ็ตเมนูใหม่เสร็จ ให้ออกไฟล์ + ส่งลิงก์เข้าบอร์ดเองทุกวันศุกร์
