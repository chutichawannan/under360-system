## 🧰 ศัพท์ที่ต้องรู้เพื่อค้นต่อเอง (นัทมีรูปสินค้าจริงอยู่แล้ว = ได้เปรียบ ข้ามชั้นที่ยากสุดไปเลย)
| ศัพท์ | ใช้ตอนไหน |
|---|---|
| **image-to-image / img2img** | เอารูปเดิมเป็นตัวตั้ง แล้วปรับ (ไม่ใช่สร้างอาหารใหม่) |
| **inpainting** | แก้เฉพาะบางส่วน เช่นเปลี่ยนแค่พื้นหลัง เก็บอาหารเดิม 100% |
| **relighting** | เปลี่ยนแสงอย่างเดียว ← ตรงกับที่นัทอยากได้ที่สุด |

| **lip sync** | ทำให้ภาพคนพูดได้ (สาย talking-head) |
| **denoise / strength** | ค่าที่คุมว่า AI แก้เยอะแค่ไหน — **ยิ่งสูง อาหารยิ่งเพี้ยนจากของจริง** |
