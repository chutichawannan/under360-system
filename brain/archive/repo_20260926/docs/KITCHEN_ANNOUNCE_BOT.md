# 📢 ประกาศแจ้งทีมครัวก่อนเชิญบอทเข้ากลุ่ม (ไทย + พม่า)

> **ใช้ตอนไหน:** ก่อนกด "เชิญบอทเข้ากลุ่ม" (ขั้น ⑨) — **ต้องแจ้งก่อนเสมอ** เพราะบอทเก็บบทสนทนาทั้งหมด (มารยาท + PDPA)
> **วิธีใช้:** ก๊อปทั้งก้อนวางในกลุ่มครัวได้เลย (ไทยบน พม่าล่าง — อู/โม๋ข่องอ่านไทย · ที่เหลืออ่านพม่า)
>
> ⚠️ **ภาษาพม่าด้านล่างผมแปลเอง ยังไม่ผ่านคนตรวจ** — ให้คนที่อ่านพม่าได้ (2-3 คนในครัว) อ่านทวนก่อนใช้จริง 1 รอบ
> ทีมเป็น**ไทใหญ่** อ่านพม่าได้ "พอได้" ไม่ใช่คล่อง → เขียนสั้น ประโยคง่าย ตั้งใจแล้ว

## 🇹🇭 ภาษาไทย

```
สวัสดีทุกคนครับ 🍳

ตั้งแต่วันนี้ จะมีผู้ช่วย (บอท) เข้ามาอยู่ในกลุ่มนี้

บอททำอะไรให้ได้:
• พิมพ์คำว่า "ยอด" หรือ "ยอดพรุ่งนี้" → บอทจะบอกว่าต้องทำกี่กล่อง เมนูอะไรบ้าง
• พิมพ์ภาษาอะไรก็ได้ ระบบจะแปลให้เจ้าของร้านอ่านเข้าใจ

สิ่งที่ต้องบอกให้ทราบ:
• ข้อความในกลุ่มนี้จะถูกบันทึกเก็บไว้ เพื่อย้อนดูตอนของผิดหรือของขาด
• ถ้าเป็นเรื่องส่วนตัว ให้คุยแชทส่วนตัว ไม่ต้องคุยในกลุ่มนี้

ถ้าใครไม่สบายใจ บอกได้เลยครับ
```

## 🇲🇲 ภาษาพม่า (⚠️ รอคนตรวจ)

```
မင်္ဂလာပါ 🍳

ဒီနေ့ကစပြီး ဒီအဖွဲ့ထဲမှာ အကူအညီပေးမယ့် စက်ရုပ် (bot) တစ်ခု ဝင်လာပါမယ်။

စက်ရုပ်က ဘာလုပ်ပေးနိုင်လဲ:
• "ยอด" ဒါမှမဟုတ် "ยอดพรุ่งนี้" လို့ ရိုက်လိုက်ပါ → မနက်ဖြန် ဘယ်နှစ်ဘူး၊ ဘယ်ဟင်းလျာတွေ လုပ်ရမလဲ ပြောပြပါမယ်။
• ဘယ်ဘာသာစကားနဲ့မဆို ရိုက်လို့ရပါတယ်။ ဆိုင်ရှင် နားလည်အောင် စနစ်က ဘာသာပြန်ပေးပါမယ်။

သိထားရမယ့် အချက်:
• ဒီအဖွဲ့ထဲက စာတွေကို သိမ်းဆည်းထားပါမယ်။ ပစ္စည်း မှားတာ၊ လိုတာ ရှိရင် ပြန်စစ်ဖို့ ဖြစ်ပါတယ်။
• ကိုယ်ရေးကိုယ်တာ ကိစ္စဆိုရင် တစ်ကိုယ်ရေး chat မှာ ပြောပါ။ ဒီအဖွဲ့ထဲမှာ မပြောပါနဲ့။

စိတ်မသက်မသာ ဖြစ်တာ ရှိရင် ပြောလို့ရပါတယ်။
```
