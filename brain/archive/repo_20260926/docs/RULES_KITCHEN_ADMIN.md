## 🎯 หลักเดียวที่ต้องเข้าใจตรงกันทุกคน

> ### **ครัวนับของ · แอดมินคุมใบ · ระบบคิดเลข**
> **ไม่มีใครต้องทำงานของอีกฝ่าย และไม่มีใครต้องคิดเลขแทนระบบ**

**ของในตู้ = ของที่ลูกค้าจองไว้แล้วแต่ยังไม่ได้หยิบ + ของที่ยังว่างอยู่**
ครัวนับได้เท่าไหร่ = เท่านั้น · **ไม่ต้องลบ ไม่ต้องบวก ไม่ต้องเดา**

---

## 👨‍🍳 ครัว — 4 ข้อ

**1. นับได้เท่าไหร่ ใส่เท่านั้น**
เห็น 3 ใส่ 3 · เห็น 0 ใส่ 0 — **ไม่ต้องดูว่าระบบขึ้นเท่าไหร่ ไม่ต้องทำให้มันตรงกัน**

**2. ถ้าใส่แล้วเลขเด้งกลับ หรือใส่ไม่ได้ → แจ้งเลย อย่าดัดเลขให้มันผ่าน**
นี่คือระบบผิด ไม่ใช่ครัวผิด · **การดัดเลขให้ผ่านคือสิ่งที่ทำให้ทุกคนงงมาตลอด**

**3. จัดของเสร็จ ต้องบอกทุกใบ ทุกครั้ง**
ถ้าไม่บอก = ระบบยังคิดว่าของอยู่ในตู้ แล้วจะขายซ้ำ · **จัดแล้วไม่บอก อันตรายกว่าไม่จัด**

**4. ของเหลือจากเมื่อวาน ห้ามใส่ช่อง "ทำเพิ่ม"**
ของเหลือ ≠ ของที่ทำใหม่ · ใส่ผิดช่องแล้ววันรุ่งขึ้นระบบจะนับเป็นของใหม่ = เลขบวมขึ้นทุกวัน
🔸 *ระหว่างที่ยังไม่มีช่องใหม่ → แจ้งในกลุ่มไลน์แทน อย่าใส่ช่องผิด*

---

## 💁‍♀️ แอดมิน — 4 ข้อ

**1. ทุกงานที่ให้ครัวทำ ต้องมีใบในระบบก่อนเสมอ**
ห้ามสั่งปากเปล่า / ห้ามสั่งในแชทอย่างเดียว · **ไม่มีใบ = ไม่มีใครรู้ว่าของหายไปไหน**

**2. ห้ามลบ/แก้เลขสต๊อกที่หลังบ้านโดยตรง**
มันไม่ทิ้งร่องรอย → เลขเพี้ยนแล้วตามไม่เจอเลยแม้แต่ตัวเจ้าของร้าน
🔸 *ตอนนี้ยังไม่มีปุ่มที่ถูกให้ใช้ — ถ้าจำเป็นต้องแก้ ให้แจ้งไว้ก่อนว่าแก้อะไร ทำไม*

**3. ลูกค้าได้ของขาด แล้วเปลี่ยนเป็นเมนูอื่น → ต้องแก้ในใบด้วยทุกครั้ง**
เปลี่ยนแต่ของจริง ไม่เปลี่ยนในใบ = เมนูเก่าค้างเป็นของขาย เมนูใหม่หายไปจากสต๊อก **ผิด 2 ต่อ**

**4. งานด่วนระหว่างวัน ต้องบอกครัวผ่านทางที่ครัวเห็นจริง**
ครัวไม่ได้จ้องหน้าจอทั้งวัน — **บอกในจอเฉยๆ ไม่นับว่าบอกแล้ว**

## ⚖️ เวลาเลขไม่ตรงกัน — ตกลงกันไว้ล่วงหน้า

| สถานการณ์ | ทำยังไง |
|---|---|
| **จอบอกอย่าง ตู้บอกอย่าง** | **เชื่อของในตู้เสมอ** แล้วแจ้งไว้ว่าต่างกันเท่าไหร่ |
| **ไม่รู้ว่าของถูกจัดไปหรือยัง** | ถามคนที่จัด **ห้ามเดาแล้วปรับเลข** |
| **เลขต่างกันบ่อยๆ ที่เมนูเดิม** | บอกไว้เลย — นั่นแปลว่าระบบมีรู ไม่ใช่คนเผลอ |

## 🚫 3 อย่างที่จะไม่ทำกันอีก

1. **ไม่โทษกันเรื่องเลขไม่ตรง** — ที่ผ่านมาเลขเพี้ยนเพราะระบบคิดกลับด้าน ไม่ใช่เพราะใครนับผิด
2. **ไม่แก้เลขให้สวยเพื่อให้จอดูถูกต้อง** — จอถูกแต่ของจริงผิด อันตรายกว่าจอผิด
3. **ไม่ทำงานให้กันโดยไม่บอก** — ทุกอย่างที่ทำแทนกันโดยไม่มีร่องรอย จะกลายเป็นปัญหาของคนที่มาทีหลัง

3. **แอดมิน: ทุกงานมีใบก่อน · แก้เมนูในใบทุกครั้งที่เปลี่ยนของจริง**
