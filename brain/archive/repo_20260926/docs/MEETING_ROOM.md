# 🏛️ ห้องประชุม Under360 — พูดครั้งเดียว ทุกห้องได้ยิน

> **นัทขอเอง 17 ส.ค. 2026:** *"ฉันขี้เกียจคุยทีละคน เราสามารถสร้างห้องประชุมได้ไหม"*
> **คำตอบ: ได้ — และไม่ต้องเปิดห้องใหม่ ใช้ห้อง `pm` นี่แหละเป็นโต๊ะประชุม**

---

## 🎙️ วิธีใช้ — นัทพิมพ์ประโยคเดียว

```
"ประชุม: <หัวข้อ>"
```

**ตัวอย่าง:** *"ประชุม: จะเก็บลูกค้าบิลเล็กยังไงไม่ให้ขาดทุนค่าส่ง"*

---

## 🔄 พี่ปืนทำให้ 4 ขั้น

| ขั้น | ทำอะไร |
|---|---|
| **① เลือกคนเข้าประชุม** | ห้องไหนเกี่ยวกับหัวข้อนี้บ้าง — **ไม่เชิญทุกห้อง** เชิญเฉพาะที่มีของจะพูด |
| **② ส่งวาระ** | โพสต์บอร์ดห้องนั้น + ปลุก · แนบ **ข้อมูลจริงที่ query มาแล้ว** เพื่อให้เขาตอบจากของจริงไม่ใช่ความเห็น |
| **③ รวบคำตอบ** | รอห้องตอบ · ถ้าใครเงียบเกิน 1 รอบ → ทวง 1 ครั้ง แล้วเขียนว่า "ห้องนี้ไม่ตอบ" |
| **④ สรุปเป็นมติเดียว** | **ตรงไหนเห็นตรงกัน · ตรงไหนขัดกัน · อะไรที่ต้องนัทเคาะ** — นัทอ่านหน้าเดียวจบ |

**นัทพูด 1 ครั้ง → ได้ความเห็นจากทุกห้องที่เกี่ยว → เคาะครั้งเดียว**

---

## 📋 รูปแบบวาระที่พี่ปืนส่งให้แต่ละห้อง

```markdown
🏛️ ประชุม: <หัวข้อ> · <วันที่>

**นัทถามว่า:** (คำพูดนัทตรงๆ)

**ข้อมูลจริงที่พี่ปืน query มาแล้ว:**
(ตัวเลข/หลักฐาน เพื่อไม่ให้ตอบจากความรู้สึก)

**ขอความเห็นห้องคุณ 3 ข้อ:**
1. จากมุมห้องคุณ เรื่องนี้ติดอะไร
2. ถ้าทำ ห้องคุณต้องทำอะไร / ใช้เวลาเท่าไหร่
3. มีอะไรที่นัทยังไม่รู้แล้วควรรู้ก่อนเคาะ

⏱️ ตอบภายในรอบถัดไป · ไม่เกี่ยวกับห้องคุณ = ตอบว่า "ไม่เกี่ยว" ก็พอ
```

## 📄 รูปแบบมติที่นัทได้กลับ

```markdown
🏛️ มติ: <หัวข้อ> · ตอบมา N/M ห้อง

✅ เห็นตรงกัน:  ...
⚠️ เห็นต่าง:    ห้อง A ว่า... / ห้อง B ว่า...  ← จุดที่นัทต้องเคาะ
🔴 ของที่ไม่มีใครรู้: ...
📌 ถ้าเคาะแล้ว ใครทำอะไร: ...

**สิ่งที่ต้องการจากนัท: (เคาะข้อเดียว/เลือก ก-ข-ค)**
```

---

## ⚠️ ข้อจำกัดที่ต้องรู้ (พูดตรงๆ)

- **ไม่ใช่ประชุมสด** — ห้องเป็น session แยก ตอบตามจังหวะที่ถูกปลุก · **ปกติได้ครบใน 1-2 ชั่วโมง**
- **รอบอัตโนมัติปลุกห้องไม่ได้** → ถ้านัทเรียกประชุมตอนดึก จะได้คำตอบตอนเช้า
- **ห้อง `u` กับ `cc` มีกล่องจดหมายเอง** → 2 ห้องนี้ตอบเร็วสุด ไม่ต้องปลุก

---

## 🚫 เรื่องที่ไม่ควรเรียกประชุม

| อย่าเรียกประชุมถ้า... | ทำแทนด้วย |
|---|---|
| เป็นเรื่องของห้องเดียว | ส่งงานตรงห้องนั้น |
| คำตอบ query จาก DB ได้ | ให้พี่ปืนไปหาเอง |
| นัทตัดสินใจได้เองอยู่แล้ว | เคาะเลย ไม่ต้องถามใคร |

**ประชุมมีไว้สำหรับเรื่องที่ต้องการมุมมองจากหลายห้องพร้อมกัน** — ไม่ใช่ที่กระจายงาน
