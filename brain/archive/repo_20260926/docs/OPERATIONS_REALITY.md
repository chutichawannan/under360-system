## 🛵 แมสเซนเจอร์ — **ไม่มีแล้ว**

> **นัทพูดเอง:** *"แมสตอนนี้ลาออกไปหมด ใช้ลาล่ามูฟ"*

🔴 **เปลี่ยนความเข้าใจครั้งใหญ่:**
- **ร้านไม่มีคนส่งของเป็นพนักงานแล้ว = Lalamove ล้วน**
- → **"ห้องแชทแมส" ที่อยู่ในเป้าเฟส 1 (เข้าห้องแชท 3 ห้อง: แอดมิน/ครัว/แมส) — ไม่มีอยู่จริงแล้ว**
- → งานพี่เก่ง (จับคู่รอบ ลดค่าส่ง) **สำคัญขึ้น ไม่ใช่ลดลง** เพราะทุกบาทคือค่า Lalamove ตรงๆ

> *"นัทใช้วิธีเปิด application ทั้งโกและเฟรช **เทียบราคา** แล้วกดสั่งจากรายการที่สินค้าถูกที่สุด
> **หลายครั้งที่นัทขี้เกียจเปิด 2 อันเพราะมันต้องเปิดคอม ก็จะสั่งเจ้านึงไปให้จบๆ เลย**"*

**= ทุกครั้งที่ขี้เกียจเปิด 2 แอป ร้านจ่ายแพงกว่าที่ควรโดยไม่มีใครรู้ว่าเท่าไหร่**

## 🩺 Kidneycare — flow จริงตอนนี้ (ทำมือทั้งหมด)

```
ลูกค้า  →  กิ๊ฟรับเรื่อง  →  ส่งข้อมูลให้นักโภชนาการ  →  แจ้งครัวล่วงหน้า 1 วัน
                                                              ↓
                                            ครัวผลิต "ลัดคิว" ในช่วงเช้าวันถัดมา
```

⚠️ **"ลัดคิว" = แทรกแผนผลิตปกติ** แต่**ไม่มีอยู่ในระบบเลยสักจุด** → นิว/ฟ้าวางแผนโดยไม่รู้ว่ามีงานแทรก

## 📅 ปฏิทินการผลิตรายสัปดาห์ — **ไม่เคยถูกบันทึกมาก่อน**

| วัน | ผลิตอะไร |
|---|---|
| **อาทิตย์** | **เมนู S1-S8** (เมนูพิเศษประจำสัปดาห์) |
| **จันทร์ · พุธ · ศุกร์** | **Meal Plan** (ทำสด) |
| **อังคาร · พฤหัสบดี** | **อาหารเด็ก** ← *เพราะเป็นวันที่ว่างที่สุด* |

🔑 **นี่คือข้อมูลที่ นิว · ฟ้า · buyer ต้องใช้ทุกวัน แต่ไม่เคยมีใครบอก**
→ อธิบายได้ว่าทำไม **อังคาร/พฤหัส = วันว่าง** และเป็นช่องที่แทรกงานได้
