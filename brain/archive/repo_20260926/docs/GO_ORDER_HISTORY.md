## 🔑 ข้อค้นพบที่เปลี่ยนวิธีออกแบบระบบ

**ของ 79% สั่งครั้งเดียวจบ** → รายการสั่งของ **ไม่ใช่ลิสต์ตายตัว** แต่เปลี่ยนตามเมนูของสัปดาห์นั้น
ระบบจึง **เดา "ของ" ตรงๆ ไม่ได้** ต้องเดินทางเดียวคือ:

```
เมนูที่ต้องผลิตพรุ่งนี้  →  วัตถุดิบของเมนูนั้น  →  รวมยอด  →  ปัดเป็นหน่วยซื้อ
```

**แต่** มีของกลุ่มหนึ่งที่สั่งซ้ำเกือบทุกครั้ง — **กลุ่มนี้ทำเป็น "รายการยืนพื้น" ได้เลย ไม่ต้องรอสูตร**
