## 🔴 ต้องแก้ก่อน cutover

### 1. ไม่มีการตัดสต็อกอัตโนมัติเลย (oversell)
- `liff_customer.html` อ่าน `stock_total` (`effectiveStock` บรรทัด ~1756) **แต่ไม่พบโค้ดใดๆ ที่ลด `stock_total` ตอนลูกค้าสั่ง** (grep ทั้งไฟล์: เจอแค่ comment + อ่านค่า)

- **ผล:** ลูกค้าสั่งไปเท่าไหร่ตัวเลขไม่ลด → badge "เหลือ N ชิ้นสุดท้าย" ไม่จริง → **ขายเกินได้** (กระทบ 22 เมนูที่ตั้งสต็อกจำกัด · เมนู `NULL` = ไม่จำกัด ไม่กระทบ)
- กันชนที่มีตอนนี้ = เช็ค remaining **ในตะกร้าของ browser ตัวเองเท่านั้น** (ข้ามคนไม่รู้กัน)
- ⚠️ ต้องเคาะก่อนแก้: ตั้งใจให้แอดมินคุมมือ หรือควรตัดอัตโนมัติ? (ถ้าตัดอัตโนมัติ ควรทำที่ DB ระดับ atomic กันสั่งพร้อมกัน)

### 2. `customer.html` — บั๊กซ้อน 3 ชั้น (แบบเดียวกับที่ OH เพิ่งแก้ใน u0.4.41 แต่ไฟล์นี้ยังไม่ได้แก้)

### 3. `liff_profile.html` — หน้า "สั่งซ้ำ" โชว์เมนูปลอม
- บรรทัด 242 select `menu_items(... stock_quantity)` — **`stock_quantity` ไม่มีอยู่จริง** (ของจริง = `stock_total`) → query error → ตกไป **mock data** (บรรทัด 246: "อกไก่ย่างสมุนไพร/สันในหมูย่าง" hardcode)
