นัทตั้ง CC เป็น **ชุมสายกลาง** (21 ส.ค. 2026): งานจากกะปัน/เลขา/ที่ CC เจอเอง → **ดูว่าเป็นของห้องไหน แล้วยิงตรงด้วย `send_message`** ⛔ ห้ามลงบอร์ดแล้วหวังว่าเขาจะเห็น (บอร์ด = ตู้ไปรษณีย์ ไม่ใช่กระดิ่ง — ของเคยหายมาแล้วหลายรอบ)

**Why:** CC เป็นคอขวดง่ายที่สุดเพราะทุกอย่างไหลผ่าน · แตะไฟล์ห้องอื่น = ชนกัน · นัทพูดเอง *"CC ไม่ระวังเหมือนนาย เขาอาจจะสร้างความพินาศเพิ่มอีกก็ได้"* / *"อย่าให้ CC ทำพังนะ"*

**How to apply:**
- **CC ลงมือเองได้ 3 กรณีเท่านั้น:** ไม่มีห้องเจ้าของจริงๆ (เช็ค `work_claims` ก่อน) · นัทสั่งห้อง CC ตรงๆ · ลูกค้ากำลังเดือดร้อนอยู่ตอนนี้ (แล้วต้องแจ้งเจ้าของไฟล์ทันที)
- **งานบานเมื่อไหร่ = ส่งต่อเมื่อนั้น** ไม่ต้องรอให้จบก่อน
- **ห้ามแก้ไฟล์ของห้องอื่น ไม่ว่าจะกดขึ้นเองหรือเตรียม branch ให้คนอื่นกด** (ฉบับแก้ 21 ส.ค. — ฉบับเดิมเขียนว่า "ห้ามกด push main เอง" ซึ่งระบบบล็อกอยู่แล้ว = กฎที่ไม่ปิดรูจริง) · ห้ามแตะไฟล์ที่มีคนจอง `work_claims`
- **เส้นที่นัทเคาะเอง 24 ส.ค. (อย่าจำผิด):** ขึ้นเว็บ/บทความสาธารณะ = **ห้องทำได้เลย ไม่ต้องรอนัท** (เป็นส่วนของพลอย) · **ส่งข้อความหาลูกค้า = ยังไม่ทำ ต้อง clarify กันก่อน** · คำว่า "แตะราคา" **ถอนออกแล้ว** — นัทบอกว่า "ไม่เข้าใจ" เพราะเป็นคำที่ห้องคิดกันเอง
- 🔑 **นัทไม่รับรู้สิ่งที่ห้องคุยกันเอง** — เขาพูดเอง: *"อะไรที่ผ่านประโยคที่พวกนายคุยกัน ฉันไม่รับรู้นะ ฉันรอสรุปอย่างเดียว จะตอบแค่ในส่วนที่ฉันพิมพ์คุยเท่านั้น"* → **เสนออะไรให้นัทเคาะ ต้องใช้คำที่เขาเข้าใจได้โดยไม่ต้องอ่านย้อน** ห้ามอ้างชื่อ/ตัวเลือกที่ตั้งกันเองในห้อง (เช่น "แบบ ก/ข")
- **ด่านกรองก่อนส่งต่อ:** คำขอบอก "ยังไม่มี" → เช็คของจริงก่อน (ฝั่งพลอยอยู่บนข้อมูลเก่าเสมอ) · แตะตัวนับ/ตัววัดผล → กันของซ้ำ · แตะข้อความเว็บ → ตรวจคำต้องห้าม · ใช้เงิน/เปลี่ยนทิศทาง/ขัดคำสั่งเดิม → ส่งเลขา
- **ถามตัวเองก่อนปล่อยผ่าน: "ถ้าอันนี้ผิด จะมีอะไรขึ้นเตือนไหม"** ไม่มี = ต้องนับของจริงก่อน ห้ามเดา
- CC กับเลขาต้องบอกกันทุกครั้งที่ยิงงานออก (มี 2 ทางเข้า: กะปัน→CC และ นัท→เลขา) · ซ้ำแล้วให้ฝ่ายที่ส่งทีหลังถอน แล้วบอกปลายทางว่ายึดฉบับไหน
