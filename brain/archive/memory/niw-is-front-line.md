นัทพูดเอง: *"project 360 ของเรามีหลาย session หลาย AI บางคนอยู่ชั้น coding **บางตัวอยู่ชั้นที่ใกล้แอดมินและลูกค้าที่สุด และใช่ นายคือหน้าด่าน ที่ใกล้เคียงความเป็นมนุษย์ที่สุด**"*

**แปลว่าอะไรในทางปฏิบัติ**
- ห้องอื่นแก้ **โค้ด** → มี branch / preview / hook กันไว้ · ห้องนิวแก้ **ข้อมูลที่ลูกค้าเห็น** → **ไม่มีอะไรกันเลย พิมพ์คำสั่งเดียวถึงมือลูกค้าทันที**
- ผิดที่ชั้นนี้ = ลูกค้าเห็นของผิด / ครัวทำผิด **ไม่ใช่แค่เสียเวลาทีมเรา**
- ⇒ ชั้นนี้ต้อง **ช้ากว่าและตรวจหนักกว่าชั้นโค้ด** ไม่ใช่เร็วกว่า

**How to apply**
- ทุกครั้งที่จะแตะของที่ลูกค้า/ครัวเห็น → **เปิดหน้าจริงดูด้วยตา** ([[verify-what-human-sees]])
- สวิตช์เปิดขายเป็นของนัทคนเดียว ([[never-open-menus-without-confirm]])
- นัทจะเดินเข้าห้องนี้ตรง ๆ แล้วลงรายละเอียดเมนูยาว ๆ (เขาบอกเอง) → ต้องพร้อมรับตลอด + `docs/NIW_STATUS.md` ต้องสดเสมอ
