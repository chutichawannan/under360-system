นัทอนุญาตให้ Claude **ปิดแอดที่ไม่เวิร์คได้เอง** (27 ส.ค. 2026) แต่มีเงื่อนไขบังคับ: **ปิดแล้วต้องหยุดทันที → รายงานนัท → ขออนุญาตก่อนเปิดใหม่หรือแก้อะไรต่อ**

**Why:** นัทพูดเอง — *"ถ้าเกิดว่านายเปิดปิดเปิดปิดเปิดปิดของนายไปเรื่อยๆ สุดท้ายฉันจะไม่รู้แล้วตามไม่ทัน ฉันไม่ต้องการเป็นแบบนั้น"*
เจ้าของธุรกิจต้องรู้ว่าเงินตัวเองเกิดอะไรขึ้น ไม่ใช่ตื่นมาเจอผลลัพธ์ที่ตามย้อนไม่ได้ · การ "แก้ให้เสร็จเงียบๆ" ทำให้นัทหลุดจากลูปการตัดสินใจเรื่องเงินของตัวเอง

**How to apply:**
- ปิดแอดได้เองตามเงื่อนไขที่ตกลงไว้ (2 วัน 0 ออเดอร์ · งบเพี้ยน · วันจบหาย · รูปพัง) — **ปิด = หยุดเลือด ทำได้ทันที**
- ปิดแล้ว **หยุดตรงนั้น** ⛔ ห้ามเปิดใหม่ · ห้ามแก้งบ · ห้ามเปลี่ยนรูป · ห้ามสร้างตัวใหม่แทน
- รายงานนัท 4 ข้อ: **ปิดตัวไหน · เพราะอะไร · ใช้เงินไปเท่าไหร่ · เสนอว่าควรแก้ยังไง** + แนบภาพหน้าจอ
- แล้ว **รอนัทเคาะ** ว่าจะเปิดต่อ/แก้/ทิ้ง
- เขียนสรุปลง [[ads-history-library]] ทุกครั้งที่แคมเปญจบ

หลักการเบื้องหลัง: **ปิดผิด = เสียโอกาส · เปิดผิด = เสียเงิน** → อำนาจที่ให้จึงไม่สมมาตรโดยตั้งใจ
