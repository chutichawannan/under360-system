**15 ก.ย. 2569 — เลขานับสูตร Meal Plan ผิด แล้วไปบอกห้องฟ้าว่าใบค้างของฟ้าเก่าแล้ว**

เลขานับว่า `parts[].lines.length > 0` = "มีวัตถุดิบ" → รายงานว่า **148 สูตรมีวัตถุดิบจริง เหลือว่าง 8**
ฟ้าทักกลับว่าไม่ตรง → เปิดดูเนื้อในบรรทัดจริง พบว่า **144 เป็นแม่แบบเปล่า** (`{qty:"", name:"คาร์บ ระบุ…"}`) · **มีวัตถุดิบจริงแค่ 3-4 ตัว** → **ฟ้าถูกมาตลอด**

**Why:** ช่องที่ "ไม่ว่าง" มักมี placeholder/แม่แบบอยู่ — การนับความยาว array จึงให้ภาพตรงข้ามกับความจริง · และตัวเลขผิดนี้เกือบทำให้สั่งงานผิดเป้า (บอกกะปันให้เติม 8 ช่อง ทั้งที่ของจริงต้องเติม 144)

**How to apply:**
- ก่อนรายงานตัวเลขนับจากฐานข้อมูล → **สุ่มเปิดดูเนื้อใน 3-5 ตัวอย่างเสมอ** แล้วค่อยสรุป
- ตั้งเกณฑ์ "ใช้งานได้" ให้ชัดก่อนนับ (เช่น ต้องมีทั้งชื่อของ + ปริมาณ ไม่ใช่แค่มีบรรทัด)
- ⛔ **ห้ามเอาตัวเลขที่ตัวเองเพิ่งนับ ไปบอกห้องเจ้าของเรื่องว่า "เอกสารคุณเก่าแล้ว"** — เจ้าของเรื่องอยู่กับข้อมูลนั้นทุกวัน ถ้าเลขไม่ตรงให้ถามก่อน ไม่ใช่ประกาศทับ
- เจอว่าตัวเองผิด → **แก้ข่าวไปทุกห้องที่เคยส่งใบผิด** พร้อมบอกว่าคำสั่งเดิมข้อไหนต้องทิ้ง
