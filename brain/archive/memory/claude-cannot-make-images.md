**Claude สร้าง/แก้ภาพกราฟิกให้นัทไม่ได้ — ห้ามรับปาก** (นัทสั่งเอง 8 ส.ค. 2026 หลังเสียโทเคนฟรีกับโบรชัวร์ที่ออกมาพัง)

**Why:** ลอง canvas ทับโบรชัวร์เดิม (1040×1289) แล้วพังหลายจุดพร้อมกัน — รูปเก่าไม่ถูกลบโผล่ข้างหลัง · รูปใหม่ล้นกรอบเพราะ**เดาพิกัดไม่ได้วัดจริง** · ฟอนต์ไทยเป็น default ไม่ใช่ฟอนต์แบรนด์ · ส่วนล่าง (D1-D5) ยังเป็นข้อมูลเก่าขัดกับส่วนบน · เครื่องไม่มี sharp/PIL/magick · **ความผิดหลัก = ไม่ประเมินตัวเองก่อนรับปาก พิมพ์ว่า "ทำได้แน่" ทั้งที่ยังไม่รู้วิธี** (ผิดกฎ verify-ก่อนพูดของนัทเอง)

**How to apply:**
- ขอให้ทำรูป/กราฟิก → **บอกตรงๆ ว่าทำไม่ได้** แล้วเสนอทางที่ใช้ได้จริงแทน (ห้ามลองแล้วค่อยขอโทษ)
- **แบ่งงานที่ถูก:** Claude = เลือกเมนู · เตรียม CSV/ข้อมูล · เขียน copy · เขียน prompt ให้ AI image tool | คน/เครื่องมือ = พิกเซล
- โบรชัวร์เมนูรายสัปดาห์ = **งาน template + data merge ไม่ใช่งาน AI generate** → Canva Bulk Create (นัทถือ template, Claude ส่ง CSV)
- ยกเว้นเดียวที่ยังทำได้: กราฟ/ไดอะแกรม/หน้าเว็บ (HTML/SVG) — คนละเรื่องกับงานกราฟิกแบรนด์
