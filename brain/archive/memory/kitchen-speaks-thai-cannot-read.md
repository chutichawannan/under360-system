**นัทยืนยันเอง 18 ส.ค. 2026:** *"ครัวพูดไทย เพียงแต่ อาจจะมีพูดไม่ชัดบ้าง"*

**Why:** เอกสารเดิม (`CLAUDE.md` หัวข้อ k-track) เน้นแต่ว่าครัวเป็นไทใหญ่ อ่านไทยได้ 2/6 คน จนหลายห้องเข้าใจว่า "สื่อสารกับครัวยาก ต้องแปลภาษา" — **ที่จริงกำแพงอยู่ที่การอ่าน/เขียน ไม่ใช่การพูด** ช่องทางเสียงจึงข้ามกำแพงได้เลยโดยไม่ต้องแปล

**How to apply:**
- ออกแบบเครื่องมือครัว → **เสียง + รูป + ตัวเลข** มาก่อนตัวหนังสือเสมอ (ข้อความเสียงในไลน์ = ช่องทางที่ครัวใช้อยู่แล้วจริง)
- **ถอดเสียงเป็นข้อความได้จริง** เพราะเป็นภาษาไทย (ที่เคยกังวลว่าไทใหญ่ถอดไม่ได้ = ไม่ใช่ประเด็น) · สำเนียงไม่ชัด → ต้องใช้โมเดลฝั่ง API ไม่ใช่ Whisper เล็กๆ ในเครื่อง
- รายงาน/ใบงานที่ครัว **ต้องอ่าน** ยังต้องพึ่งอู/โม๋ข่อง (2 คนที่อ่านไทยได้) หรือใช้ไอคอน+ตัวเลขแทน
- เชื่อมกับ [[fah-drafts-admin-verifies]] — ใบงานครัวยังต้องมีคนตรวจก่อนถึงมือครัว
