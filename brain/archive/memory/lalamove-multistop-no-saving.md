วัดด้วยเรทสด Lalamove กับงานส่งจริง 5 ส.ค. 2026 (15 จุด กทม.) — **วิธีจับกลุ่มเปลี่ยนผลลัพธ์ทั้งหมด**:

| วิธีจัดรอบ | ผล |
|---|---|
| แยกคันต่อจุด (แอดมินทำอยู่) | ฿1,404 |
| **จับกลุ่มตามทิศ+ระยะ (≤6 กม. · ทิศติดกัน · ≤6 จุด/รอบ)** | **฿1,129 = ประหยัด 20%** |
| แบ่งรอบตามลำดับ N จุด (ไม่ดูทิศ) | ฿993–1,136 = **แพงกว่า** แยกคัน |

**Why:** Lalamove คิดตามระยะที่วิ่งจริง · ครัวอยู่กลาง (13.7179969, 100.5010971) จุดกระจายรอบทิศ → ถ้าเอาจุดคนละทิศมาต่อกันเป็นสาย ระยะรวมยาวกว่าวิ่งตรงจากครัวทีละจุด · **รวมรอบชนะเฉพาะตอนจุดเกาะกลุ่มกันเองในทิศเดียวกัน**

**How to apply:** อัลกอริทึมจัดรอบต้อง **จับกลุ่มตามทิศ+ระยะก่อน** ห้ามแบ่งเป็นก้อนละ N ตามลำดับเฉยๆ · ใช้เป็นฐานออกแบบ agent พี่เก่ง · **รถเก๋งแพงกว่ามอเตอร์ไซค์ทุกกรณีที่ลอง** (~1.4-1.9 เท่า) → ใช้ต่อเมื่อของเกิน 20 กก. (เพดานมอเตอร์ไซค์) เท่านั้น

**สเปคจริงจาก Lalamove API (`?info=cities` · verify แล้ว):** กทม. **ไม่มีตัวเลือก "ประหยัด/ธรรมดา"** — มีแค่ประเภทรถ (MOTORCYCLE 20 กก. · CAR 100 กก. · MPV/SUV/รถกระบะ/รถบรรทุก) + special request (ถุงเก็บอุณหภูมิ · ไป-กลับ · เก็บเงินปลายทาง)

**ยังขาด:** ต้นทุนแมสร้านต่อเที่ยว (ฝาก f-track) · น้ำหนัก/จำนวนกล่องต่อใบ (order_items ไม่ครบ) → วางแผนว่าเกิน 20 กก. ไหมยังทำไม่ได้

เครื่องมือ: ปุ่ม "💰 คำนวณค่าส่งถูกสุด" ในแท็บแมสเซนเจอร์ `operation_hub.html` · API หลายจุดที่ `api/lalamove-quote.js` (`{drops:[...]}`, `?info=cities`)
⚠️ **ปุ่มใน OH ยังใช้วิธีแบ่งตามลำดับ (แบบที่แพงกว่า) — ยังไม่ได้อัปเป็นการจับกลุ่มตามทิศ**
