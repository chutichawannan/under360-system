นัทสั่งเอง (28 ส.ค. 2026): **"แก้ที่ต้นเหตุ ต่อไปนี้ เราจะแก้ที่ต้นเหตุเท่านั้น"**

**Why:** เคสกวาง (อินฟลู VIP จ่ายเงินแล้ว) หลุดจากใบครัว 2 วันซ้อน เพราะหน้า "สั่งแทนลูกค้า" เขียนวันส่งลง `orders` กับ `mp_deliveries` คนละวันแบบเงียบๆ · ห้องฟ้ารู้อาการนี้มาเป็นสัปดาห์ ("5 จุดที่พังซ้ำทุกรอบ") แล้ว **กรองด้วยมือทุกวันแทนที่จะแก้ต้นตอ** — การกรองมือทำให้บั๊กมองไม่เห็นและอยู่ต่อได้เรื่อยๆ จนกัดลูกค้าจริง · ทุกวันที่แก้ปลายทาง = จ่ายค่าแรงซ้ำ + บั๊กยังอยู่ + ดินพอกหางหมู

**How to apply:** เจออาการซ้ำครั้งที่ 2 = หยุดกรองมือ ไล่หาต้นตอในโค้ด/ไปป์ไลน์ให้เจอ แล้วส่งเจ้าของระบบแก้ **พร้อมชี้ไฟล์+บรรทัด** · workaround ทำได้เฉพาะเพื่อกันของเสียหายเฉพาะหน้า และต้องมีตั๋วต้นเหตุคู่กันเสมอ · ห้ามเขียนกฎใหม่ให้ agent "คอยระวัง" แทนการแก้โค้ด — [[fah-acts-like-human-not-code]] · [[verify-what-human-sees]]
