**นัทบอกเอง 12 ส.ค. 2026:** *"คอมนี้รับรู้ไว้ซะนะว่ามันเปิด 24 ชม. รันมาเพื่อ claude code เฉพาะ"*

**Why:** เปลี่ยนสมมติฐานการออกแบบทั้งหมด — เดิม Claude คิดว่า "ต้องรอนัทเปิดคอม" เลยไม่กล้าเสนออะไรที่ต้องรันต่อเนื่อง
ของจริงคือ **cron / ตัวเฝ้า / กล่องจดหมายที่ poll ทุกกี่นาที = ทำได้จริง** ไม่ต้องยกขึ้นคลาวด์

**How to apply:**
- เสนอ automation ที่ต้อง "รันค้าง" ได้เลย (เฝ้าเว็บ · poll กล่องจดหมาย · เช็คยอดรายวัน)
- ⚠️ **แต่ข้อจำกัดจริงไม่ใช่เครื่อง — คือ session ค้าง** นัทบอกว่า *"ช่วงนี้มีปัญหาคือแต่ละห้องคุยกันแล้วชอบค้าง"*
  → ออกแบบให้ **ไม่พึ่งห้องเดียว** · มี cron ปลุกซ้ำ · เขียนสถานะลงไฟล์/DB ทุกครั้ง ไม่เก็บไว้ในหัว session
  → ตรงกับ [[docs-are-snapshots-verify-first]] และระบบบอร์ด `session_messages`
- สิ่งที่ยังทำไม่ได้แม้คอมเปิด: งานที่ต้องรอ **คนกดยืนยัน** (login · จ่ายเงิน · token)
