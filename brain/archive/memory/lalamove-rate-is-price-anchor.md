slot **"ส่งระบุเวลา"** ใน `liff_customer.html` ดึงเรทจริงจาก Lalamove v3 API (`api/lalamove-quote.js`) — ราคาออกมา **2-4 เท่าของค่าส่งปกติร้าน** (เช่น 5 กม. ร้านคิด ฿30 · Lalamove ฿119 · verify กับพิกัดลูกค้าจริง 3 ส.ค. 2026)

**Why:** นัทเคาะเอง (3 ส.ค. 2026) ว่าตัวเลขแพงนี้ **คือฟีเจอร์ ไม่ใช่บั๊ก** — *"มีไว้ขู่ลูกค้าเฉยๆ ว่าถ้าไม่เลือกให้เราส่งเอง ราคาจะบ้าบอ"* → เป็น **anchor ราคา** ให้ลูกค้าเห็นว่าค่าส่งของร้าน (ที่ร้าน subsidize 30-50K/เดือน) ถูกกว่ามาก ไม่ได้ตั้งใจให้ลูกค้าเลือกช่องนี้จริงๆ

**How to apply:** ห้าม "แก้ให้ถูกลง"/ใส่ cap/หาร 2 เพราะคิดว่าคิดเงินผิด — ถ้าจะเปลี่ยนต้องให้นัทสั่งเท่านั้น · ใช้เป็นวัตถุดิบ marketing ได้ว่าค่าส่งร้านถูกเพราะร้านช่วยออก (แต่ยังห้ามเคลม "ถูกที่สุด" ตามกฎ copy — ดู [[response-style-concise]] ไม่เกี่ยว แต่กฎ copy อยู่ใน CLAUDE.md) · auto-booking ยังไม่ทำ (ตอนนี้ขอราคาอย่างเดียว) = งานพี่เก่งต่อ
