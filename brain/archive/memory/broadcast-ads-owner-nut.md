นัทเป็นคน **ยิง broadcast LINE OA + โฆษณา (FB/Google) เองทั้งหมด** — แอดมินไม่ได้ยิง broadcast/แอด · แอดมินหน้าที่ = ตอบแชทลูกค้า + tag ในแชท (chat.line.biz) เท่านั้น

**Why:** CLAUDE.md + masternote หลายจุดเขียน "broadcast/CRM owner = แอดมิน/พลอย" หรือสั่งงาน broadcast ให้แอดมิน — นัทแก้ 22 ก.ค. 2026 ว่าผิด: broadcast/ad = นัทลงมือเอง

**How to apply:** ทุก deliverable เรื่อง broadcast/ad (copy, segment, ปุ่ม CTA, calendar/จังหวะยิง) = ทำให้ **นัทเอาไปยิงเอง** (paste-ready สำหรับนัท) ไม่ใช่ "ส่งให้แอดมินยิง" · งานที่มอบแอดมินได้ = เฉพาะ **ตอบแชท / tag รายคน / win-back ไล่ทักรายคนในแชท** · ปลายทาง broadcast routine = handoff ให้ subagent เอิธ (ไม่ใช่แอดมิน)
