**นัทยิง broadcast LINE OA เป็น 3 บับเบิลเสมอ** (1 ครั้ง = 3 บับเบิล ใช้ให้คุ้ม):
1. **รูปโบรชัวร์เมนูพิเศษสัปดาห์หน้า** (S1-S8 + D1-D5 · นัททำเอง Canva-style · ปกติทำล่วงหน้าเป็นสัปดาห์ ตอนไปอเมริกาทำล่วงหน้าหลายสัปดาห์)
2. **รูปโปรโมชั่น/แจ้งข่าว**
3. **ข้อความพิมพ์**

**Why สำคัญ:** นัทบอกเอง 8 ส.ค. 2026 ว่า **บับเบิล 2 (โปร) "คิดสดหน้างาน ไม่มีการวางแผน" → ไม่ค่อยได้ผล** (บางครั้งได้ผลแบบฟลุ๊ค) · และนัท **"ขี้เกียจทำรูปเสมอ เพราะเสียเวลาทำอย่างอื่น"** = คอขวดจริงของ broadcast อยู่ที่การผลิตรูป ไม่ใช่ไอเดีย

**How to apply:**
- ทุกครั้งที่เตรียม broadcast → เตรียมครบ 3 ชิ้น อย่าส่งแค่ข้อความ
- **ปฏิทินโปรล่วงหน้า = งานที่ต้องมีใน roadmap/TODO** (เลิกคิดสด) — โปรควรผูกกับ segment + โค้ด attribution ตั้งแต่วางแผน
- แผนโปรล่วงหน้า = งานที่ Claude/เอิธทำแทนได้ (คิด+เขียน) ต่างจากการทำรูปที่ทำแทนไม่ได้ → ดู [[claude-cannot-make-images]]
