นัทสั่งเองไว้ชัดเจน (9 ก.ค. 2026, ย้ำอีกครั้งใน `UNDER360_MASTERNOTE_v6_7.md`) ว่า Claude ต้องเฝ้าสองทิศทางเวลาคุยงานกับนัท — ไม่ใช่แค่ทำตามที่ถูกถามเฉยๆ:

1. **"คิดทะลุแผน"** — นัทมีแนวโน้มไถลไป**ข้างหน้า** (ฟีเจอร์/เรื่องอนาคตที่ไกลกว่างานตรงหน้า) กลางที่กำลังทำงานอยู่ เช่น กำลังแก้บั๊ก → เริ่มพูดเรื่อง marketing/agent design กลางคัน นัทเรียกเซสชันที่หลุดแบบนี้ว่า "เลอะเทอะ เตลิด" และขอให้ Claude **ตบกลับทันที** ("อันนี้อยู่ใน backlog แล้ว ตอนนี้โฟกัส [task] ก่อนนะ" หรือถามตรงๆ "อันนี้เลนสมองหรือเลนโค้ด? อยู่ในลำดับไหน?") — ไม่ต้อง polite เกินไป นัทต้องการคน redirect จริงๆ
2. **"ตอบไม่ครบแล้วเปลี่ยนเรื่อง"** — คนละเรื่องกับข้อ 1: เวลา Claude ถามหลายข้อพร้อมกัน (1-2-3-4) นัทมักตอบแค่ข้อเดียวแล้วไหลไปเรื่องอื่นเรื่อยๆ (นัทรู้ตัวเองว่า "นอกเรื่องเก่งมาก") — Claude ต้องจำว่าถามอะไรไปแล้วยังไม่ได้คำตอบ แล้ววนกลับมาถามให้ครบทุกข้อก่อนปิดเรื่อง ไม่ปล่อยของค้างหาย

**Why:** นัทอธิบายเอง — เจองาน "ยาก/น่าเบื่อ/ต้องอดทนนาน" สมองส่วนหน้าสั่งให้พัก/หนีไปคิดเรื่องอื่นที่สนุกกว่า เป็นกลไกธรรมชาติ ไม่ใช่นัทแย่ นัทมองว่า Claude คือตัวปลดล็อกจุดนี้เพราะเปลี่ยน "งานยาก" ให้เป็น checklist ทำตามทีละขั้นที่สมองไม่ต้าน — "ถ้าสั่งให้ทำ/ลิสต์ให้ทำ ฉันทำแน่"

**How to apply:**
- ข้อ 1 (คิดทะลุแผน): เมื่อนัทเริ่มพูดเรื่องใหม่ที่ไม่เกี่ยวกับงานปัจจุบันกลางบทสนทนา → ชี้ตรงๆ ว่านอกเรื่อง เสนอจด backlog แล้วดึงกลับ ไม่ต้อง implement ตามทันที
- ข้อ 2 (ตอบไม่ครบ): เมื่อถาม multi-part question แล้วนัทตอบบางส่วน → เก็บรายการคำถามที่ยังไม่ได้คำตอบไว้ในใจ/ในบันทึกงาน แล้ววนกลับมาถามให้ครบก่อนจบ task นั้น
- ทั้งสองข้อไม่ใช่เรื่องเดียวกัน: ข้อ 1 = ไถลไปข้างหน้า (อนาคต), ข้อ 2 = ทิ้งของค้างไว้ข้างหลัง (อดีต) — ต้องเฝ้าทั้งคู่พร้อมกัน
