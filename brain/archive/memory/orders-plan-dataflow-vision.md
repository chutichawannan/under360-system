นัทอยากให้ระบบเชื่อม order จริงเข้ากับการวางแผน:

**แพลนเมนู (operation_hub):**
- รายชื่อลูกค้า**ควร**ดึงจากคนที่สั่ง/สมัคร HP-LC ของวันนั้นจริง (order_type=meal_plan) → เด้งเข้าแพลนตามวันที่
- ตอนนี้ยังเป็น `MOCK_CUSTOMERS` (ฮาร์ดโค้ด 8 คน) ไม่ผูกวันที่/order — งาน น้องนิว v0.4 [[mealplan-customization-logic]]
- Layout ที่อยากได้: หัววันที่อยู่เหนือบล็อกลูกค้า · เลือกหลายวัน → ลูกค้าของแต่ละวันโผล่ตามจริง

**แท็บออเดอร์ (sidebar บนสุด) — ต้องขยาย:**
- ดูได้ อดีต / ปัจจุบัน / อนาคต (กดตามวัน)
- ดูราย **30 วัน** → สรุปว่าผ่านมามีออเดอร์เท่าไหร่
- **แยกประเภท:** คอร์สทำสด (HP/LC = order_type meal_plan) vs อาหารทำล่วงหน้า (สต็อก = individual/package)
- ตอนนี้มีแค่ วันนี้/พรุ่งนี้/ทั้งหมด ไม่มี past/30วัน/type breakdown

**Flow ข้ามแผนก (สำคัญ): order เข้า → 2 ที่**
- **① ออเดอร์:** ภาพรวมทั้งวัน + สรุปยอดขายรายวันคร่าวๆ → น้องนิว + AI มาเก็ตติ้ง ใช้ร่วมกัน
- **② แพลนเมนู:** แอดมิน assign เมนูรายคน + เลือกเมนูประจำสัปดาห์ = รายงาน + ใบงาน + จุดประสานแผนก
- ลูกโซ่: `แพลนเมนู → KQ → ครัวจัดลงถุง → แมสรับไปส่ง`
  - KQ โชว์ว่าลูกค้าแต่ละคนรับอะไร (เช่น "A รับ LC 7 กล่อง"; บางคน 3-6 กล่องตาม assign)
  - ครัวดู 2 หน้า: แพลนเมนู (ผลิตอาหาร) + KQ (จัดลงถุงต่อให้แมส)
  - แมสดู KQ ด้วย — ทุกหน้าลิ้งต่อกัน

**Why:** เป็นทิศทางที่นัทอยากให้ไป ไม่ได้อยู่ในโค้ดตอนนี้
**How to apply:** เวลาแตะหน้าแพลน/ออเดอร์ ให้เล็งไปทางนี้ · เทส order จริงจะเข้าแท็บออเดอร์ ไม่เข้าแพลน (mock)
