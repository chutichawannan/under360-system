ตอนทำหน้าที่ **Command Center / เลขากลาง** (รวมงานหลาย session ผ่าน `send_message`): **ห้ามสั่งงาน/ping ห้องอื่นเองแบบต่อเนื่องไปมา** — นัทเบื่อการที่ AI คุยกันเองเป็นสิบรอบให้ต้องนั่งอ่าน (28 ก.ค. 2026)

**Why:** คืนนั้นผมส่ง cross-session message รัวๆ ทุกครั้งที่ห้องตอบกลับ → เกิด AI-to-AI back-and-forth ยาวมาก นัทกลายเป็นคนอ่าน log การประสานแทนที่จะได้สาระ

**How to apply:**
- **ส่ง cross-session message ต่อเมื่อนัทสั่งชัดเจนเท่านั้น** ("ถามห้อง X" / "บอก U ให้ทำ Y")
- **ห้องตอบกลับมา → หยุด** รับไว้ สรุปให้นัท ไม่ auto-ยิงตอบต่อเอง
- **นัทคุมจังหวะ** — รวบรวมสถานะ + สรุปให้นัท แล้ว**รอนัทสั่ง**ค่อยประสานรอบถัดไป
- catchup/สรุปให้นัท = ทำได้เสมอ (นั่นคือคุยกับนัท ไม่ใช่ ping ห้อง)

**ข้อยกเว้นที่นัท sanction (1 ส.ค. 2026) — ระบบ "กล่องจดหมาย + บุรุษไปรษณีย์":** นัทออกแบบเองให้ห้องตอบกันได้แบบคุมต้นทุน → skill `under360-postman` (รันใน terminal เปิดค้าง 1 หน้า · `/loop 1h`) ไล่ดูบอร์ด `session_messages` แล้วปลุก**เฉพาะห้องที่มีจดหมายจริง** · ห้องอ่าน+ตอบเองตาม inbox protocol ใน `under360-session-start` ข้อ 4 · **นี่ไม่ขัดกฎนี้** — เพราะ (ก) นัท sanction เอง (ข) ปลุกเฉพาะเมื่อมีจดหมายถึงห้องนั้นจริง ไม่ใช่ยิงรัวมั่ว (ค) เรื่องที่ต้องนัทตัดสิน = ห้องยกให้นัท ไม่ตอบวนกันเอง · กฎเดิม (ห้าม ping มั่วเอง) ยังใช้กับการประสานนอกกลไกนี้
