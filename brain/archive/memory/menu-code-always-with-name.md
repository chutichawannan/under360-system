นัทสั่ง 17 ก.ย. 2026: **"กฎถาวรต่อจากนี้คือ ทุกครั้งที่บอกรหัสเมนูต้องบอกชื่อเมนูตามด้วยเสมอ"**

**Why:** รหัสอย่าง S020 / D057 / S182 นัทจำไม่ได้ว่าคือเมนูอะไร ต้องเลื่อนหาหรือถามซ้ำ = ต้นทุนการอธิบาย (ดู [[explaining-cost-decides-what-nut-does]]) · เจอจริงวันเดียวกัน: ผมตอบว่า "6 ตัวตกด่าน S020 · S075 · S087 · S096 · S182 · D057" โดยไม่มีชื่อ

**How to apply:** ทุกข้อความถึงนัท (และจดหมายข้ามห้องที่นัทอาจอ่าน) → เขียน `S020 ข้าวน้ำพริกอ่องอกไก่` ไม่ใช่ `S020` · ใช้กับตาราง รายการ bullet และประโยคในย่อหน้าเหมือนกัน · ถ้าพื้นที่แคบ ย่อชื่อได้ แต่ห้ามตัดชื่อทิ้ง · ตระกูลเดียวกับ [[issue-number-needs-label]] (เลขต้องมีชื่อกำกับ)
