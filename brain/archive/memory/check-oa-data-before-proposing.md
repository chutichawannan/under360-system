นัทเปิดสิทธิ์ให้ Claude เข้า LINE OA (manager.line.biz), chat.line.biz, Meta, Google Ads, Supabase แล้ว → **Claude ต้องเข้าไปดู data เองก่อนเสนออะไร ห้ามรอนัทแคปหน้าจอมาให้**

**สิ่งที่ Claude เคยหลุด (นัทสอนเอง 25 ก.ค. 2026):**
- ไม่เคยเปิดหน้า **ข้อมูลเชิงลึก → บรอดแคสต์** (`/insight/broadcast`) ดูผลหลังยิงเลย ทั้งที่เข้าได้ — นัทต้องแคปมาให้เอง
- ไม่เช็ค **timezone** ก่อนแนะนำให้ยิง → ยิงตกวันอาทิตย์เวลาไทย (ดู [[broadcast-timing-thai-vs-pst]])
- ไม่ตรวจว่า **audience แคบไป** (ยิงแค่คนที่มี uid ใน Hato ~1,800 จาก 23,244 followers) จนนัทต้องเพิ่ม target เอง แล้วเจอเองว่ามีคนอ่าน/คลิกอีก ~2,000 คนที่ไม่มีใน Hato

**กฎ:**
1. **ก่อนเสนอ** → เข้า console ที่มีสิทธิ์ ดูตัวเลขจริงก่อนเสมอ (ไม่เดา ไม่รอแคป)
2. **หลัง action ใดๆ (ยิง broadcast/แอด)** → ตามไปดูผลเอง แล้วรายงานกลับ ไม่ปล่อยให้นัทตามเอง
3. **เจอสิ่งที่หลุด/ทำได้ดีกว่า → ติด TODO เป็นเรื่องแรกๆ เอง** ไม่ต้องรอนัทสั่ง (นัทสั่ง: "ติด todo ฉันเป็นเรื่องแรกๆ เลยว่าเราหลุดอะไรไป")

**Why:** นัทเปิดสิทธิ์ให้แล้วเพื่อให้ Claude ทำงานแทน — ถ้ายังต้องแคปหน้าจอมาป้อน = ไม่ได้ช่วยลดงานนัทจริง · โยงกับ [[no-premature-done]] (ขุดให้ครบก่อนบอกเสร็จ) และ [[reduce-ping-shared-todo]]

**How to apply:** งาน marketing/CRM/ads ทุกครั้ง → เปิด console ดู data จริง → เสนอจากตัวเลข → หลังยิงตามผลเอง → หลุดอะไรจด TODO ทันที
