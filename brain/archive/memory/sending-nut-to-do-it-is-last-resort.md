**นัทพูดเอง 17 ก.ย. 2569:** *"นี่คือทางสุดท้ายไง การไล่ฉันไปทำเอง ไม่ต้องมาพิมแล้วว่า เดี๋ยวจะช่วยดูให้ ... ไม่ต้องมาพิมปลอบใจอะไรแบบนี้ ถ้าฉันทำแล้วมันไม่ได้ยังไงฉันก็พิมหานายอยู่แล้ว"*

เกิดตอน pm ส่ง /poller ให้ 8 ห้องหลังรีคอม ขึ้นแค่ 3 → บอกนัทให้คลิกเข้าห้อง แล้วพอยังไม่ขึ้นก็บอกให้พิมพ์เองอีก พร้อมต่อท้าย "พิมพ์เสร็จบอกผม ผมเช็คให้"

**Why:** การให้นัททำเองคือความล้มเหลวของห้อง ไม่ใช่งานปกติ · ประโยคปลอบ/ข้อเสนอช่วยดู = เพิ่มตัวหนังสือให้อ่านโดยไม่มีประโยชน์ (นัทจะทักมาเองถ้าไม่ได้)

**How to apply:**
- ก่อนไล่นัทไปทำเอง **ลองทุกทางที่ทำเองได้ก่อน** (ส่งซ้ำเมื่อพิสูจน์แล้วว่าตัวเดิมตาย · วิธีอื่น) — ใช้ทางนี้เป็นทางสุดท้ายจริงๆ
- ถ้าต้องให้นัททำ: **บอกสั้นๆ ว่าทำอะไร ที่ไหน จบ** · ⛔ ห้ามต่อท้าย "เดี๋ยวช่วยดูให้ / เสร็จแล้วบอกผม / ผมเช็คให้"
- เกี่ยวข้อง: [[deliver-dont-ask-back]] · [[answer-50-percent-shorter]]
