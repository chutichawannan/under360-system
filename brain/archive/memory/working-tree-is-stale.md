หลาย session ใช้ repo เดียวกัน แต่ทรีในเครื่องไม่ได้ pull ตาม → **grep ไฟล์ในเครื่องแล้วสรุปว่า "ยังไม่มีฟีเจอร์นี้" = รายงานผิด**

เกิดจริง 2 ครั้ง: พี่ปืนรายงานนัทว่า "LIFF ไม่เก็บ UTM เลย" (1 ก.ย.) · ห้อง 06 เกือบรายงานว่า u-maintainer ยังไม่ทำ `source_content` (8 ก.ย.) — ทั้งคู่ของจริงมีอยู่แล้วบน origin/main

**Why:** รายงานผิดเรื่อง "ห้องอื่นยังไม่ได้ทำ" ทำให้นัทไปทวงงานที่เสร็จแล้ว และทำให้ห้องนั้นเสียเครดิตฟรีๆ

**How to apply:** ก่อนบอกว่าโค้ดมี/ไม่มีอะไร → `git fetch -q origin` แล้ว `git show origin/main:<path> | grep …` ไม่ใช่ grep ไฟล์ในเครื่อง · เป็นชั้นเดียวกับ [[docs-are-snapshots-verify-first]] แต่กับไฟล์โค้ด ไม่ใช่เอกสาร
