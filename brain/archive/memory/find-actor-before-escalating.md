ก่อนส่งงานที่ "ต้องให้คนไปทำ" ถึงนัท ต้องตอบครบ 3 ข้อก่อน ขาดข้อไหน = ยังไม่ส่ง

1. **ใครทำ** — query `orders.created_by` / `activity_log.actor` จาก DB จริง **ห้ามเดาจากชื่อที่คุ้น**
2. **ทำผ่านหน้าไหน**
3. **หน้านั้นเปิดให้ทำแบบนั้นได้หรือเปล่า** ← ข้อที่แยก "คนพลาด" ออกจาก "ระบบพัง"

**Why:** 17 ส.ค. 2026 — ผมรับต่อจากห้องฟ้าว่า "Diet Set A 24 กล่องยังไม่มีใครเลือกเมนู รอกิ๊ฟ" แล้วส่งถึงนัทตรงๆ
ของจริง `created_by = เพอรี่` ไม่ใช่กิ๊ฟ (query เดียวก็รู้) → นัทไปไล่ถามผิดคน
และไม่มีใครถามข้อ 3 เลย จนนัทเปิดหน้าจอเอง แล้วเจอว่า **หน้า "สั่งแทนลูกค้า" ไม่มี UI ให้ติ๊กเมนูในเซ็ต** = ระบบพัง ไม่ใช่ใครลืมเลือก
นัทพูดเอง: *"ของแบบนี้ troubleshoot เองไม่ได้ ฉันต้องทำยังไงดี มันมาคอขวดที่ฉัน"*

**How to apply:** เจอปัญหาที่ปลายทาง (ครัวทำไม่ได้ / ของขาด / ข้อมูลไม่ครบ) → ไล่ย้อนไปหาต้นทางในระบบก่อนเสมอ
ห้ามส่งต่อรายงานของห้องอื่นแบบ pass-through — ห้องอื่นก็อาจข้ามข้อ 3 มาเหมือนกัน
ถ้าคำตอบข้อ 3 คือ "ระบบเปิดให้ทำผิดได้" → เป็นใบงานส่ง U ไม่ใช่งานที่นัทต้องไปตามคน
