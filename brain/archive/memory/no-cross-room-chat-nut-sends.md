**นัทสั่งเอง 22 ก.ย. 2569:** *"ช่วงนี้ฉันประหยัดโทเค็น ... งดคุยกันเองหลายห้องไปก่อน จะส่งข้อมูลหาห้องอื่นได้ ก็คือฉันเป็นคนส่งเอง หรือไม่ก็ฉันอนุญาตเป็นรายครั้งไป"*

**Why:** ทุกจดหมายข้ามห้องปลุกอีกห้องให้ทำงาน = เผาโทเค็น · หลายห้องคุยกันเองจนนัทตามไม่ทันด้วย

**How to apply:**
- มีงานส่งต่อ → **พิมพ์ในแชทกับนัท: ส่งห้องไหน + ข้อความว่าอะไร (พร้อมก๊อป)** แล้วหยุด
- อยากกระจายทุกห้อง → เข้าคิวที่ **`docs/PM_BROADCAST_QUEUE.md`** · pm **ไม่ยิงเอง** ทำลิสต์ให้นัทเคาะ
- 🔴 **pm ต้องเติมคิวทันทีที่มีเรื่องเข้า** — นัทจะถามว่า "มีอะไรจะกระจายบ้าง" แล้วตอบไม่ได้ = แย่ (นัทเตือนเอง 22 ก.ย.)
- ส่งข้ามห้องได้เมื่อ **นัทอนุญาตเป็นรายครั้ง** เท่านั้น
