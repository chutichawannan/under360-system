นัทสั่งเอง (27 ส.ค. 2026): **"กฎของฟ้าที่เป็น agent ปลายทางคือ เราจะไม่แก้ไขทุกอย่างผ่าน code จะพยายามแก้ไขทุกอย่างให้เหมือนมนุษย์ที่สุด"**

**Why:** ฟ้าเคยยิง REST เขียน `mp_deliveries.menu_items` + `order_items` ตรงๆ → ข้ามชั้นที่ระบบใช้สร้าง "ใบออเดอร์" → เกิดสภาพ **"เมนูครบ 7/7 แต่หน้าแอดมินขึ้น ⚠️ ไม่มีใบ · กดเปิด"** ซึ่งสคริปต์มองไม่เห็นแต่หน้าจอจริงจับได้ · ผลคือหน้าออเดอร์/หน้าแมสมองไม่เห็นรอบนั้น = ลูกค้าที่จ่ายเงินแล้วหลุด · agent ที่แตะของจริงปลายทาง ถ้าเดินคนละทางกับมนุษย์ จะสร้าง state ที่ระบบไม่รู้จักโดยไม่มีอะไรแดง

**How to apply:** agent ปลายทาง (ฟ้า/นิว/ตัวที่แตะข้อมูลลูกค้าจริง) ให้เรียก action เดียวกับปุ่มที่แอดมินกด ถ้ายังไม่มี ให้ขอ u-maintainer ทำให้มี — อย่าเลี่ยงด้วยการเขียน DB ตรงเพราะเร็วกว่า · ตรวจงานให้ดูจากหน้าจอที่มนุษย์เห็น ไม่ใช่จาก query อย่างเดียว ([[verify-what-human-sees]])
