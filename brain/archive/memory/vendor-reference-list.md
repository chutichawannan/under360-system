**นัทเคาะเอง 10 ส.ค. 2026: จะทำคอนเทนต์ภาพ/วิดีโอ *เองทั้งหมดด้วย AI* ไม่จ้างใคร** — *"ถ้าฉันทำไหว ฉันจะจ้างทำไม"*

**ที่เก็บ: `docs/VENDOR_REFERENCE.md`** (ใน repo)

นัทส่งลิงก์/รูป reference มาเรื่อยๆ (*"ฉันยังหา reference ให้นายเรื่อยๆนะ"*) → **ทุกอันต้องถอด 3 ข้อ:**
① ทำด้วยอะไร (เทคนิค + **ศัพท์ที่นัทเอาไปค้นต่อเองได้**) ② ทำเองไหวไหม/ต้นทุน ③ ใช้กับร้านเรามุมไหน + ขัดกฎแบรนด์ตรงไหน

**⚠️ บทเรียนที่ Claude พลาดมาแล้ว (10 ส.ค.) — อย่าทำซ้ำ:**
- นัท**ไม่ได้ต้องการให้ Claude ทำแทน** (เคยเสนอเขียนสคริปต์ API ให้ = ผิดทาง) และ**ไม่ได้จะจ้างใคร**
- นัทต้องการ **"ไปหาแหล่งไหน · ทำยังไงให้ภาพสวย"** = ความรู้/แผนที่ให้เดินเองต่อได้
- **อย่าไล่ list เครื่องมือให้เลือก** (นัทบอกเอง "ไม่เวิร์ค") · ให้หลักการ + ศัพท์ค้นต่อ + แหล่งที่ก๊อปสูตรได้จริง (Civitai มี prompt ติดทุกภาพ)
- ข้อได้เปรียบของเรา: **มีรูปสินค้าจริงเยอะแล้ว** → ข้ามชั้นที่แพงสุดของสาย AI (สร้าง character) ไปเลย · ใช้ img2img/inpainting/relighting ไม่ใช่ text-to-image

**Why:** ประหยัด + คุมเองได้ + ตรงกฎแบรนด์ "อาหารจริงจากกล่องจริง"
**How to apply:** เก็บ reference → ถอดสูตร → ให้นัทลองเอง · เกี่ยวโยง [[claude-cannot-make-images]] (Claude ทำภาพเองไม่ได้ = ยิ่งต้องส่งความรู้ให้นัททำ)
