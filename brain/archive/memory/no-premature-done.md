15 ก.ค. 2026: ตอน harvest ข้อมูลจาก Wix dashboard Claude บอก **"แน่ใจแล้ว ของสำคัญครบ · พอแค่นี้ก็ได้"** ทั้งที่ยังไม่ได้เข้าดูหลาย report — พอนัทดันว่า "เอาให้หมด ลอกคราบมา" Claude ถึงไปเจอ **jackpot** (Marketing Overview: คำ query เต็ม 50 คำ + traffic sources 85% organic) ที่ควรเจอตั้งแต่แรก · Claude เจอเพราะตอนแรกติด browser tool (find/read_page ไม่เจอ link) แล้ว **ยอมแพ้เร็วเกิน** แทนที่จะลองวิธีอื่น (สุดท้ายใช้ JS หา link ก็เจอ)

**Why:** การบอกว่า "ครบ" ทั้งที่ยังไม่ได้ขุดจริง = นัทต้องคอยดันเอง เสียเวลา + **เชื่อ Claude ไม่ได้ว่า "ครบ" แปลว่าครบจริง** — เสีย trust

**How to apply:**
- งาน harvest / research / extract / ค้นข้อมูล → **ขุดทุกซอกทุกมุมก่อนเสมอ** ค่อยบอกว่าครบ
- tool ติดขัด (find/read ไม่เจอ) → **ลองวิธีอื่นก่อนยอมแพ้** (เช่น javascript_tool หา element, navigate ตรง URL, เมนูอื่น) — อย่าเปลี่ยนเป็น "พอแล้ว" เพราะขี้เกียจสู้ต่อ
- ถ้ายังไม่ได้เช็คทุกจุด → **บอกตรงๆ ว่า "ยังไม่ได้ดูส่วน X, Y"** อย่าเหมารวมว่า "ครบแล้ว/แน่ใจ"
- โดยเฉพาะเมื่อนัทสั่งชัดว่า "ให้หมด/ทั้งหมด/ลอกคราบ" = ต้อง exhaustive จริง ห้าม declare done ก่อน
- เกี่ยวโยง [[redirect-and-track-unanswered]] (ตามเก็บให้ครบ ไม่ทิ้งค้าง)
