นัทสั่งเอง 11 ส.ค. 2026: **"เรื่องเทสทดลองไม่ต้องสนใจ มันไม่ใช่ระบบที่พวกเราต้องแก้ · ฉันไม่อยากแก้ไข การทดลองเป็นสิทธิ์ของ admin"**

**Why:** ผมรายงานแพค "เทส ทดลอง ฿500" ว่า "ลูกค้ากดสั่งได้จริง ควรปิด" **ซ้ำ 3 รอบใน 2 วัน** — เข้าใจผิดทั้งหมด
· ลูกค้าเข้าไม่ถึงจริง เพราะ **ไม่ได้ใส่ไว้ในการ์ดหน้าโฮม (`home_layout`)** — `packages.is_active=true` อย่างเดียวไม่พอที่ลูกค้าจะเจอ
· ของพวกนี้คือเครื่องมือทำงานของแอดมิน การไปปิดให้ = ไปยุ่งกับพื้นที่ทำงานคนอื่น

**How to apply:** เจอของที่ดูเหมือน "หลุดไปหาลูกค้า" → เช็ค `home_layout` ก่อนว่ามีการ์ดชี้ไปหาไหม · ถ้าไม่มี = ลูกค้าไม่เจอ ไม่ใช่บั๊ก · และถ้าชื่อบ่งว่าเป็นของเทส/ทดลอง **ถามก่อน อย่าปิดเอง**

**กฎกว้างกว่านั้น: "เปิดขายอยู่ในตาราง" ≠ "ลูกค้าเจอ"** — ใช้กับ `menu_items.is_available` ด้วย ([[docs-are-snapshots-verify-first]] แนวเดียวกัน: อย่าสรุปจากค่าใน DB ค่าเดียว)
