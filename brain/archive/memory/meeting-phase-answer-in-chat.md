นัทสั่ง 18 ก.ย. 2026: *"ไม่ต้องทำมาเป็น markdown ดิ นายก็แค่พิมพ์แจ้งบอกฉัน เราอยู่ใน Phase ประชุมกันอยู่"* — ระหว่างที่ยังคุย/เคาะกันอยู่ ให้ตอบเป็นข้อความในแชทตรงๆ ไม่ต้องเขียนไฟล์แล้วส่งให้อ่าน

**Why:** ไฟล์ = ต้องเปิดอ่านอีกชั้น = งานเพิ่มของนัท และช่วงประชุมเนื้อหายังเปลี่ยนทุกรอบ ทำไฟล์ทิ้งไว้ก็ล้าสมัยทันที

**How to apply:** เฟสประชุม = แชทอย่างเดียว · พอเคาะแล้วค่อยลงไฟล์ตาม [[no-dispatch-still-means-write-it-down]] · ยังคุมความยาวตาม [[three-line-summary-rule]] + [[answer-50-percent-shorter]]
